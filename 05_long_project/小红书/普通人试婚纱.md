### 款1：一字肩蕾丝/闪钻大拖尾蓬裙
- [ ] 评估一字肩对微胖上半身（尤其手臂）的遮肉效果
- [ ] 试穿时观察蕾丝/闪钻在丰满身材上的视觉效果

### 款2：抹胸大拖尾蓬裙（全闪钻/珠绣）
- [ ] 确认抹胸款在丰满身材上的稳定性与安全感
- [ ] 试穿时评估全闪钻是否会显胖或过于隆重

### 款3：蕾丝方领/圆领大拖尾蓬裙
- [ ] 观察蕾丝款对普通身材的包容度与温柔感
- [ ] 试穿时确认领口高度是否显脖子短或脸大

### 款4：一字肩缎面/纱面大拖尾蓬裙
- [ ] 对比缎面与纱面在普通身材上的显瘦差异
- [ ] 试穿时评估一字肩宽度与肩部比例协调性

### 款5：抹胸褶皱/立体花大拖尾蓬裙
- [ ] 评估胸前装饰（褶皱/花朵）对胸型的修饰作用
- [ ] 试穿时观察整体比例是否协调、是否显腰粗

### 款6：半袖/中袖蕾丝大拖尾蓬裙
- [ ] 确认半袖/中袖对微胖手臂的遮肉效果
- [ ] 试穿时对比有袖款与无袖款在正式场合的端庄感

### 款7：挂脖/V领大拖尾蓬裙
- [ ] 评估挂脖/V领对脸型与肩颈线条的修饰
- [ ] 试穿时确认上半身支撑力与舒适度

### 综合筛选
- [ ] 根据自身体型特点（上半身丰满/手臂粗等）筛选3-4款候选
- [ ] 试纱时携带原相机拍摄正面/侧面/背面全身照对比
- [ ] 参考评论区经验（如"不漏肩膀的比一字肩好"）调整选款方向
