## 待办

### 试纱前准备
- [ ] 先在线上锁定几家心仪的店铺和款式
- [ ] 先去能免费试纱的店家（一般前三件免费）
- [ ] 穿无肩带内衣或胸贴
- [ ] 处理腋下脱毛
- [ ] 简单化个淡妆
- [ ] 带1-2位审美同频的人参考

### 试纱过程
- [ ] 多试风格，大胆沟通
- [ ] 疯狂拍照，多角度拍（正面、侧面、背面、走起来、坐下来）
- [ ] 注意舒适度，确保行动自如
- [ ] 不着急当天就下单，回家对比照片

### 异地租赁
- [ ] 确认租赁条款：是否支持异地租赁，邮寄还是自取，是否需要额外收取异地费或清理费
- [ ] 算好租期（一般3-5天），确保覆盖婚礼日期和前面试装时间，问清超时收费
- [ ] 费用弄清楚：定金、尾款、清洁费、损坏赔偿标准、修改尺寸是否收费，写进合同
- [ ] 寄送的话，收到后第一时间在快递点检查外包装，全程录像开箱
- [ ] 拿到婚纱后要立刻试穿
- [ ] 如果尺寸有出入，马上联系店家
- [ ] 寄出前一周和店家反复确认好自己的准确尺码
