### 新娘妆核心审美原则

- **辨识度优先**：保留新娘自身五官特点与气质，不盲目追求网红妆容，避免“千人一面”，让新娘既精致又有个人特色
- **色调统一**：底妆、眼妆、唇妆、腮红色调协调，避免色彩冲突；根据新娘肤色、婚纱颜色、婚礼风格确定主色调，凸显整体高级感
- **减龄与精致兼顾**：弱化面部瑕疵（痘印、黑眼圈、毛孔等），提升轮廓立体感，同时打造减龄感，让新娘呈现温柔、灵动的状态
- **肤质优先**：根据肤质调整妆面质感，干皮追求光泽感，油皮追求雾面哑光感，敏感肌注重温和无刺激，避免卡粉、出油、过敏等问题
- **整体适配**：妆面风格与婚纱款式、头饰、婚礼主题（中式/西式）、场景（室内/外景）高度匹配，实现“妆、纱、景”一体化

### 新娘妆主流风格解析

**清透裸妆风**
- 核心“伪素颜”，底妆轻薄通透
- 眼妆以大地色、香槟色为主；眉形自然有毛流感
- 唇妆选用裸粉色、奶茶色
- 适合偏爱简约、自然的新娘，适配外景婚礼、简约西式婚礼

**精致大气风**
- 底妆细腻服帖，眼妆稍显精致（可添加细闪、轻微拉长眼线）
- 眉形柔和有弧度，唇妆选用玫瑰色、水红色
- 适合主纱仪式，适配室内婚礼、高端婚礼，上镜效果佳

**中式温婉风**
- 眉形规整（柳叶眉、平眉为主），眼妆偏古典，可添加红色系点缀
- 唇色选用正红、枣红，底妆干净白皙
- 凸显东方女性温婉气质，适配秀禾、龙凤褂造型

**复古优雅风**
- 眉形偏细、有弧度，眼妆以大地色、红棕色为主
- 唇妆选用复古红、豆沙红，底妆哑光细腻
- 适配复古婚纱、民国风婚礼，凸显优雅气质

**森系灵动风**
- 底妆清透有光泽，眼妆以浅棕色、蜜桃色为主，可添加少量细闪或干花点缀
- 眉形偏自然野生，唇妆选用水蜜桃色、浅豆沙色，搭配森系头饰
- 适配户外草坪婚礼、森系主题婚礼，凸显灵动与清新感

**轻法式优雅风**
- 底妆强调皮肤原生质感，眼妆柔和自然，以奶茶色、浅棕色为主
- 眉形柔和有弧度，唇妆选用温柔豆沙色、裸玫瑰色，搭配简约法式头饰
- 适配法式婚礼、简约高端婚礼，凸显优雅与慵懒感

### 风格适配技巧：按脸型选妆面

**圆脸新娘 → 精致大气风、复古优雅风**
- 核心问题：面部圆润、线条柔和，视觉重心偏低，易显幼态或缺乏立体感
- 精致大气风：通过高鼻梁修容（纵向加深鼻影）、微扬眉峰（拉长面部视觉）、眼尾拉长的眼线，将视觉重心上移，打破圆润感，打造精致立体小脸效果
- 复古优雅风：借助复古感眼妆晕染（眼尾加深）、清晰唇线，增加面部精致度与成熟度，弱化稚气感，凸显优雅气质

**方脸新娘 → 清透裸妆风、中式温婉风**
- 核心问题：面部棱角分明、下颌线明显，轮廓硬朗，易显干练或凌厉
- 清透裸妆风：采用低饱和度、无明显边界妆面，以柔和光影过渡替代硬朗修容，弱化尖锐线条，打造清透温婉原生感
- 中式温婉风：通过圆润平缓眉形（如平眉）、大面积晕染的柔和眼妆、横向延展的腮红，从视觉上柔化面部棱角，传递东方女性温婉气质

**长脸新娘 → 清透裸妆风、森系灵动风**
- 核心问题：面部纵向比例长、横向比例不足，易显单薄或成熟
- 核心在于缩短纵向比例、拓宽横向视觉：平眉（降低眉峰，避免纵向延伸）、横向晕染腮红（提升面部横向存在感）、眼头提亮眼妆（分散视觉重心），平衡长脸比例

**鹅蛋脸新娘 → 适配所有风格**
- 核心优势：面部比例均衡、线条流畅，是最理想的脸型
- 全风格通用，可根据新娘个人气质、婚纱款式及婚礼主题自由选择；重点在于强化自身五官优势，打造贴合场景与气质的专属妆感，避免平淡

**椭圆脸新娘 → 轻法式优雅风、精致大气风**
- 核心问题：线条柔和、比例接近鹅蛋脸，但面部略偏修长，轮廓感偏柔和，易显寡淡、缺乏高级感与记忆点
- 轻法式优雅风：以慵懒柔和眉形、通透自然底妆、低饱和度唇妆，搭配轻微面部提亮，提升氛围感，凸显优雅慵懒气质
- 精致大气风：通过适度立体修容（强化鼻影、轻微修饰下颌线）、精致眼尾晕染、清晰唇线，增加轮廓感与高级感，让妆面更具辨识度

**正三角脸（梨形脸） → 精致大气风、轻法式优雅风**
- 核心问题：下颌宽、额头窄，视觉重心下沉，易显下颌厚重、上庭单薄，整体比例失衡
- 精致大气风：提亮额头（增加上庭饱满度）、弱化下颌修容（避免加重厚重感）、强化眼妆与眉妆（将视觉重心上移），平衡上下庭比例
- 轻法式优雅风：以柔和自然眉形（拓宽额头视觉）、通透轻薄底妆（避免下颌显厚重）、重点突出的眼妆与唇妆，转移对下颌的注意力

**倒三角脸（心形脸） → 清透裸妆风、森系灵动风**
- 核心问题：额头宽、下巴尖窄，上庭偏宽、下庭偏尖，轮廓偏尖锐，易显单薄、凌厉，缺乏柔和感
- 清透裸妆风：弱化额头修容（避免加重上庭宽度），用柔和腮红与唇妆增加下庭饱满度，以低饱和、无明显边界妆感中和尖锐线条
- 森系灵动风：以自然毛流眉（弱化额头宽度）、横向晕染元气腮红（拓宽下庭视觉）、饱满唇妆（增加下庭厚重感），搭配轻微颧骨柔和修容

**菱形脸 → 中式温婉风、复古优雅风**
- 核心问题：颧骨突出、额头与下巴偏窄，面部凹凸感强，易显颧骨突兀、面部单薄，轮廓偏凌厉
- 中式温婉风：以圆润平缓眉形（避免强化颧骨线条）、柔雾质感腮红（晕染在颧骨下方，弱化颧骨突出感）、柔和眼妆与唇妆，提升面部柔和度
- 复古优雅风：通过强调唇妆（转移对颧骨注意力）、弱化颧骨修容（柔和光影过渡）、精致眼尾晕染（提升面部精致度），修饰凹凸不平轮廓
