### 方领
- [ ] 判断自己是否属于胸部丰满/手臂较粗/方形脸型，确认是否适合方领
- [ ] 试纱时试穿方领款并观察遮肉与修饰脸型效果

### 抹胸
- [ ] 确认肩颈背部线条是否适合抹胸款
- [ ] 试纱时试穿抹胸款并测试上半身视觉效果

### 高领
- [ ] 判断身形是否偏瘦、脸型是否偏长，确认高领适配度
- [ ] 试纱时试穿高领款并观察颈部与脸型修饰效果

### 半袖
- [ ] 确认是否属于肩膀较宽/微胖身材，评估半袖遮肉效果
- [ ] 试纱时试穿半袖款并观察直角肩与比例拉长效果

### 一字肩
- [ ] 确认肩颈线条是否适合一字肩，评估斜方肌/肩膀厚度影响
- [ ] 试纱时试穿一字肩重工款并记录舒适度与视觉效果

### 宫廷风
- [ ] 确认婚礼场地是否为酒店且能撑起大拖尾气场
- [ ] 试纱时试穿宫廷风大拖尾款并评估身高/现场适配度

### 缎面
- [ ] 判断婚礼是否为草坪/户外/绿色主题，确认缎面风格适配
- [ ] 试纱时试穿缎面款并记录优雅简约效果

### 泡泡袖
- [ ] 确认是否属于肩瘦/溜肩身材，评估泡泡袖减龄效果
- [ ] 试纱时试穿泡泡袖款并观察肩部视觉量感

### V领
- [ ] 判断是否需要修饰脸型，确认V领对微胖身材的友好度
- [ ] 试纱时试穿V领款并观察脸型修饰效果

### 鱼尾
- [ ] 确认身材比例与曲线是否适合鱼尾款
- [ ] 试纱时试穿鱼尾款并观察腰臀曲线与腹部修饰效果
