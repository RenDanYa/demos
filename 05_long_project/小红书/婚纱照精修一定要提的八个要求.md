### 精修沟通要求

- [ ] 拒绝一键磨皮，保留皮肤质感和个人特征痣
- [ ] 拒绝流水线P图，按原五官比例微调
- [ ] 处理婚纱和西服褶皱

- [ ] 身型比例调整自然，不过度拉长，注意斜方肌、锁骨、手臂对称
- [ ] 修掉背景杂物、穿帮、背景布褶皱
- [ ] 调修草地颜色，外景全身照适当拉高身高
- [ ] 调亮肤色，避免外景肤色暗沉

### 人物修图要求

- **皮肤质感**：去痘印、斑点、法令纹，磨皮要自然，保留皮肤纹理，避免假面感。
- **身材比例**：适当瘦腿、收腰、瘦手臂、收副乳，但不能过度变形失真。
- **面部五官**：眼睛放大且左右对称、鼻梁挺一点、鼻翼收一点、下巴尖一点，但要符合本人特征。
- **笑容与表情**：嘴角对称、牙齿美白，表情自然不生硬。

### 服装与背景修图要求

- **服装褶皱与破损**：婚纱、西装的褶皱修平顺，破损、脏污、线头修掉，裙摆要干净自然。
- **背景杂物**：内景地板砖线条、背景布褶皱、外景游客、地面垃圾等穿帮全部修掉。
- **背景光线**：纯色内景背景因外部光线造成的深浅不一要统一调节，使画面干净。

### 场景色调修图要求

- **肤色统一**：新郎新娘肤色要协调，不能一个过白一个过黄，整体肤色自然。
- **草地颜色**：草地婚纱照的草地要修出绿草如茵的感觉，避免光秃秃；同时人物身高适当拉高，弥补外景全身显矮的问题。
- **天空与海景**：有天空或海景的照片注意色调统一，海水要蓝、天空要自然。
