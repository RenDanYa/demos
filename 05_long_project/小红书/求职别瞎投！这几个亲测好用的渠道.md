### 国家官方校招平台
- [ ] 在国聘行动（https://www.iguopin.com/）注册并投递
- [ ] 在24365国家大学生就业服务平台（https://job.ncss.cn/）查找岗位
- [ ] 在就业在线（https://www.jobonline.cn/）投递简历
- [ ] 在中国公共招聘网（http://job.mohrss.gov.cn/）查看招聘信息

### 央企/国企专项
- [ ] 在中智招聘（https://www.ciicscjob.com/）投递央企岗位
- [ ] 在国家电网人力资源平台（https://zhaopin.sgcc.com.cn/）投递
- [ ] 在中国烟草招聘系统（http://www.tobacco.gov.cn/）查看信息
- [ ] 搜索所在省市国资委官网，关注本地国企招聘

### 公务员/事业单位
- [ ] 访问国家公务员局官网（http://www.scs.gov.cn/）了解国考信息
- [ ] 访问高校人才网（https://www.gaoxiaojob.com/）投递高校岗位
- [ ] 搜索当地人社局官网，关注事业单位招聘信息

### 地方政府渠道
- [ ] 在目标城市人才网（北京人才网、上海外服、山东人才网等）注册投递
- [ ] 在广东人才网、浙江人才网、四川人才网、广西人才网、辽宁人才网投递目标岗位

### 综合招聘平台
- [ ] 在前程无忧、智联招聘、BOSS直聘、猎聘网注册并投递
- [ ] 在拉勾网、实习僧、牛客网、海投网查找并投递岗位

### 企业官方渠道
- [ ] 关注腾讯校招、阿里巴巴校招、字节跳动校招并投递
- [ ] 关注华为招聘、百度招聘、搜狐招聘并投递

### 行业垂直渠道
- [ ] 在北极星招聘（能源）、医药英才网、中国汽车人才网投递对口岗位
- [ ] 在银行招聘网、中公金融人查看金融岗位

### 国际/外企求职
- [ ] 注册 LinkedIn（领英）并投递外企岗位
- [ ] 在 Indeed 全球版（https://www.indeed.com/）搜索海外岗位
- [ ] 在外企德科（https://www.fescoadeco.com/）查看外企岗位

### 国家官方校招平台

政策保障类岗位，信息权威：
- 国聘行动（国资委主办）：https://www.iguopin.com/
- 24365国家大学生就业服务平台：https://job.ncss.cn/
- 就业在线（教育部）：https://www.jobonline.cn/
- 中国公共招聘网（人社部）：http://job.mohrss.gov.cn/

### 公务员/事业单位渠道

- 国家公务员局：http://www.scs.gov.cn/
- 高校人才网：https://www.gaoxiaojob.com/
- 各地人社局官网：搜索"xx市人社局"，部分地区招聘信息在人事考试网或人社局官网专题专栏

### 央企/国企专项渠道

国企央企校招机会多，专属通道竞争更小：
- 中智招聘（98家央企直招）：https://www.ciicscjob.com/6
- 国家电网人力资源平台：https://zhaopin.sgcc.com.cn/
- 中国烟草招聘系统：http://www.tobacco.gov.cn/（招聘通常在省级烟草公司官网，搜索"xx省烟草专卖局招聘"）
- 各省市国资委官网：搜索"xx省国资委"

### 企业官方渠道

互联网、快消等名企校招核心入口：
