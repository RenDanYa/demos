## 一、前期准备与预算规划

### 1.1 预算制定

- [ ] 不着急付定金，警惕"价格只保留今天"等销售话术
- [ ] 不透露自己的预算给对方
- [ ] 看高价套餐争取按预算价拿下（如6000预算看7000套餐）
- [ ] 砍不动价格时，争取多要精修张数
- [ ] 提前告知婚纱店婚礼场地和预算范围
- [ ] 提前和礼服师说明预算，避免推荐超出预算的款式
- [ ] 确认摄影、主持、化妆预算
- [ ] 确认双方父母衣服、新娘新郎新衣服预算
- [ ] 确认婚房装饰品预算
- [ ] 明确成片交付节点、付款方式、吃住行费用
- [ ] 确认新娘化妆跟妆费用是否另算及具体价格
- [ ] 确定伴手礼预算和数量
- [ ] 确认婚礼当天是一个人来还是带助理、是否需要增加额外费用
- [ ] 确认四大金刚单项报价及明细
- [ ] 确认**婚纱礼服租赁价格**及换款政策
- [ ] 记录每家店的款式、价格和服务评价
- [ ] 确认取还纱时间及超时费用
- [ ] 确认无清洗费、超时费、上门额外费用
- [ ] 确认婚礼当天婚纱破损或污渍的清理方式及赔偿金额

### 1.2 时间规划与流程安排

- [ ] 确认因个人原因改期需提前多久通知可免费用
- [ ] 确认拍完后多久可以选片、多久可以拿到精修
- [ ] 提前确认婚礼场地类型（室内或户外）
- [ ] 提前确认店内能否拍照/拍视频留存参考
- [ ] 确认改衣周期（一般1-2周），赶婚期需提前安排
- [ ] 确认婚纱提前多久取货、最晚归还时间、超时计费标准
- [ ] 控制试纱时间在1-2小时内
- [ ] 若确定要租，提前问清楚取衣时间、存放要求
- [ ] 告知婚礼整体流程
- [ ] 跟主持人提前见面沟通
- [ ] 对接仪式所有流程、仪式时长、习俗、彩排时间
- [ ] 提前沟通新人恋爱故事、重要回忆、谁上台讲话/送祝福
- [ ] 确认是否提供婚礼时间表和双方准备物品清单
- [ ] 确认是否需要长辈上台致辞、是否需要提前准备稿子
- [ ] 确认化妆和换妆需要多长时间、是否能配合礼服适当修改
- [ ] 确认新娘需要提前准备什么
- [ ] 确认付款方式、精修多长时间能出
- [ ] 订婚宴确定婚礼时间后立即预订酒店
- [ ] 至少提前1个月制作电子请帖和纸质请帖
- [ ] 提前3-6月试纱并预订婚纱
- [ ] 提前2-3月购买主纱鞋（7-10cm高跟）
- [ ] 准备头饰、秀禾团扇（提前与化妆师沟通）
- [ ] 提前2周左右理发，尽量不染发烫发
- [ ] 提前2-3月定制或购买西服（长袖衬衫、短袖衬衫、马甲一套）
- [ ] 婚前一周做裸色简单款美甲（如需延长甲提前适应）
- [ ] 准备浅棕色美瞳（提前确认化妆师指定色）
- [ ] 提前预约多家婚纱店（建议3-5家）
- [ ] 规划试纱行程路线和时间安排
- [ ] 安排第一次试纱：婚礼前3-4个月，确定婚纱店和风格方向
- [ ] 安排第二次试纱：婚礼前1-2个月，结合最终身材和场布定稿选定婚纱

- [ ] 根据自身情况制定90天备婚流程计划

- [ ] 提前一天做好护肤准备
- [ ] 问清婚期改了能否免费换档期、提前多久通知
- [ ] 新娘：跟化妆师摄影摄像确定到达时间
- [ ] 两人一起：确定婚纱照拍摄地点并预约时间
- [ ] 两人一起：与酒店沟通婚礼流程等
- [ ] 两人一起：确定父母感恩环节流程
- [ ] 新郎：安排专人接待陆续到来的外地来宾
- [ ] 租赁婚纱提前3-6个月试纱，旺季提前4-6个月
- [ ] 定制婚纱提前6-8个月试纱，中式礼服提前8-10个月
- [ ] 提前收藏喜欢的款式并**告知礼服师**
- [ ] 提前预约试纱时间，尽量避开周末高峰
- [ ] 婚期前6-8个月开始试纱，热门日子提前半年预定
- [ ] **提前在社交平台收藏喜欢的款式**
- [ ] 提前预约（避开节假日及周末，提前1-3天预约，准时到达）
- [ ] 礼服馆需要安排试衣间和礼服师
- [ ] 提前问询是否需要自带妆，如已定好化妆师可当天**妆纱同试**
- [ ] 确认取婚纱提前几天取，婚礼结束几天归还
- [ ] 确认婚纱归还后多久退押金

- [ ] 携带场地照片和婚礼策划定稿去试纱
- [ ] 尽早预订婚礼酒店场地
- [ ] 确定婚礼方案（鲜花、甜品台、桌数等）
- [ ] 新郎：挑选酒店

## 二、婚庆与四大金刚

### 2.1 婚庆公司选择与谈判

- [ ] 确认定金是否可退，明确是"定"还是"订"
- [ ] 将赠送的产品和沟通细节写进合同
- [ ] 让谈判强势的一方出面砍价，通常可砍500-1000元
- [ ] 确认套餐包含几本相册、几个相框，并明确材质和尺寸
- [ ] 定金最多交30%，确认可退或可转让，不要被忽悠交全款
- [ ] 交定金预定后，若更换新款/其他款式是否可以调整
- [ ] 确认套餐内拍摄团队有几个人
- [ ] 婚庆确定后再挑选四大金刚，不要未定婚庆就急着定
- [ ] 确认婚庆免费提供物品清单（礼花筒、喜字、拉花、红包、对联、礼账本等）
- [ ] 通过已婚朋友或当地推荐筛选婚庆公司
- [ ] 试纱时考虑婚礼整体布置风格和色调协调性
- [ ] 与婚礼策划沟通方案
- [ ] 准备婚房布置和婚礼用品
- [ ] 新郎：挑选婚庆策划
- [ ] 确认套餐是否包含头纱、裙撑、伴娘服等配饰
- [ ] 不冲动付定金，多对比几家

### 2.2 摄影师沟通确认

- [ ] 将用不上的产品（如摆台）换成精修(精修拿到手才是最值钱的)
- [ ] 确认底片数量及是否全送
- [ ] 确认精修是否可预审，不满意是否可修改到满意
- [ ] 确认是否有拍摄花絮短片赠送
- [ ] 确认是否赠送结婚登记照，照片是否给精修打印
- [ ] 多拍多角度照片（正面/侧面/背面），方便对比和商量
- [ ] 确认尾款是拍摄完后付还是拿到精修后付
- [ ] 确认拍摄后是否需要支付服装清洁费
- [ ] 确认套餐内底片拍摄张数
- [ ] 确认拍完后底片何时可取走及交付方式（U盘/网盘/邮箱）
- [ ] 确认风格可私人订制还是固定拍摄样式
- [ ] 确认拍完每组照片后是否可当场查看并调整
- [ ] 确认拍摄团队是否分等级
- [ ] 确认后期精修张数（如50张）
- [ ] 确认精修不满意的处理方式
- [ ] 确认精修照片是否可以重复入册
- [ ] 确认摄影单机还是双机
- [ ] 摄影
- [ ] 确认摄影内容是否包含晨袍互动、父母合影、迎亲送别等
- [ ] 确认摄影师拍摄角度偏好（正拍/斜拍/仰拍/俯拍/特写/远景）
- [ ] 确认摄像拍摄内容（摆拍多还是抓拍多，各环节占比和顺序）
- [ ] 确认摄影服务时长和价位
- [ ] 确认精修数量、底片数量、是否全送、不满意是否重修
- [ ] 明确底片和精修交付时间点
- [ ] 确认当天是否能出预告片
- [ ] 确认喜欢的拍摄成片风格（动感/文艺）
- [ ] 确认摄影师人数及档次（高端跟拍/普通跟拍）
- [ ] 确认婚礼当天拍摄张数（如不少于200-400张）
- [ ] 确认是否提供全部底片
- [ ] 确认礼堂气拱门及照片墙喷绘服务
- [ ] 确认四大金刚具体人员配置（司仪/摄像/摄影/跟妆）
- [ ] 确认**摄影摄像**精修张数、底片数量及交付时间
- [ ] 确认婚礼摄影多长时间、拍摄过多少场婚礼、拍摄机器
- [ ] 确认婚礼当天会拍多少张照片、底片是否全给、精修多少张

- [ ] 摄影摄像建议双机位，多了解拍摄风格并指定摄影师
- [ ] 试穿多种款式婚纱并拍摄照片做对比
- [ ] 尽早预订四大金刚（摄影、摄像、化妆、主持）
- [ ] 新娘：与摄影摄像沟通拍摄想法
- [ ] 两人一起：确定主持人、摄影摄像、化妆师
- [ ] 取纱时拍摄360度视频留证
