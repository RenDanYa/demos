### 1.2 砍价与谈判策略

#### 1.2.1 砍价技巧

- [ ] 不着急付定金，警惕"价格只保留今天"等销售话术
- [ ] 不透露自己的预算给对方
- [ ] 让谈判强势的一方出面砍价，通常可砍500-1000元
- [ ] 确定心理价位，避免盲目去奢华店

#### 1.2.2 套餐比价

- [ ] 看高价套餐争取按预算价拿下（如6000预算看7000套餐）
- [ ] 记录每家店的款式、价格和服务评价
- [ ] 提前了解婚纱店的套餐内容和潜在消费项
- [ ] 不冲动付定金，多对比几家
- [ ] 保留谈价聊天记录避免后期涨价

- [ ] 确认拍照是否需包工作人员午餐
