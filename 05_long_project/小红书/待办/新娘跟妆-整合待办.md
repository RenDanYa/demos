## 1、前期准备

### 1.1 婚礼风格与婚纱确认

#### 1.1.1 风格场地

- [ ] 确定婚礼风格（室内/草坪、婚纱大体量/小体量）
- [ ] 确定婚厅布置与婚纱风格，提前试穿确认上身效果

### 1.2 妆造需求梳理

#### 1.2.1 自我评估

- [ ] 评估五官特点，明确需修饰角度和可放大优势
- [ ] 提前收集喜欢的妆造灵感图，明确偏好的色调、风格和适合方向

#### 1.2.2 资料准备

- [ ] 制作并发送跟妆诉求资料给化妆师
	- [ ] 制作跟妆诉求PPT（含婚纱上身照、身高体重、五官特点、化妆习惯、意向造型妆容、不喜欢的妆造）
	- [ ] 找好参考图并提前发给化妆师，附上基本情况、自然照片和要求
	- [ ] 将妆造需求清单连同个人照片一起发给跟妆老师
	- [ ] 整理中式造型需求（妆容、头饰、耳饰、团扇等）并附参考图
	- [ ] 整理敬酒造型需求（风格、发型、花草点缀等）并附参考图

### 1.3 时间与预算规划

#### 1.3.1 时间规划

- [ ] 婚礼酒店订好后开始选化妆师，旺季提前一年、淡季提前半年确定
- [ ] 规划试妆行程，一天最多安排两家，可与试纱安排在同一天，条件允许时约化妆师到婚纱店同步试妆试纱

#### 1.3.2 预算规划

- [ ] 制定跟妆预算范围

## 2、筛选化妆师

### 2.1 寻找渠道

#### 2.1.1 多渠道搜索

- [ ] 通过线上线下多渠道寻找化妆师/店铺
	- [ ] 快速从各平台搜索附近可跟妆店铺（优先婚纱店、化妆培训、摄影店）
	- [ ] 小红书上搜"地点+新娘化妆师"
	- [ ] 通过熟人推荐找化妆师
	- [ ] 找摄影摄像师推荐当地化妆师
	- [ ] 咨询婚纱店是否有合作化妆师
	- [ ] 从各平台评价和朋友打听中对比口碑

### 2.2 初筛与考察

#### 2.2.1 筛选标准

- [ ] 按预算、距离、规模等标准初筛化妆师
	- [ ] 挑选多家有规模的店铺并联系，小店找创始人、大店找经理及总监级
	- [ ] 对比价格，超过预算PASS，低于1000的尽量不考虑，筛选到5家以内
	- [ ] 多对比几家，选择距离婚礼酒店近、性价比高的化妆师/店铺
	- [ ] 线上带图问价，话不投机立刻换

#### 2.2.2 实地考察

- [ ] 电话沟通无问题后实地考察店铺

### 2.3 作品核查

#### 2.3.1 作品真实性

- [ ] 核查化妆师作品真实性与审美匹配度
	- [ ] 网上查看化妆师真实客片/作品集，确认作品为本人出品
	- [ ] 让化妆师发实际案例原图（不要精修照），将作品与本人及价位对应
	- [ ] 根据实际案例确认审美是否一致
	- [ ] 确认化妆师擅长风格及往期作品
	- [ ] 亲自试妆比较等级划分，不盲目相信价位等级
	- [ ] 提前拿到化妆师资料，查看过往案例和风格

## 3、沟通确认

### 3.1 档期确认

#### 3.1.1 档期核实

- [ ] 首先确认化妆师档期，使用阳历日期避免乌龙
- [ ] 沟通婚期，确认婚礼当天是否有档期

### 3.2 费用与套餐

#### 3.2.1 套餐类型

- [ ] 确认跟妆套餐价位及包含的妆造套数
- [ ] 确认全程跟妆、半程跟妆、早妆分别多少钱
- [ ] 确认是否为全程跟妆、凌晨化妆是否额外收费、套餐工作时长及加时费

#### 3.2.2 隐形消费

- [ ] 确认套餐配饰、耗材及隐形消费
	- [ ] 确认是否存在隐形消费（头饰、配饰、假睫毛、身体素颜霜等材料费）
	- [ ] 确认套餐是否包含头饰头纱、耳环、项链、秀禾团扇等配饰
	- [ ] 确认是否提供身体素颜霜、高光闪粉、精灵耳贴、双眼皮贴、假睫毛等耗材

### 3.3 服务范围

#### 3.3.1 人员妆造

- [ ] 确认妈妈、婆婆、伴娘、新郎妆的包含范围与费用
	- [ ] 确认妈妈妆、婆婆妆、伴娘妆、新郎妆是否包含及人数限制，不送是否额外收费
	- [ ] 确认新娘妈妈和伴娘化妆费用怎么算
	- [ ] 确认价格包含几人

#### 3.3.2 试妆与化妆品

- [ ] 确认试妆是否收费、费用多少、是否可免，满意后能否抵扣或免去
- [ ] 确认试妆和婚礼当天是否为同一个化妆师，不满意能否更换
- [ ] 确认造型套数及试妆可试数量
	- [ ] 确认每套衣服可以试多少个造型、不满意是否可以多试
	- [ ] 确认一共包含几套造型，超出造型是否额外加钱
- [ ] 确认化妆品品牌（是否一线品牌），敏感肌是否可自带，要求拍摄化妆台

### 3.4 合同付款与保障

#### 3.4.1 付款方式

- [ ] 确认定金何时交、试妆费是否包含在套餐内或可抵扣
- [ ] 确认付款流程及尾款是否可在婚礼结束后结算
- [ ] 确认近期优惠活动及合作婚纱店/婚庆公司是否有额外折扣

#### 3.4.2 风险保障

- [ ] 确认婚礼当天化妆师因不可抗力无法到场时是否有同档位或以上化妆师补救
- [ ] 确认化妆时间紧或婚礼当天临时有事时的补救措施

### 3.5 异地交通食宿

#### 3.5.1 异地费用

- [ ] 确认异地跟妆的交通、食宿及额外费用
	- [ ] 确认化妆师交通费是否实报实销及是否需要安排食宿
	- [ ] 确认异地婚礼是否收取额外异地费
	- [ ] 确认异地跟妆的交通费、食宿费、早起/晚结束加班费及服务内容

## 4、试妆执行

### 4.1 试妆前准备

#### 4.1.1 护肤与物品

- [ ] 试妆前后做好皮肤护理与物品准备
	- [ ] 试妆前一天不洗头，带好美瞳、胸贴，只做基础护肤
	- [ ] 试妆前一周做好基础保湿，不尝试新的功效型护肤品，试妆当天精简护肤避免搓泥
	- [ ] 随身携带眼唇卸妆液、卸妆湿巾等用品
	- [ ] 试妆后敷舒缓补水面膜修复皮肤

#### 4.1.2 人员安排

- [ ] 选择审美相近的朋友陪同试妆
- [ ] 给新郎也约个试妆

### 4.2 试妆沟通

#### 4.2.1 现场沟通

- [ ] 化妆过程中主动沟通喜好、避雷点和调整要求，及时反馈每一步感受
- [ ] 试妆时考察化妆师性格、沟通能力和态度是否耐心顺畅
- [ ] 试妆时观察妆容与手法是否喜欢、是否熟练轻柔

### 4.3 妆容细节检查

#### 4.3.1 底妆眉眼

- [ ] 试妆时重点检查底妆、眉毛和眼妆细节
	- [ ] 试妆时检查底妆是否暗沉假面卡粉、细节处理是否到位
	- [ ] 试妆时检查眉毛是否根根分明、有无糊成一团
	- [ ] 试妆时检查眼妆是否显气质、真假睫毛是否分层或融合自然
	- [ ] 试妆时检查睫毛是否有苍蝇腿

### 4.4 发型与造型检查

#### 4.4.1 发型头饰

- [ ] 试妆时重点检查发型与头饰细节
	- [ ] 试妆时检查发型碎发情况及颅顶高度是否足够
	- [ ] 试妆时检查发型是否显头小显脸小、头饰能否试戴
	- [ ] 试妆时观察配饰与造型是否齐全干净、风格选择是否多样

#### 4.4.2 造型确认

- [ ] 重点试主纱妆和秀禾妆
- [ ] 多试几个造型，确认晨袍/秀禾/主纱/敬酒服造型
- [ ] 基本确定化妆师后，将每套婚纱、妆容和发型一起试一遍再敲定

### 4.5 动态测试

#### 4.5.1 牢固度测试

- [ ] 试妆后进行动态与镜头测试
	- [ ] 试妆后走动、抬头、低头、鞠躬，测试发饰和发髻牢固度
	- [ ] 用原相机拍半身照，检查妆容自然度和整体比例
	- [ ] 用手机录一段15秒视频，检查大笑、皱眉、假装流泪时的妆面状态

### 4.6 试妆后确认

#### 4.6.1 存档与流程

- [ ] 试妆时多角度拍照留档造型细节，保存好照片供婚礼当天参考
- [ ] 确定礼服后及时与化妆师沟通当天妆造细节
- [ ] 模拟婚礼当天流程，估算各造型切换所需时间
