# 整合后待办

## 1、选购规划

### 1.1 选购时机与顺序

#### 1.1.1 购买时间与物流

- [ ] 提前半个月至一个月购买婚鞋，预留退换货及物流时间
- [ ] 关注天气因素，预留收货缓冲时间
- [ ] 先确定礼服款式和颜色，再购买婚鞋

### 1.2 款式与颜色

#### 1.2.1 款式选择

- [ ] 选择百搭耐看款式：尖头高跟鞋/一字带凉鞋/浅口单鞋/粗跟鞋/平底低跟鞋
- [ ] 确定婚鞋颜色（白色/奶油色/香槟色/裸色/红色/银色/珍珠色）
- [ ] 根据秀禾颜色选择香槟色或红色婚鞋
- [ ] 避免购买透明塑料材质婚鞋（穿着会疼）

### 1.3 鞋跟高度与数量

#### 1.3.1 鞋跟高度决策

- [ ] 根据平时穿鞋习惯确定鞋跟高度（不常穿选3-5cm，常穿选5-7cm，8cm以上仅作拍照用）
- [ ] 小个子新娘准备一双很高且稳的鞋子（约14cm）
- [ ] 小个子选购时测量礼服长度，确认跟高是否足够
- [ ] 确认自己是否会穿高跟鞋，若不会优先考虑粗跟或防水台款式

#### 1.3.2 数量规划

- [ ] 预算允许时准备两双婚鞋（一双仪式鞋+一双备用鞋→舒服、稳定）

## 2、试穿与磨合

### 2.1 试穿检查

#### 2.1.1 试穿与尺码调整

- [ ] 提前在家多次试穿婚鞋，检查是否磨脚、掉跟、卡脚背
- [ ] 同一批次购买多双同款式不同尺码婚鞋进行对比试穿
- [ ] 准备半码垫调整鞋码贴合度

### 2.2 婚前磨合

#### 2.2.1 磨合时间表

- [ ] 按时间表进行婚前婚鞋磨合
	- [ ] 婚前2-3周用吹风机热风吹软鞋面，厚棉袜撑鞋，后跟涂凡士林静置一晚
	- [ ] 婚前1-2周每天穿婚鞋30分钟磨合，先地毯后地砖，挤脚处及时处理
	- [ ] 婚前3-5天搭配婚纱完整走一遍，模拟站立及上下台阶动作

## 3、婚礼当天方案

### 3.1 分段换鞋

#### 3.1.1 按环节准备婚鞋

- [ ] 根据婚礼环节确定婚鞋购买清单
	- [ ] 购买红色拖鞋作为晨袍鞋
	- [ ] 购买红色Nike鞋作为秀禾鞋并准备小装饰配件
	- [ ] 购买Vme水晶运动鞋作为主纱鞋
	- [ ] 购买达芙妮5.5cm粗跟鞋作为敬酒鞋
- [ ] 按婚礼环节准备不同高度的婚鞋
	- [ ] 准备接亲外景用的5-7cm粗跟鞋或平底鞋，方便跑动
	- [ ] 准备迎宾仪式用的8cm高跟水晶鞋，提升出片效果
	- [ ] 准备敬酒晚宴用的低跟或平底鞋，确保长时间站立舒适

### 3.2 防磨与应急配件

#### 3.2.1 防磨装备

- [ ] 提前准备防磨脚贴、后跟贴、创可贴、鞋垫、脚趾保护贴
- [ ] 准备高跟鞋束鞋带（透明款）防止掉跟

#### 3.2.2 应急与展示

- [ ] 婚包中备一双软底拖鞋，敬酒间隙让双脚休息
- [ ] 准备光腿神器搭配婚鞋
- [ ] 准备婚鞋展架/高跟鞋展架用于婚房展示

## 4、店铺调研与比价

### 4.1 收藏与价格确认

#### 4.1.1 链接收藏与比价

- [ ] 收藏待考察婚鞋链接并做好比价
	- [ ] 收藏2号"红红家女鞋"链接（法式不累脚主婚纱神器，小个子友好）
	- [ ] 收藏3号"广州高端女鞋良品店"同款婚鞋链接（头层牛皮一字扣亮片红色婚鞋）
	- [ ] 收藏10号"HBING法式女鞋"链接（中式国风珍珠粗跟高跟鞋）
- [ ] 查看2号婚鞋当前实际价格（评论区提到涨价，升级版82元）
- [ ] 向客服确认2号婚鞋具体增高几厘米
- [ ] 关注支持"退货包运费"的店铺，降低试错成本

### 4.2 店铺避雷

#### 4.2.1 红黑榜整理

- [ ] 整理婚鞋店铺红黑榜
	- [ ] 记录"硬/不好穿"的避雷店铺清单（乔治娜古德曼、斯启、金玉良缘、小龙女的鞋屋、美鞋悠悠、梦琪真皮女鞋店、Candy Girl定制女鞋）
	- [ ] 优先选择交易成功且评价"舒服"的店铺（红红家女鞋、广州高端女鞋良品店、HBING法式女鞋）
