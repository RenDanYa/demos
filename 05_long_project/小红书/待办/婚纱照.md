# 整合后待办

## 阶段一：签约前（店铺筛选与合同签订）
> 目标：选定店铺，签下合同。建议预留 2~4 周。

### 1. 预算与风格预规划（到店前完成）

- [ ] 确定婚纱照预算区间（建议 3000~6000 元），预留 1000 元左右浮动空间→按预算筛选**套系**
- [ ] 根据婚礼需求确定婚纱照拍摄套数（一般 4 套，外景 1~2 套）
- [ ] 可选风格：
    - [ ] 选定经典主纱风格（用于迎宾海报）
    - [ ] 选定新中式 / 喜嫁风格：
        - [ ] 室内可选喜嫁风或汉服风
        - [ ] 室外可选新中式
    - [ ] 选定草坪外景 / 海边风格
    - [ ] 选定韩式简约风格
    - [ ] 选定落日夜景 / 夕阳风格
    - [ ] 特色风格（复古、胶片、油画、法式）按个人喜好选择
- [ ] 谨慎选择（以下风格易翻车，建议避开）：
    - [ ] 反串婚纱照
    - [ ] 工笔画风格（挑身材脸型且考验修图）
    - [ ] 情绪感风格（需颜值和表现力）
- [ ] 提前收集喜欢的拍摄风格和动作参考图，发给摄影师和化妆师
- [ ] 第三、四套拍摄礼服或轻纱，提前确定内景或外景

---

### 2. 店铺筛选与实地考察

- [ ] 先在网上筛选合适的婚纱摄影店，加客服咨询后再决定是否到店
- [ ] 对比婚纱店时重点看：
    - [ ] 后期服务
    - [ ] 门店经营年限
    - [ ] 工作室还是影楼（根据自己喜欢的风格和预算选择）
- [ ] 到店实地查看：
    - [ ] 婚纱款式
    - [ ] 干净程度
- [ ] 不要因为便宜而将就，多去后面看看婚纱

---

### 3. 客片与样片考察

- [ ] 看真实客片：
    - [ ] 确认拍摄风格、角度、姿势是否符合喜好
    - [ ] 根据客片呈现效果 → 选择风格 → 选择店铺
    - [ ] 确认摄影师、化妆师、修图师水平
    - [ ] 优先参考身材 / 长相相似的新人
- [ ] 提前看客片、未精修原片和可选婚纱款式
- [ ] 到店确认客片由店里摄影师拍摄
- [ ] 确认是否有该套餐的客照参考
- [ ] 确认是否有精修和底片对比图

---

### 4. 谈判签约

#### 4.1 砍价策略

##### 一、谈判前的信息收集与策略准备（到店前完成）
> 目的：摸底市价、隐藏底牌、制造竞争压力

- [ ] 不透露自己的预算和婚期给商家
- [ ] 多看几家婚纱店，第二天再回访，用竞品套餐压价
- [ ] 避开周末到店，选择人少时更方便讲价
- [ ] 网上联系时询问套餐分类、价格、活动和优惠力度

##### 二、到店谈判的核心诉求清单（现场逐项确认）
> 目的：按高价套餐的标准去压低价格，同时争取实物升级

- [ ] 看高价套餐按低价谈（如看 1 万档，按 8000 档谈，不透露真实预算）
- [ ] 按高价套餐标准争取：
    - [ ] 精修张数（例如 1 万套餐 68 张，谈到 8000 时争取保留 65 张）
    - [ ] 相框升级加大（按更高价位套餐的相框标准要求）
- [ ] 到店询问：
    - [ ] 减价活动（要求直接减现金）
    - [ ] 增加精修数量（目标争取精修片总数达到 50 张以上）
    - [ ] 当前套餐能否免费升级到更高一级套系
- [ ] 争取升级摄影老师（指定更高等级）
- [ ] 在报价优惠基础上继续砍价（常规可再砍 500~1000 元）
- [ ] 争取多要一张登记证件照并含精修

##### 三、僵局应对与替代方案（砍不动时的后备计划）
> 目的：不硬磕，用“换赠品”或“离场施压”拿回主动权

- [ ] 谈判时少做声，等销售介绍完再问问题（避免暴露急切）
- [ ] 不要现场立即成交，必要时离开以争取更大优惠（可隔天再联系）
- [ ] 稳住心态，谈不下可以走人（底线思维）
- [ ] 砍不动价格时，争取多要精修张数（比要实物更易答应）
- [ ] 预订前谈判争取更多底片、精修、服装和赠品（小件如喜帖、相册等也要开口）→ 全部写入合同

---

#### 4.2 套餐内容确认

- [ ] 不升级套餐和相框，按基础套餐拍摄
	- [ ] 包含几个**造型**及男女各几个
	- [ ] 几套**服装**及男女各几套（建议 4 套左右，避免因过多导致疲惫）：
	    - [ ] 是否分价格区间及是否二次收费
	    - [ ] 确认套餐内衣服是否可以随意选择
	- [ ] 可拍摄**风格**
	- [ ] 是否内外景结合（内外景可以选择几个）
- [ ] 确认**底片**：
    - [ ] 共多少张，是否全部赠送
    - [ ] 底片格式为 JPG 还是 RAW（优先 RAW（无损））
    - [ ] 底片交付时间和形式（网盘 / 邮箱 / U 盘）
- [ ] 确认**精修**：
    - [ ] 是否可以修几张预审，不满意是否可以修改到满意
    - [ ] 确认精修不满意的处理方式（能否重修或更换修图师）
    - [ ] 确认精修**张数**、加精修**单价**及**精修是否都入册**
    - [ ] 确认相框照片是否占用精修数量
- [ ] 确认拍完后：
    - [ ] 能否当场看底片，不满意能否重拍
    - [ ] 多久可以选片
    - [ ] 精修照片多久能拿到
- [ ] 其他：
    - [ ] 用不到的套餐内容找商家替换（如摆台换精修）
    - [ ] 确认是否有强制选片
- [ ] 费用：
    - [ ] 确认好需要**自费的项目**，避免额外消费
    - [ ] 确认**外景拍摄是否有额外费**用（门票、停车、交通、午餐、服装清洁费、化妆品费等）
    - [ ] 确认化妆品是否收费（假睫毛、胸贴等），确认使用的化妆品品牌，避免过敏
    - [ ] 确认道具（手捧花、对戒、饰品）是否收费
    - [ ] 确认产品是否包邮到家
    - [ ] 是否含夜拍、MV、鲜花费用，不含需加多少钱

---

#### 4.3 合同条款

##### 一、合同必写项（避免反悔）
> 目的：把所有口头承诺转化为可追责的书面条款

- [ ] **套餐与赠品基础承诺（必写项）**
    - [ ] 将套餐承诺（服装套数、精修张数）写进合同
    - [ ] 将赠品清单（几个相框、几本相册、摆台、登记证件照）写入合同，并明确材质和尺寸
    - [ ] 效果不满意免费重拍，写进合同

- [ ] **人员与档期确认（核心权益）**
    - [ ] 确认档期、化妆师、摄影师名字写进合同，注明是否分等级及对应费用
    - [ ] 要求商家提供团队人数、落实外景是否 **1 对 1 服务**及成员构成
    - [ ] 敲定**拍摄日期**并准时到达

- [ ] **重拍与突发情况处理（风险保障）**
    - [ ] 要求合同中写明当天不满意可免费重拍
    - [ ] 要求合同中写明重拍可换团队 / 场景及收费标准
    - [ ] 要求合同中写明临时换装收费标准

- [ ] **附加赠送与交付周期**
    - [ ] 要求赠送拍摄花絮或小短片
    - [ ] 落实选片、看精修、收成品的周期和时间


##### 二、费用与风险条款确认（改期、退款、隐性消费）
> 目的：堵死后期加价和突发变故的扯皮空间

- [ ] 确认改期是否有费用（天气 / 不可抗力 / 个人原因 / 工作人员失误）
- [ ] 确认因个人原因不拍了定金是否可以退
- [ ] 拒绝隐性消费，提前确定所有价格并写入合同

##### 三、合同签订前检查与细节核对（签约当场完成）
> 目的：对照实物，避免后期货不对板

- [ ] 签订合同前仔细检查所有项目条款，核对相册相框尺寸
- [ ] 合同中写明照片是冲印还是喷墨打印（影响保存年限，务必确认）

---

#### 4.4 付款与退款

- [ ] 确认定金金额、是否可退、退还政策及**余款支付时间**（最好拍完再付或拿到**精修后付**）
- [ ] 确认付款方式及是否有附加手续费
- [ ] 定金：
    - [ ] 不要急着交定金，警惕“价格只保留今天”等销售话术
    - [ ] 慎重支付，不一次性交完全款
    - [ ] 支付小额定金时要求开具收据，并注明未选可退

---

## 阶段二：拍摄前准备（倒计时执行）
> 目标：调理状态、准备物品、与商家确认所有细节。建议拍摄前 1 个月开始逐步推进。

### 倒计时 30 天（长期准备）

- [ ] 开始健身塑型、纠正体态

### 倒计时 7 天（集中调理）

- [ ] 拍摄前一周开始清淡饮食
- [ ] 拍摄前一周开始坚持涂润唇膏
- [ ] 提前一周开始护肤补水
- [ ] 提前对着镜子练习自然笑容、表情和拍照姿势

### 倒计时 3~7 天（造型基础准备）

- [ ] 提前 3~5 天染发，推荐黑茶色或深棕色系，保持发色统一
- [ ] 提前 3~7 天理发（男生），注意不要剪太短
- [ ] 拍照前不种睫毛、不剪头发

### 倒计时 1~2 天（细节收尾）

- [ ] 提前 1~2 天完成腋下及手臂脱毛
- [ ] 提前 1~2 天做裸色或法式美甲，或备好裸钻穿戴甲
- [ ] **试穿婚鞋**并准备创可贴、高跟鞋贴及防磨脚润滑剂
- [ ] 有正式西装或衬衣可自带，提前拍照发群确认款式
- [ ] 浅色高跟鞋和平底鞋提前拍照发群确认款式颜色

### 倒计时 1 天（终极准备）

- [ ] 拍摄前一天洗头，不使用护发素和发膜
- [ ] 拍摄前一天修剪指甲（男生）、刮胡子、修鼻毛
- [ ] 拍摄前一晚早睡并减少饮水，避免水肿
- [ ] 拍摄前一晚尽量少吃
- [ ] 提前一天查看拍摄日天气预报
- [ ] 备齐拍摄当天需自备的物品（见下方“物品打包清单”）
- [ ] 提前试穿主纱，检查舒适度与效果
- [ ] 录制一个转场短视频（如有此需求）

---

### 服装与造型沟通（拍摄前1~2周重点执行）

> 注：此部分原属于“前期准备”中的内容，按时间线归入拍摄前阶段。

#### 一、前期选纱与风格确认（拍摄前1~2周）

- [ ] 确认**选婚纱时间**（拍摄当天还是提前几天），在群里问清
- [ ] 确认是否会**提前试婚纱**
- [ ] 确认当天是否可以参观婚纱场景
- [ ] 提前整理并告知礼服师自己想要的婚纱风格
- [ ] 前置沟通争取**升级礼服区域**
- [ ] 遇到**喜欢的服装** → 向礼服师索要样片确认效果
- [ ] 不选裙摆脏、超过三种材质、长袖带领子或泡泡袖婚纱
- [ ] 婚纱首选**缎面或纱面材质**
- [ ] 慎选烟雾光影婚纱照，避免看不清人脸
- [ ] 红色礼服更适合室内纯色背景，外景颜色易扎眼
- [ ] 确认能否看**化妆师作品和服装款式**
- [ ] 确认**鞋子**是否需要自带

#### 二、人员沟通与妆造服务确认（选纱后、拍摄前集中沟通）

- [ ] 确认一套服装可拍几个造型
- [ ] 确认妆造更换规则
- [ ] 在既定服装数量下争取多做造型（如主纱做两套妆造）
- [ ] 确认摄影师、造型师等级及是否可以指定
- [ ] 确认拍摄前是否有时间与化妆师、摄影师沟通需求
- [ ] 化妆师：
    - [ ] 确认化妆师是否**全程跟妆**
    - [ ] 确认**化妆时间**
    - [ ] 确认改妆是否免费，是否可随时与化妆师沟通
    - [ ] 提前与化妆师充分沟通妆造（不满意当场提出）
    - [ ] 确认是否可以要求造型
- [ ] 摄影师：
    - [ ] 拍摄前与摄影师沟通拍摄风格、动作及构图
    - [ ] 告知摄影师按用途拍摄：横版双人正面照、竖版全身显高照、横版大场景照、竖版甜蜜亲密照
    - [ ] 要求摄影师多拍横版、竖版、特写、全景等不同构图
    - [ ] 让摄影师在拍摄时提醒驼背、耸肩、高低肩等问题
    - [ ] 拍摄过程中有想法及时与摄影师 / 化妆师沟通
    - [ ] 每组拍完后现场查看原片，发现问题立即要求重拍
    - [ ] 拍摄中提醒摄影师注意男生的姿势与面部拍摄角度

#### 三、拍摄流程与选片规划（拍摄前定好方案）

- [ ] 四套服装按秀禾、主纱、礼服、轻纱顺序安排，主纱放第二套
    - [ ] 选择白灰 / 简约光影背景拍摄内景主纱
    - [ ] 选择草坪 / 森系场景拍摄外景主纱
    - [ ] 慎选红色秀禾拍外景，优先浅色秀禾搭配中山装拍园林
- [ ] 4 套服装安排 1~2 套外景即可，避免过多
- [ ] 提前给摄影师强调哪套是主纱
- [ ] 提前规划每套服装入选张数（如每套约 10 张）

## 阶段四：后期处理
> 目标：选片、精修沟通、产品制作与交付。核心原则：**不加精修、不升级产品、逐张审核**。建议预留 1~2 个月。

### 1. 选片策略

**原则类：**
- [ ] 选片前设定预算与目标，拒绝选片师引导
- [ ] 选片时坚定不加精修
- [ ] 拒绝强制加片与诱导加片
- [ ] 选片时隔几天再决定是否加片
- [ ] 查清加片单价并设定加片预算上限

**选片标准：**
- [ ] 优先保留双人合照，单人照各留 1~2 张
- [ ] 少选背影、剪影、半身、远景及大全景
- [ ] 多选全身正面照与中近景照片
- [ ] 重复动作 / 场景只保留最好的一张
- [ ] 只选表情、光线、构图最佳的照片，不凑数
- [ ] 手或物品特写只保留最好的一张

**产品核对：**
- [ ] 查清赠送相册、摆台、相框数量
- [ ] 查清相册、相框材质与尺寸
- [ ] 查清是否赠送婚礼海报和电子相册
- [ ] 不升级昂贵相册，不额外加相册页数
- [ ] 查清附加礼包内容及实际价值

**用途预留：**
- [ ] 按用途预留对应照片：迎宾海报 / 请柬 / 相框 / 床头 / 视频 / 手机壁纸
- [ ] 按相册排版预留精修张数，避免被动加片

---

### 2. 精修沟通（逐项核对）

**整体要求：**
- [ ] 查看客片修图效果并提出皮肤质感要求
- [ ] 要求指定或优先安排修图师
- [ ] 要求先修几张预审，不满意可修到满意为止
- [ ] 要求初版精修不满意可免费修改
- [ ] 逐张检查精修细节、胖瘦与体态
- [ ] 检查整体环境与服饰细节，不只关注脸部
- [ ] 拒绝流水线 P 图，按原五官比例微调
- [ ] 提前告知修图师需保留的特征（如痣）
- [ ] 保留明显个人特征，拒绝一键磨皮

**肤色与色调：**
- [ ] 要求肤色均匀、整体提亮、气色自然
- [ ] 要求整体色调统一，避免发青发紫
- [ ] 要求色调和谐温馨，避免假白
- [ ] 要求光线正常曝光、光影过渡自然
- [ ] 要求背景颜色干净自然
- [ ] 要求外景草地调色、肤色提亮

**背景与杂物修复：**
- [ ] 要求去除背景杂物、穿帮及背景布褶皱
- [ ] 要求去除外景反光板、电线及背景多余人物
- [ ] 要求修掉脏污、褶皱痕迹及裙摆周边干净
- [ ] 放大检查迎宾照及放大产品的裙摆与衣服破损

**五官与脸型：**
- [ ] 要求面部头部整体稍微修小，额头饱满、发际线补齐
- [ ] 要求脸型对称、五官立体轮廓
- [ ] 要求适当放大双眼、对称眼神提亮
- [ ] 要求鼻翼缩小、鼻梁适当拔高
- [ ] 要求淡化颈纹、眼角细纹，自然不抢镜
- [ ] 要求牙齿美白

**皮肤质感：**
- [ ] 要求皮肤去除痘印、卡粉，干净清透且有纹理

**身形调整：**
- [ ] 要求人物整体瘦身但比例协调
- [ ] 要求身材比例适当拉长、腿部挺拔
- [ ] 要求瘦胳膊、锁骨立体、消除斜方肌和腰部赘肉
- [ ] 要求高低肩、颈部前倾、驼背自然调整
