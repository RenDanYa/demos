# 整合后待办



## 一、前期准备（婚礼前 6-10 个月）

### 1.1 确定基础信息

- [ ] ⭐ **确定预算与心理价位** — 避免盲目去奢华店，了解高定品牌与普通婚纱价位区别
	- [ ] ⭐ **根据预算决定租赁还是定制**（5000以内租赁，以上定制）
	- [ ] ⭐ **确定预算参考**（不同档位参考：2.3k / 4.5k / 5k）
- [ ] ⭐ **确定婚礼场地类型** — 室内可冲大拖尾/重工款；户外/草坪优先轻纱、简约款

### 1.2 身材版型认知

- [ ] 确认自己的身材类型（倒三角/矩形/沙漏/苹果/梨型）筛选适合的婚纱版型
- [ ] 明确自己最在意的身材点（腰、肩、手臂等）
- [ ] 列出需要**避开的婚纱款式清单**

### 1.3 信息收集与店铺锁定

- [ ] ⭐ 线上锁定 **2-3 家**心仪婚纱店铺和具体款式，并**告知礼服师**
- [ ] 为每套衣服至少留一个**备选款式**
- [ ] 🔍 查阅品牌授权名单，确认婚纱店是否为正版授权（警惕低价引流工作室）
- [ ] 线上私信顾问，说清楚：**婚期、婚礼场地风格、心理预算、身材情况、心仪婚纱款式**
- [ ] ⭐ 多找几家婚纱店初步沟通比价（3k档位选择较少，需提前筛选）
- [ ] 选择线上沟通积极、不轰炸式推销的店家到店试纱
- [ ] 🔍 对比多家婚纱店价格，不要轻信当天限时优惠套路

### 1.4 时间安排与预约

- [ ] ⏰⭐ **第一次试纱**：婚礼前 **3-4 个月**，确定婚纱店和风格方向
- [ ] ⏰⭐ **第二次试纱**：婚礼前 **1-2 个月**，结合最终身材和场布定稿选定婚纱
- [ ] 提前 **1-2 周**预约并告知场地风格、预算和身材特点
- [ ] ⏰ 提前 **1-3 天**确认预约，准时到达
- [ ] 选择**工作日**（如周二下午）或**淡季**，预约多家婚纱店（建议 **3-5 家**）
- [ ] 🔍 出行前确认**试纱档期和租赁档期**
- [ ] 预留 **2-3 小时**试纱时间
- [ ] 预留 **1-2 次**到场机会用于**调换款式或复尺**
- [ ] 时间允许时：**上午试妆、下午带妆试纱**
- [ ] 🔍 加客服询问**试纱收费规则**（免费件数、抵扣政策）
- [ ] 优先预约提供免费试纱的店家（一般**前三件免费**）
- [ ] 下单后能否**换款**及是否需**额外费用**
- [ ] 提前询问中意款式的在店档期

### 1.5 店铺实地考察对比

- [ ] 🔍 核查品牌授权与婚纱店名单
- [ ] 优先选择品牌齐全、款式丰富的店面
- [ ] 🔍 观察婚纱**新旧程度、做工、质感和干净程度**
- [ ] 确认婚纱店审美是否在线，是否真心推荐**适合你的款式**
- [ ] 提前了解婚纱店的套餐内容和潜在消费项
- [ ] 记录每家店的**款式、价格和服务评价**

### 1.6 穿戴物品与个人形象准备

- [ ] ⭐ 肉色/浅色**无痕内裤**
- [ ] ⭐ **胸贴/乳贴**（主纱、敬酒服、晨袍用）
- [ ] 肉色**安全裤**（优先选有收腰提臀效果的）
- [ ] 肉色**收腹裤**
- [ ] **内衣**（秀禾服用 — 聚拢定型效果优于胸贴）
- [ ] 准备试纱鞋履与隐形眼镜
	- [ ] 准备隐形眼镜/美瞳（框架眼镜影响观感）
	- [ ] 带上婚鞋去试纱（鞋跟高度与婚礼当天一致）
	- [ ] 穿增高鞋代替高跟鞋试纱
- [ ] 试纱当天化淡妆与发型准备
	- [ ] 提前洗头发、化淡妆（底妆+眉毛+口红）
	- [ ] 盘发或扎马尾（披发会遮挡肩颈线条）
	- [ ] 试纱当天低发髻造型前往
	- [ ] 提前问询是否需要自带妆，如已定好化妆师可当天**妆纱同试**
- [ ] ⏰ 提前确定婚礼当天发型方案（主纱/秀禾配高盘发，敬酒服配公主头）
- [ ] 试纱前身体护理与状态调整
	- [ ] 试纱前一天洗头洗澡、护肤、腋下/胳膊脱毛
	- [ ] 避开生理期以免不小心弄脏婚纱
	- [ ] 试纱前吃七分饱（空腹易低血糖，吃太饱影响观感）
	- [ ] 试纱前早睡不熬夜、少喝水

### 1.7 试纱日穿搭

- [ ] 上身：穿**抹胸**或贴好**胸贴**前往
- [ ] 下身：穿**肉色四角裤/打底裤**前往
- [ ] 🔍 试穿时确认礼服是否**透底**

> 💡 **婚礼日礼服内衣搭配速查**
>
> | 礼服 | 内衣搭配 |
> |------|----------|
> | 主纱 | 胸贴/乳贴 + 收腹裤/安全裤 |
> | 敬酒服 | 胸贴/乳贴 |
> | 晨袍 | 胸贴/乳贴 |
> | 秀禾服 | 内衣（聚拢定型）+ 安全裤 |
>
> **核心原则**：秀禾服穿内衣（定型效果最佳），其余礼服配胸贴。试纱日务必穿肉色打底裤，方便检查礼服透光问题。

## 二、执行中（试纱当天 + 定纱签约）

### 2.1 到店沟通

- [ ] ⭐ 进店先和礼服师明确需求：
	- 婚礼场地（室内/户外）
	- 身材痛点（肩宽/腰腹/副乳）
	- 风格偏好（极简、公主风、复古、鱼尾）— **别盲目试网红款！**
- [ ] 提前和礼服师说明预算，避免推荐超出预算的款式
- [ ] 携带**场地照片**和**婚礼策划定稿**去试纱

### 2.2 选款与试穿

- [ ] ⭐ 进店先**试自己选的款**，再听店员推荐（避免被带着试滞销款）
- [ ] 试纱时考虑婚礼整体**布置风格和色调协调性**
- [ ] 主动与店员沟通，尝试不同风格的婚纱

### 2.3 按身材选款

- [ ] 确定偏好风格（干净简约还是华丽繁复）
- [ ] 按版型试穿：小个子选A字款/短款，微胖选高腰A字/缎面简约，肩宽选一字肩/V领，避开无袖
- [ ] 结合自身身材特点选款（领型、肩部设计、裙摆、材质）
- [ ] 坚持自己喜欢的风格，不要被销售PUA

### 2.4 试穿动作测试

- [ ] 🔍 试穿时做走动、坐下、抬手、转身等动作测试舒适度，确认不勒腰、不踩裙边、不走光
- [ ] 🔍 试穿时仔细检查婚纱是否有破损、污渍、开线，配饰是否齐全
- [ ] 关注婚纱舒适度，确保行动自如

### 2.5 记录与决策

- [ ] 多角度拍摄试穿照片与视频留存
	- [ ] 每套婚纱多角度拍摄（正面、侧面、背面、全身、走动、坐下），方便参考商量
	- [ ] 让别人帮拍视频（视频比照片更直观，能看清走动时的裙摆动态）
- [ ] 提前确认店内拍照/拍视频政策，将照片发给亲友或化妆师参考
- [ ] 控制试穿数量与时间避免审美疲劳
	- [ ] 控制试穿数量在3-5件（主纱、出门纱、敬酒服各 1-2 件）
	- [ ] 控制试纱时间在1-2小时内
- [ ] 邀请审美同频的亲友陪同试纱
- [ ] 大胆砍价，谈好低价保留聊天记录，避免后期涨价
- [ ] ⭐ 试纱后不冲动当场下单
	- [ ] 回家**对比照片后**再决定
	- [ ] 多对比几家

### 2.6 款式与服装套数确认

- [ ] 确定婚礼所需服装套数（主纱、敬酒服、秀禾等）
- [ ] 按主纱→轻纱/迎宾纱→秀禾→敬酒服的顺序试纱
- [ ] 在本地品牌集合店多试穿
	- [ ] 问清不同套餐的实物差异（品牌、新旧、面料、定制程度）
	- [ ] 明确品牌、版型和具体款式
	- [ ] 先锁定一套心仪婚纱，保留后期换款权利
	- [ ] 使用搜索引擎识图功能查询婚纱品牌和款式名称
	- [ ] 找到品牌官方社交媒体账号
- [ ] 确认单件租赁可行性及费用
	- [ ] 问清能否单租某一件、单租怎么算
	- [ ] 付定金或全款前**明确租赁款式**
- [ ] 确认西装与伴郎服购买/租赁方案
	- [ ] 男士西装买比租划算（租赁1000-2000元只能穿一次，同价位可买质量不错的西装日后常穿）
	- [ ] 确认伴郎服**自备或租赁**方案
- [ ] 私信品牌询问个人购买可能性

### 2.7 套餐内容确认

- [ ] ⭐ 确认套餐包含的具体服装件数
	- [ ] 问清具体包含哪几件衣服（出门纱/主纱/敬酒服/晨袍等）
	- [ ] 问清是否包含新郎衣服
	- [ ] 确认包不包含妈妈装和伴娘伴郎服，各有几件
- [ ] 🔍 确认套餐包含的配饰及收费
	- [ ] 确认头纱、头冠、团扇、首饰等配饰是否免费附赠还是额外收费
	- [ ] 试婚纱时搭配头纱、头冠、手套看整体效果
	- [ ] 让礼服师列"免费配饰清单"，写清楚款式和使用时间
- [ ] 确认套餐加价规则与议价空间
	- [ ] 确认是否全场通选、有无分区加价
	- [ ] 在服装满意前提下争取更划算的套餐价格
- [ ] 确认套餐升级与附加服务
	- [ ] 问清套餐能否升级、补差价规则
	- [ ] 咨询婚纱店是否提供**试妆服务及套购优惠**
- [ ] 确认换款升级政策
	- [ ] 交定金后若**更换新款**是否可以调整
	- [ ] 问清后续更换款式是否需要**加价及具体收费标准**
	- [ ] 问清套餐里的衣服能否更换或加钱升级
- [ ] ⭐ **综合评估性价比后再下定**

### 2.8 费用明细确认

- [ ] 🔍 确认隐形消费与全费用明细
	- [ ] 试纱前1-2天和婚纱店确认有无隐形消费（**试纱费、改衣费、配饰费**等）
	- [ ] 确认婚纱归还是否有额外**清洗费**，**超时费、上门额外费用**
- [ ] 🔍 问清试纱费收费标准与抵扣规则
	- [ ] 问清试纱费能否免除（当天定下或多人同行时）
	- [ ] 问清免费试纱是否有**数量限制**
	- [ ] 问清试纱是否**限时、超时怎么算**
	- [ ] 问清试纱费怎么收费（按**件数还是按次数**，是否抵扣租金）
	- [ ] 要求写进**收据**："试纱费XX元，抵扣婚纱租金"
- [ ] ⭐ 明确定金、押金、尾款金额与退还规则
	- [ ] 🔍 **定金**最多交30%，确认可退或可转让，不要被忽悠交全款
	- [ ] 确认**押金**金额（警惕高于套餐价）、返还日期、退还途径、扣款规则，押金条款
	- [ ] 问清**尾款**支付时间（取纱时付还是还纱时付？）
	- [ ] 确认**付款流程**（定金、押金、尾款分别什么时候付）
	- [ ] 🔍 合同写"还纱后**X个工作日**内退押金，无正当理由不得扣钱"
	- [ ] 🔍 仔细审核押金条款，避免过高押金（一般婚纱定金几千块即可）
	- [ ] 合同写明"无重大损坏全额退还押金"
- [ ] 与销售议价/讨价还价，争取优惠与赠品
	- [ ] 尝试协商赠送伴娘伴郎服、晨袍、饰品等权益
- [ ] 🔍 确认婚纱破损/污渍赔偿标准
	- [ ] 确认归还时若出现轻微破损是否扣费及扣费标准，有上限吗
	- [ ] 确认婚礼当天婚纱污渍的清理方式及赔偿金额
- [ ] 🔍 拒绝合同中"全额不退款"的霸王条款（退款一般最多扣除40%的费用）

### 2.9 合同签订

- [ ] ⭐ 签订完整合同并核对后付款
	- [ ] 🔍 确认合同中写明婚纱品牌/款号、取还纱日期、物品清单、总价及违约条款
	- [ ] 将所有确认细节写入合同，确认无误后再付清款项
- [ ] 明确改尺寸与赔偿条款
	- [ ] 写清楚"具体需要**赔钱的污渍种类**，**破损赔偿上限**不超过租金的XX%"
	- [ ] 问清单：免费**改尺寸、复尺**次数
	- [ ] 问清修改费含不含在租金里
	- [ ] 确认一次修改免费还是全部自费
	- [ ] 合同写明修改次数与费用
	- [ ] 询问破损清洗费标准
- [ ] 确认租期超时政策
	- [ ] 算好租期确保覆盖婚礼日期和试装时间（一般**租3-5天**），问清超时收费标准

---

## 三、收尾（定纱后 + 取还纱 + 婚礼当天）

### 3.1 量体与改衣

- [ ] ⏰ 婚礼前安排量体并记录身体数据
	- [ ] 确认**量体时间**（婚礼前1个月），做最终复尺与确认
	- [ ] 记录三围（胸围，腰围，臀围）、肩宽、臂围等身体数据
	- [ ] 量体时携带**婚鞋和提臀裤**
- [ ] 确认改衣周期与免费修改尺寸政策
	- [ ] 确认**改衣周期**（一般1-2周）
	- [ ] 确认婚纱尺寸是否可以微调，修改是否**免费**
	- [ ] 确认免费修改尺寸**次数**和超出收费
	- [ ] 🔍 避坑：合同标注"免费修改至合身，不限次数"
- [ ] 问清婚礼前**多久可以再来试穿**、不合适能否**免费换款或改尺寸**

### 3.2 取纱与归还

- [ ] ⏰ 确认婚纱提前多久**取货**、最晚**归还**时间、超时计费标准
	- [ ] 明确**婚期**和婚纱**租赁**日期（一般是提前一天去取衣服，次日归还）
	- [ ] 确认能否提前1天取来试穿
- [ ] 提前沟通取衣安排与存放要求
	- [ ] 协商**提前发货并延长归还期限**
	- [ ] 确认取衣时婚纱是否会**清洗熨烫**，是否需要额外付**清洁费**
- [ ] 🔍 取还纱时**录像/签字**确认状态
	- [ ] **取纱**时拍摄360度视频留证
	- [ ] **还纱时**让店员签字确认"无破损"
	- [ ] 收货时在快递点全程录像开箱检查外包装

### 3.3 异地租纱特殊事项

- [ ] ⭐ 明确异地租纱邮费
- [ ] 🔍 收货/还货时录像检查款式、件数与状态
	- [ ] **发货前**视频确认**款式和件数**，尤其检查头纱、裙撑等**配件**是否齐全
	- [ ] **收到包裹后**录制开包视频并检查完整性
	- [ ] 收货当天**全程录像**开包检查，重点查看**脏污、破损和配件缺失**
	- [ ] 寄送的话，收到后第一时间在快递点**检查外包装**，全程录像开箱
	- [ ] 拿到婚纱后立即试穿，发现尺寸问题马上联系店家
	- [ ] 归还礼服时**同样录像**并选择**保价邮寄**
- [ ] 要求**租赁方**提供**送上门服务**或安排可靠人员收取包裹
- [ ] 收到婚纱后妥善熨烫与安置
	- [ ] 向商家索要婚纱熨烫注意事项（蒸汽温度等）
	- [ ] 收到婚纱后第一时间打开使其恢复蓬松
	- [ ] 准备礼服专用挂架和足够挂衣区
	- [ ] 主纱最好铺开放置在床或沙发上，注意礼服掉细金银闪粉的问题
- [ ] ⏰ 安排好异地取还婚纱时间
	- [ ] 提前一周左右到店**取婚纱或安排邮寄**（提前3-4天）
	- [ ] 婚礼**当天或第二天**顺丰打包寄回租赁方
- [ ] 异地租纱前反复确认尺寸
	- [ ] 婚礼前半个月到店量尺寸
	- [ ] 取纱当天再次量尺寸确认
	- [ ] 如果尺寸有出入，马上联系店家
	- [ ] 寄出前一周和店家反复确认好自己的准确尺码

### 3.4 婚礼当天管理

- [ ] ⏰ 婚礼**前一天**提前**安置与熨烫礼服**
	- [ ] 预留**一个下午时间**提前熨烫所有礼服
	- [ ] 评估是否提前将礼服放到婚礼酒店（注意财产安全）
- [ ] 指定**可靠人员**负责婚礼当天**礼服回收**
