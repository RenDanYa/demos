# 整合后待办



## 1、试纱前准备

### 1.1 身材版型认知

#### 1.1.1 身材类型确认

- [ ] 确认自己的身材类型（倒三角/矩形/沙漏/苹果/梨型）
- [ ] 明确自己最在意的身材点（腰、肩、手臂等）



#### 1.1.2 版型与款式筛选

- [ ] 根据身材类型筛选适合的婚纱版型
- [ ] 列出需要**避开的婚纱款式清单**


### 1.2 物品与个人形象

#### 1.2.1 穿戴物品准备

- [ ] 准备试纱鞋履与隐形眼镜
	- [ ] 准备隐形眼镜/美瞳（框架眼镜影响观感）
	- [ ] 带上婚鞋去试纱（鞋跟高度与婚礼当天一致）
	- [ ] 穿增高鞋代替高跟鞋试纱

#### 1.2.2 个人形象准备

- [ ] 试纱当天化淡妆与发型准备
	- [ ] 提前洗头发、化淡妆（底妆+眉毛+口红）
	- [ ] 盘发或扎马尾（披发会遮挡肩颈线条）
	- [ ] 试纱当天低发髻造型前往
	- [ ] 提前问询是否需要自带妆，如已定好化妆师可当天**妆纱同试**
- [ ] 试纱前身体护理与状态调整
	- [ ] 试纱前一天洗头洗澡、护肤、腋下/胳膊脱毛
	- [ ] 避开生理期以免不小心弄脏婚纱
	- [ ] 试纱前吃七分饱（空腹试到第三件就低血糖了，吃太饱穿婚纱又不好看）
	- [ ] 试纱前早睡不熬夜、少喝水


### 1.3 信息与计划


#### 一、前期准备（婚礼前 6-10 个月）

##### 1.1 确定基础信息
- [ ] **确定婚期** — 越早选择越多，避免喜欢的款式没档期
- [ ] **确定预算与心理价位** — 避免盲目去奢华店，了解高定品牌与普通婚纱价位区别
- [ ] **确定婚礼场地类型** — 室内可冲大拖尾/重工款；户外/草坪优先轻纱、简约款

##### 1.2 信息收集与店铺锁定
- [ ] 在社交平台收藏喜欢的款式，并**告知礼服师**
- [ ] 线上锁定 **2-3 家**心仪婚纱店铺和具体款式
- [ ] 在各大平台搜索当地知名婚纱店
- [ ] 根据婚礼舞台风格，针对性选择婚纱店
- [ ] 为每套衣服至少留一个**备选款式**
- [ ] 查阅品牌授权名单，确认婚纱店是否为正版授权（警惕低价引流工作室）
- [ ] 在小红书搜索 **3 家左右**婚纱店并查看真实客照

##### 1.3 提前沟通与功课
- [ ] 线上私信顾问，说清楚：**婚期、婚礼场地风格、心理预算、身材情况、心仪婚纱款式**
- [ ] 去试纱前列出要问的问题清单
- [ ] 向有经验的朋友收集试纱经历和建议
- [ ] 提前做功课（查好攻略再试纱）

---

#### 二、时间安排与预约

##### 2.1 试纱时间规划
- [ ] **第一次试纱**：婚礼前 **3-4 个月**，确定婚纱店和风格方向
  - 租赁婚纱：提前 **3-6 个月**试纱，旺季提前 **4-6 个月**
  - 定制婚纱：提前 **6-8 个月**试纱，中式礼服提前 **8-10 个月**
  - 热门日子/节假日：提前 **半年**预定
- [ ] **第二次试纱**：婚礼前 **1-2 个月**，结合最终身材和场布定稿选定婚纱

##### 2.2 预约执行
- [ ] 提前预约多家婚纱店（建议 **3-5 家**）
- [ ] 选择**工作日**（如周二下午）或**淡季**（如清明节前后）预约，避开周末高峰和节假日
- [ ] 选择**新款到店后**的时间段去试纱
- [ ] 提前 **1-3 天**确认预约，准时到达
- [ ] 提前 **1-2 周**预约并告知场地风格、预算和身材特点
- [ ] 出行前确认试纱档期和租赁档期
- [ ] 预留 **2-3 小时**试纱时间
- [ ] 预留 **1-2 次**到场机会用于调换款式或复尺
- [ ] 时间允许时：**上午试妆、下午带妆试纱**

##### 2.3 费用与政策确认
- [ ] 加客服询问试纱收费规则（免费件数、抵扣政策）
- [ ] 优先预约提供免费试纱的店家（一般**前三件免费**）
- [ ] 确认定完/下单后能否换款及是否需额外费用
- [ ] 提前询问中意款式的在店档期

---

#### 三、店铺筛选与考察

##### 3.1 线上初步筛选
- [ ] 核查品牌授权与婚纱店名单
- [ ] 优先选择品牌齐全、款式丰富的店面
- [ ] 根据名单联系小城市授权婚纱店

##### 3.2 实地考察对比（到店）
- [ ] 线下到婚纱门店实地查看婚纱实物
- [ ] 观察婚纱**新旧程度、做工、质感和干净程度**
- [ ] 确认婚纱店审美是否在线，是否真心推荐适合你的款式
- [ ] 提前了解婚纱店的套餐内容和潜在消费项
- [ ] 记录每家店的款式、价格和服务评价
- [ ] 对比多家婚纱店，考察款式数量、婚纱状态、价格区间
- [ ] 多跑几家婚纱店对比方案和套餐

---

#### 四、试纱当天执行

##### 4.1 到店沟通
- [ ] 进店先和礼服师明确需求：
  - 婚礼场地（室内/户外）
  - 身材痛点（肩宽/腰腹/副乳）
  - 风格偏好（极简、公主风、复古、鱼尾）— **别盲目试网红款！**
- [ ] 提前和礼服师说明预算，避免推荐超出预算的款式
- [ ] 携带**场地照片**和**婚礼策划定稿**去试纱

##### 4.2 选款与试穿
- [ ] 进店先**试自己选的款**，再听店员推荐（避免被带着试滞销款）
- [ ] 试纱时考虑婚礼整体布置风格和色调协调性
- [ ] 主动与店员沟通，尝试不同风格的婚纱
- [ ] 不同风格婚纱各选一件进行对比试穿

---

#### 五、穿搭准备（试纱日 & 婚礼日）

##### 5.1 提前采购
- [ ] 肉色/浅色**无痕内裤**
- [ ] **胸贴/乳贴**（主纱、敬酒服、晨袍用）
- [ ] 肉色**安全裤**（优先选有收腰提臀效果的）
- [ ] 肉色**收腹裤**
- [ ] **内衣**（秀禾服用 — 聚拢定型效果优于胸贴）

##### 5.2 试纱当天穿搭
- [ ] 上身：穿**抹胸**或贴好**胸贴**前往
- [ ] 下身：穿**肉色四角裤/打底裤**前往
- [ ] 试穿时确认礼服是否**透底**

##### 5.3 婚礼日搭配速查
| 礼服 | 内衣搭配 |
|------|----------|
| 主纱 | 胸贴/乳贴 + 收腹裤/安全裤 |
| 敬酒服 | 胸贴/乳贴 |
| 晨袍 | 胸贴/乳贴 |
| 秀禾服 | 内衣（聚拢定型）+ 安全裤 |

> 💡 **核心原则**：秀禾服穿内衣（定型效果最佳），其余礼服配胸贴。试纱日务必穿肉色打底裤，方便检查礼服透光问题。

---

#### 六、行程规划
- [ ] 规划试纱行程路线和时间安排


## 3、试纱中执行

### 3.1 到店沟通

#### 3.1.1 需求与场地沟通

- [ ] 提前与礼服师沟通婚礼场地、预算和风格需求
	- [ ] 提前确认婚礼场地类型（室内或户外）
	- [ ] 提前告知婚纱店婚礼场地和预算范围
	- [ ] 进店先和礼服师明确婚礼场地（室内一可冲大拖尾、重工款，户外/草坪优先轻纱、简约款）、身材痛点（肩宽/腰腹/副乳）、风格偏好（极简、公主风、复古、鱼尾，别盲目试网红款!）
	- [ ] 到店先和礼服师明确需求
	- [ ] 提前和礼服师说明预算，避免推荐超出预算的款式
	- [ ] 携带场地照片和婚礼策划定稿去试纱
- [ ] 试纱时结合自身风格主动选款
	- [ ] 试纱时考虑婚礼整体布置风格和色调协调性
	- [ ] 进店先试自己选的款，再听店员推荐（避免被带着试滞销款）
	- [ ] 主动与店员沟通，尝试不同风格的婚纱
	- [ ] 不同风格婚纱各选一件进行对比试穿



#### 3.1.2 试纱费与拍照

- [ ] 问清单：婚礼前是否支持免费换款、有无时间限制



#### 3.1.3 套餐内容与换款政策

- [ ] 确认套餐包含内容与换款升级政策
	- [ ] 确认是否有包含秀禾、敬酒服、伴郎伴娘服的套餐及性价比
	- [ ] 交定金预定后，若更换新款/其他款式是否可以调整
	- [ ] 问清楚后续更换款式是否需要加价及具体收费标准
	- [ ] 问清套餐里的衣服能否更换或加钱升级
	- [ ] 问清套餐价是否包含修改、清洗、头纱裙撑等配饰、运费
	- [ ] 确认套餐是否赠送伴郎伴娘服



#### 3.1.4 费用、押金与赔偿

- [ ] 确认隐形消费与全费用明细
	- [ ] 试纱前1-2天和婚纱店确认有无隐形消费（试纱费、改衣费、配饰费等）
	- [ ] 问清所有费用（试纱费、改衣费、配饰费、清洗费、押金）并写进合同
	- [ ] 确认婚纱归还是否有额外清洗费
- [ ] 确认婚纱破损/污渍赔偿标准
	- [ ] 确认归还时若出现轻微破损是否扣费及扣费标准
	- [ ] 确认婚礼当天婚纱破损或污渍的清理方式及赔偿金额
	- [ ] 问清破损赔偿怎么算、有上限吗


### 3.2 试穿技巧

#### 3.2.1 按身材选款

- [ ] 按身材特点与偏好风格选款
	- [ ] 确定偏好风格（干净简约还是华丽繁复）
	- [ ] 按版型试穿：小个子选A字款/短款，微胖选高腰A字/缎面简约，肩宽选一字肩/V领，避开无袖
	- [ ] 结合自身身材特点选款（领型、肩部设计、裙摆、材质）
- [ ] 多试不同风格并坚持个人喜好
	- [ ] 不用盲目跟风网红款
	- [ ] 各种款式都试一下，选择最适合自己的
	- [ ] 坚持自己喜欢的风格，不要被销售PUA
	- [ ] 多试风格，大胆沟通



#### 3.2.2 试穿动作测试

- [ ] 试穿时做走动、坐下、抬手、转身等动作测试舒适度，确认不勒腰、不踩裙边、不走光
- [ ] 试穿时仔细检查婚纱是否有破损、污渍、开线，配饰是否齐全
- [ ] 关注婚纱舒适度，确保行动自如


### 3.3 记录与决策

#### 3.3.1 拍照与视频记录

- [ ] 多角度拍摄试穿照片与视频留存
	- [ ] 每套婚纱多角度拍摄照片与视频（正面、侧面、背面、全身、走动、坐下），并试穿多种款式做对比，方便参考商量
	- [ ] 让别人帮拍视频（视频比照片更直观，能看清走动时的裙摆动态）
- [ ] 提前确认店内拍照/拍视频政策，将照片发给亲友或化妆师参考



#### 3.3.2 试穿数量控制

- [ ] 控制试穿数量与时间避免审美疲劳
	- [ ] 不要一次性试太多款（建议3-5件），避免审美疲劳
	- [ ] 控制试穿数量在3-5件（主纱、出门纱、敬酒服各 1-2 件），试太多会产生审美疲劳
	- [ ] 控制试纱时间在1-2小时内



#### 3.3.3 回家冷静决策

- [ ] 邀请审美同频的亲友陪同试纱
	- [ ] 只带1-2个审美在线、会说实话的陪同人员
	- [ ] 第一次试纱带老公、妈妈或闺蜜多人参考
	- [ ] 邀请1-2位审美在线的闺蜜或家人陪同
- [ ] 保留first look惊喜，试纱不带老公
	- [ ] 带闺蜜去试纱并提供参考建议，最好别带老公（保留first look惊喜）
- [ ] 大胆砍价，谈好低价保留聊天记录，避免后期涨价
- [ ] 试纱后不冲动当场下单，回家对比照片后再决定
	- [ ] 不冲动付定金，多对比几家
	- [ ] 绝不当场付定金

## 4、款式与服装套数确认

### 4.1 款式选择

#### 4.1.1 服装套数明确

- [ ] 确定婚礼所需服装套数（主纱、敬酒服、秀禾等）
- [ ] 按主纱→轻纱/迎宾纱→秀禾→敬酒服的顺序试纱



#### 4.1.2 款式风格筛选

- [ ] 明确品牌、版型与具体款式
	- [ ] 问清不同套餐的实物差异（品牌、新旧、面料、定制程度）
	- [ ] 在本地品牌集合店多试穿，明确品牌、版型和具体款式
	- [ ] 先锁定一套心仪婚纱，保留后期换款权利
	- [ ] 使用搜索引擎识图功能查询婚纱品牌和款式名称
	- [ ] 找到品牌官方社交媒体账号



#### 4.1.3 购买与租赁方案

- [ ] 确认单件租赁可行性及费用
	- [ ] 问清能否单租某一件、单租怎么算
	- [ ] 付定金或全款前**明确租赁款式**
- [ ] 确认西装与伴郎服购买/租赁方案
	- [ ] 租赁一套男士西装价格在1000-2000元左右，但租赁只能穿一次。如果买的话，这个价位能买一身质量不错的西装了，日后还能经常穿。所以我觉得男士西装买比较划算！
	- [ ] 确认伴郎服**自备或租赁**方案
- [ ] 私信品牌询问个人购买可能性


### 4.2 套餐套数

#### 4.2.1 套餐服装件数

- [ ] 确认套餐包含的具体服装件数
	- [ ] 确认套餐包含衣服套数（秀禾、敬酒服、伴郎伴娘服？）及配饰（头纱、裙撑、首饰等）是否另收费
	- [ ] 问清套餐具体包含哪几件衣服（出门纱/主纱/敬酒服/晨袍等）
	- [ ] 问清楚套餐是否包含新郎衣服、秀禾、敬酒服及是否全场通选（试纱当天好看的全要加钱）
	- [ ] 确认套餐内包含几套衣服，包不包含妈妈装和伴娘伴郎服，各有几件
	- [ ] 问好套餐内是否包含新郎秀禾、伴娘伴郎服
- [ ] 确认套餐加价规则与议价空间
	- [ ] 确认是否全场通选、有无分区加价
	- [ ] 在服装满意前提下争取更划算的套餐价格



#### 4.2.2 套餐配饰与服务

- [ ] 确认套餐包含的配饰及收费
	- [ ] 确认头纱、头冠、秀禾服、团扇等配饰是否免费附赠还是额外收费
	- [ ] 试婚纱时搭配头纱、头冠、手套看整体效果
	- [ ] 确认套餐是否包含头纱、裙撑、伴娘服等配饰
	- [ ] 问清套餐里的配饰是否真的免费（头纱、裙撑、首饰）
	- [ ] 确认租的婚纱包含哪些配饰（头纱、头饰、耳环、项链等）
	- [ ] 问清单：租赁价格是否包含头纱、手套、团扇等
	- [ ] 让礼服师列"免费配饰清单"，写清楚款式和使用时间
- [ ] 确认套餐升级与附加服务
	- [ ] 问清套餐能否升级、补差价规则
	- [ ] 咨询婚纱店是否提供试妆服务及套购优惠

## 5、费用与合同

### 5.1 费用确认

#### 5.1.1 租赁套餐费用

- [ ] 确定租赁预算并了解全部费用构成
	- [ ] 确定婚纱租赁的心理预算
	- [ ] 了解除租赁费外的其他费用（如押金）
	- [ ] 问清楚是否需要试纱费，下单后是否退还
- [ ] 明确定金、押金、尾款金额与退还规则
	- [ ] 定金最多交30%，确认可退或可转让，不要被忽悠交全款
	- [ ] 确认定金、押金金额是多少，何时退还，有无退还条件
	- [ ] 确认押金金额及退还方式
	- [ ] 问清定金比例、尾款支付时间（取纱时付还是还纱时付？）、取消婚礼定金能否退
	- [ ] 问清定金和押金金额、退还时间
	- [ ] 问清押金什么时候退、会扣钱吗
	- [ ] 确认付款流程（定金、押金、尾款分别什么时候付）
	- [ ] 确认婚纱归还后多久退押金
	- [ ] 合同写"还纱后X个工作日内退押金，无正当理由不得扣钱"
- [ ] 与销售议价/讨价还价，争取优惠与赠品
	- [ ] 尝试协商赠送伴娘伴郎服、晨袍、饰品等权益



#### 5.1.2 试纱费

- [ ] 问清试纱费收费标准与抵扣规则
	- [ ] 问清试纱费能否免除（当天定下或多人同行时）
	- [ ] 问清免费试纱是否有数量限制
	- [ ] 问清试纱是否限时、超时怎么算
	- [ ] 问清试纱费及是否可全额抵扣并要求写进收据
	- [ ] 问清试纱费怎么收费（按件数还是按次数，是否抵扣租金）（可以先去不限件数的地方试，大概确定好风格后如果店里没有心仪的款，可以再去论件数收费的店里试）
	- [ ] 要求写进收据："试纱费XX元，抵扣婚纱租金"



#### 5.1.3 附加费用

- [ ] 确认无清洗费、超时费、上门额外费用


### 5.2 合同条款

#### 5.2.1 合同内容确认

- [ ] 签订完整合同并核对后付款
	- [ ] 确认合同中写明婚纱品牌/款号、取还纱日期、物品清单、总价及违约条款
	- [ ] 将所有确认细节写入合同
	- [ ] 合同确认无误后再付清款项



#### 5.2.2 改尺寸与赔偿条款

- [ ] 明确改尺寸与赔偿条款
	- [ ] 写清楚"具体需要赔钱的污渍种类，破损赔偿上限不超过租金的XX%"
	- [ ] 问清单：免费改尺寸、复尺次数
	- [ ] 询问破损清洗费标准



#### 5.2.3 定金、尾款与档期变更

- [ ] 确认婚期变动与租期超时政策
	- [ ] 问清婚期改了能否免费换档期、提前多久通知
	- [ ] 问清单：若婚期临时变动，订单是否可以延期/改期
	- [ ] 算好租期确保覆盖婚礼日期和试装时间（一般租3-5天），问清超时收费标准

## 6、定纱后事项

### 6.1 量体与改衣

#### 6.1.1 量体安排

- [ ] 婚礼前安排量体并记录身体数据
	- [ ] 婚礼前1个月左右做最终复尺与确认
	- [ ] 确认量体时间（婚礼前1-2天）
	- [ ] 记录三围、肩宽、臂围等身体数据
	- [ ] 量体时携带婚鞋和提臀裤



#### 6.1.2 改衣跟进

- [ ] 确认改衣周期与免费修改尺寸政策
	- [ ] 确认改衣周期（一般1-2周），赶婚期需提前安排
	- [ ] 确认婚纱尺寸是否可以微调，修改是否免费
	- [ ] 确认婚纱租赁是否包含修改尺寸服务
	- [ ] 确认免费修改尺寸次数和超出收费
	- [ ] 确认什么时候去试最终尺寸，是否可以免费修改尺寸
	- [ ] 问清改尺寸是否全免费、能改几次（“腰围、肩带、裙摆修改都免费吗？改到合身最多能改几次？”）
	- [ ] 避坑：合同标注"免费修改至合身，不限次数"
- [ ] 问清婚礼前多久可以再来试穿、不合适能否免费换款或改尺寸


### 6.2 取纱与归还

#### 6.2.1 取还时间确认

- [ ] 确认婚纱提前多久取货、最晚归还时间、超时计费标准
	- [ ] 确认取婚纱提前几天取，婚礼结束几天归还
	- [ ] 明确婚期和婚纱租赁日期（一般是提前一天去取衣服，次日归还）
- [ ] 提前沟通取衣安排与存放要求
	- [ ] 若确定要租，提前问清楚取衣时间、存放要求
	- [ ] 提前2周左右提醒店家使用时间，避免排期冲突
	- [ ] 协商提前发货并延长归还期限
	- [ ] 确认取衣时婚纱是否会清洗熨烫，是否需要额外付清洁费



#### 6.2.2 取还状态留证

- [ ] 取还纱时录像/签字确认状态（还纱时让店员签字确认"无破损"）
	- [ ] 取纱时拍摄360度视频留证
	- [ ] 收货时在快递点全程录像开箱检查外包装

## 7、异地租纱

### 7.1 合同与费用

#### 7.1.1 邮费与押金条款

- [ ] 明确异地租纱邮费与押金条款
	- [ ] 在租赁合同中明确来回邮费由谁承担
	- [ ] 在合同签订时明确异地租纱押金金额（警惕高于套餐价）、收取依据、扣款规则、返还日期和途径
	- [ ] 要求店家在签约阶段提前说明押金条款，避免婚礼前临时通知
	- [ ] 确认租赁条款：是否支持异地租赁，邮寄还是自取，是否需要额外收取异地费或清理费
	- [ ] 预算婚纱邮寄运费成本
- [ ] 选择高铁两小时圈内的异地租赁城市



#### 7.1.2 租期与赔偿

- [ ] 费用弄清楚：定金、尾款、清洁费、损坏赔偿标准、修改尺寸是否收费，写进合同


### 7.2 物流与安置

#### 7.2.1 寄送与收货

- [ ] 收货/还货时录像检查款式、件数与状态
	- [ ] 发货前视频确认款式和件数，尤其检查头纱、裙撑等配件是否齐全
	- [ ] 收到包裹后录制开包视频并检查完整性
	- [ ] 收货当天全程录像开包检查，重点查看脏污、破损和配件缺失
	- [ ] 寄送的话，收到后第一时间在快递点检查外包装，全程录像开箱
	- [ ] 拿到婚纱后立即试穿，发现尺寸问题马上联系店家
	- [ ] 拿到婚纱后要立刻试穿
	- [ ] 归还礼服时同样录像并选择保价邮寄
- [ ] 要求租赁方提供送上门服务或安排可靠人员收取包裹



#### 7.2.2 熨烫与安置

- [ ] 收到婚纱后妥善熨烫与安置
	- [ ] 向商家索要婚纱熨烫注意事项（蒸汽温度等）
	- [ ] 收到婚纱后第一时间打开使其恢复蓬松
	- [ ] 准备礼服专用挂架和足够挂衣区
	- [ ] 主纱最好铺开放置在床或者沙发上，还得注意礼服掉细金银闪粉的问题


### 7.3 取还安排

#### 7.3.1 异地取还时间

- [ ] 安排好异地取还婚纱时间
	- [ ] 提前一周左右到店取婚纱或安排邮寄（提前3-4天）
	- [ ] 婚礼当天或第二天顺丰打包寄回租赁方



#### 7.3.2 取纱尺寸确认

- [ ] 异地租纱前反复确认尺寸
	- [ ] 婚礼前半个月到店量尺寸
	- [ ] 取纱当天再次量尺寸确认
	- [ ] 如果尺寸有出入，马上联系店家
	- [ ] 寄出前一周和店家反复确认好自己的准确尺码
