## 1、预算规划

### 1.1 预算决策

#### 1.1.1 租赁方式与金额

- [ ] 根据预算决定租赁还是定制（5000以内租赁，以上定制）
- [ ] 婚纱礼服-4500
- [ ] 租赁婚纱-5000
- [ ] 租婚纱-2300

## 2、选店与比价

### 2.1 店家筛选

#### 2.1.1 初步沟通与比价

- [ ] 多找几家婚纱店初步沟通比价（3k档位选择较少，需提前筛选）
- [ ] 选择线上沟通积极、不轰炸式推销的店家到店试纱
- [ ] 对比多家婚纱店价格，不要轻信当天限时优惠套路

## 3、试纱流程

### 3.1 试纱准备

#### 3.1.1 时间与妆容准备

- [ ] 做好试纱前准备
	- [ ] 试纱前预留 2-3 小时充足时间
	- [ ] 试纱前化淡妆或确认店家是否赠送淡妆体验
	- [ ] 提前确定婚礼当天发型方案（主纱/秀禾配高盘发，敬酒服配公主头）
	- [ ] 预约最终试纱并带妆试纱

### 3.2 款式试穿

#### 3.2.1 主纱与礼服试穿

- [ ] 利用免费试纱额度多试不同风格主纱（如爆闪、缎闪）进行对比
- [ ] 秀禾和敬酒服也安排试穿确认
- [ ] 试纱时关注舒适度细节（如亮片是否扎皮肤），及时与店家沟通解决方案

## 4、签约与合同

### 4.1 套餐确认

#### 4.1.1 附加服务与性价比

- [ ] 确认租赁套餐是否赠送新郎秀禾、伴郎伴娘服等附加服务
- [ ] 综合评估性价比后再下定

### 4.2 合同审核

#### 4.2.1 押金与赔偿条款

- [ ] 审核合同押金与赔偿条款
	- [ ] 签约前问清押金退还条件
	- [ ] 拍照留档租赁时的原始状态
	- [ ] 合同写明"无重大损坏全额退还押金"
	- [ ] 仔细审核押金条款，避免过高押金（一般婚纱定金几千块即可）
	- [ ] 确认合同中关于污渍和破损的赔偿标准是否合理

#### 4.2.2 修改费用

- [ ] 确认修改费用相关条款
	- [ ] 问清修改费含不含在租金里
	- [ ] 确认一次修改免费还是全部自费
	- [ ] 合同写明修改次数与费用

#### 4.2.3 取还时间与超时费

- [ ] 确认取还时间与超时费用
	- [ ] 问清租赁时长是否够用
	- [ ] 确认租期安排（婚礼前一天取，婚礼后一天还）
	- [ ] 超时费标准写进合同
	- [ ] 确认能否提前1天取来试穿
	- [ ] 确认婚礼第二天还还是当天还

#### 4.2.4 换款与退款

- [ ] 拒绝合同中"全额不退款"的霸王条款（退款一般最多扣除40%的费用）
- [ ] 确认免费换款次数和试纱费收费标准

#### 4.2.5 合同形式

- [ ] 确保签订书面合同，避免口头承诺
