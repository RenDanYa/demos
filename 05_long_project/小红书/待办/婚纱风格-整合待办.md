## 一、前期准备（试纱前规划与自测）

### 1.1 预算与风格方向

- [ ] ⭐ **提前规划婚纱与新郎服装的整体预算**
- [ ] 参考评论区经验（如"不漏肩膀的比一字肩好"）调整选款方向
- [ ] 选择深V领或大领口分散上半身视觉重心

### 1.2 身材自测与选款原则

- [ ] ⭐ **确认自身身材类型**，逐项自测并记录
	- [ ] 确认是否属于梨形身材（胯宽、大腿粗、腰细；判断胯宽与大腿围是否明显大于肩宽）
	- [ ] 确认是否属于苹果型身材（腰腹肉多、四肢相对细；判断腰腹是否为主要脂肪集中区域）
	- [ ] 确认是否属于沙漏型身材（胸臀丰满、腰细；判断腰臀比是否明显，腰明显细于胸臀）
	- [ ] 确认是否属于H型身材（肩腰臀接近、腰线不明显；判断肩腰臀围是否接近、缺乏明显腰线）
	- [ ] 确认是否属于倒三角身材（肩宽、胯窄）
	- [ ] 确认身高是否属于小个子范畴
- [ ] 根据自测身材类型，整理"适合/避免"款式清单
	- [ ] 避免直筒或oversize款掩盖腰线（H型）
	- [ ] 选择腰部有装饰或明显收腰设计的款式（H型）
	- [ ] 避免肩部复杂装饰或夸张袖型（倒三角）
	- [ ] 避免过于宽松或直筒款，以免掩盖身材优势
	- [ ] 确认是否需要遮手臂肉肉同时保留精致感
- [ ] 根据自身身材类型，列出3-5个适合的婚纱关键词
