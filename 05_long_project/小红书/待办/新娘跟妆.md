# 整合后待办


## 一、前期准备（婚礼前 6-12 个月）

### 1.1 婚礼风格与妆造需求确认

- [ ] **评估五官特点** — 明确需修饰角度和可放大优势
- [ ] **收集妆造灵感图** — 明确偏好的色调、风格和适合方向

### 1.2 妆造需求资料准备

- [ ] ⭐ **制作并发送跟妆诉求资料给化妆师**
	- [ ] 制作跟妆诉求PPT（含婚纱上身照、身高体重、五官特点、化妆习惯、意向造型妆容、不喜欢的妆造）
	- [ ] 找好参考图并提前发给化妆师，附基本情况、自然照片和妆造需求
	- [ ] 整理中式造型需求（妆容、头饰、耳饰、团扇等）并附参考图
	- [ ] 整理敬酒造型需求（风格、发型、花草点缀等）并附参考图

### 1.3 时间规划

- [ ] 规划试妆行程，一天最多安排两家，可与试纱安排在同一天，条件允许时约化妆师到婚纱店同步试妆试纱

### 1.4 筛选化妆师

- [ ] **多渠道寻找化妆师/店铺**
	- [ ] 从各平台搜索附近可跟妆店铺（优先婚纱店、化妆培训、摄影店）
	- [ ] 小红书上搜"地点+新娘化妆师"
	- [ ] 咨询婚纱店是否有合作化妆师
	- [ ] 从各平台评价和朋友打听中对比口碑

- [ ] **按预算、距离、规模初筛化妆师**
	- [ ] 挑选多家有规模的店铺并联系，小店找创始人、大店找经理及总监级
	- [ ] 低于1000的尽量不考虑，筛选到5家以内
	- [ ] 选择距离婚礼酒店近、性价比高的化妆师/店铺
	- [ ] 线上带图问价，话不投机立刻换

- [ ] 电话沟通无问题后实地考察店铺

- [ ] 🔍 **核查化妆师作品真实性与审美匹配度**
	- [ ] 网上查看化妆师真实客片/作品集，确认作品为本人出品
	- [ ] 让化妆师发实际案例原图（不要精修照），将作品与本人及价位对应
	- [ ] 根据实际案例确认审美是否一致，确认化妆师擅长风格及往期作品
	- [ ] 提前拿到化妆师资料，查看过往案例和风格
	- [ ] 亲自试妆比较等级划分，不盲目相信价位等级

### 1.5 沟通确认清单（签约前确认）

- [ ] 🔍 **确认档期**

- [ ] 🔍 **确认套餐价位与服务范围**
	- [ ] 确认跟妆套餐价位及包含的妆造套数
	- [ ] 确认新娘化妆跟妆费用是否另算及具体价格
	- [ ] 确认跟妆费用怎么算（包天/按小时/按造型数量）、是否全天跟妆补妆
	- [ ] 确认全程跟妆、半程跟妆、早妆分别多少钱
	- [ ] 确认化妆和换妆需要多长时间、是否能配合礼服适当修改
	- [ ] 确认凌晨化妆是否额外收费、套餐工作时长及加时费

- [ ] 🔍 **确认隐形消费与耗材**
	- [ ] 确认套餐是否包含头饰头纱、耳环、项链、秀禾团扇等配饰
	- [ ] 确认是否提供身体素颜霜、高光闪粉、精灵耳贴、双眼皮贴、假睫毛等耗材

- [ ] 🔍 **确认人员妆造范围与费用**

	- [ ] 确认不送是否额外收费、价格包含几人

- [ ] 🔍 **确认试妆方案与费用**

	- [ ] 确认跟妆是否可试妆及服务时长
	- [ ] 确认试妆和婚礼当天是否为同一个化妆师，不满意能否更换
	- [ ] 跟妆提前试妆并确认风格
	- [ ] 新娘：试妆并确定妆面
	- [ ] 预约专业化妆师试妆（可节省眉弓骨+山根等医美费用）
	- [ ] 确认**每套衣服可以试多少个造型**、不满意是否可以多试
	- [ ] 确认一共包含**几套造型**，超出造型是否额外加钱
	- [ ] 确认化妆品品牌（是否一线品牌），敏感肌是否可自带，要求拍摄化妆台

- [ ] 🔍 **确认合同付款与风险保障**
	- [ ] 确认定金何时交
	- [ ] 确认付款流程及尾款是否可在婚礼结束后结算
	- [ ] 确认近期优惠活动及合作婚纱店/婚庆公司是否有额外折扣
	- [ ] 确认化妆时间紧或婚礼当天临时有事时的补救措施

- [ ] 🔍 **确认异地交通食宿**（异地婚礼适用）
	- [ ] 确认化妆师交通费是否实报实销及是否需要安排食宿

	- [ ] 确认异地跟妆的早起/晚结束加班费及服务内容

## 二、执行中（试妆当天）

### 2.1 试妆前准备

- [ ] ⏰ 试妆前一周做好**基础保湿**，不尝试新的功效型护肤品
- [ ] ⏰ 试妆前一天**不洗头**，带好美瞳、胸贴，只做基础护肤
- [ ] 试妆当天**精简护肤**避免搓泥
- [ ] 随身携带眼唇卸妆液、卸妆湿巾等用品
- [ ] 给新郎也约个试妆
- [ ] 确认新娘需要提前准备什么（提前与化妆师沟通确认）
- [ ] 试妆后敷舒缓补水面膜修复皮肤

### 2.2 试妆现场沟通

- [ ] 化妆过程中主动沟通喜好、避雷点和调整要求，及时反馈每一步感受
- [ ] 🔍 试妆时考察化妆师性格、沟通能力和态度是否耐心顺畅
- [ ] 🔍 试妆时观察妆容与手法是否喜欢、是否熟练轻柔

### 2.3 妆容细节检查

- [ ] 🔍 **重点检查底妆、眉毛和眼妆细节**
	- [ ] 检查底妆是否暗沉假面卡粉、细节处理是否到位
	- [ ] 检查眉毛是否根根分明、有无糊成一团
	- [ ] 检查眼妆是否显气质、真假睫毛是否分层或融合自然
	- [ ] 检查睫毛是否有苍蝇腿

### 2.4 发型与造型检查

- [ ] 🔍 **重点检查发型与头饰细节**
	- [ ] 检查发型碎发情况及颅顶高度是否足够
	- [ ] 检查发型是否显头小显脸小、头饰能否试戴
	- [ ] 观察配饰与造型是否齐全干净、风格选择是否多样

- [ ] **造型确认**
	- [ ] 重点试主纱妆和秀禾妆
	- [ ] 多试几个造型，确认晨袍/秀禾/主纱/敬酒服造型
	- [ ] 基本确定化妆师后，将每套婚纱、妆容和发型一起试一遍再敲定

### 2.5 动态测试

- [ ] 🔍 **试妆后进行动态与镜头测试**
	- [ ] 走动、抬头、低头、鞠躬，测试发饰和发髻牢固度
	- [ ] 用原相机拍半身照，检查妆容自然度和整体比例
	- [ ] 用手机录一段15秒视频，检查大笑、皱眉、假装流泪时的妆面状态
