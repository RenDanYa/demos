# 整合后待办

> **标签说明**：⏰ 关键时间节点 ｜ ⭐ 必备项 ｜ 🔍 关键检查点
>
> **流程阶段**：一、前期准备（婚礼前 6-12 个月）→ 二、执行中（婚礼前 1-6 个月）→ 三、收尾（婚礼前 1 个月 ~ 婚礼当天及婚后）
>
> **排序规则**：同一子阶段内，带时间锚点的待办按时间顺序排列（由远及近），无时间锚点的待办置于其后

## 一、前期准备（婚礼前 6-12 个月）

### 1.1 确定婚期与整体规划

- [ ] ⏰⭐ **确定婚期** — 越早选择越多，避免喜欢的没档期（婚前 8-12 个月）
- [ ] ⭐ 根据自身情况制定 90 天备婚流程计划
- [ ] 新郎：预估男方宾客数量
- [ ] 向身边已婚朋友收集经验和建议，完善备婚清单

### 1.2 预算规划

#### 1.2.1 整体预算

- [ ] ⭐ **确定预算与心理价位** — 确定心理价位，避免盲目去奢华店
- [ ] 确认新郎西服、婚纱礼服、敬酒服、美甲预算
- [ ] 确认双方父母衣服、新娘新郎新衣服预算
- [ ] 确认上车礼、梳头礼、开口礼、伴郎伴娘礼预算
- [ ] 确定伴手礼预算和数量

#### 1.2.2 四大金刚预算

- [ ] 确认摄影、主持、化妆预算
- [ ] 确认四大金刚单项报价及明细

#### 1.2.3 婚纱礼服预算

- [ ] 确认**婚纱礼服租赁价格**及换款政策

#### 1.2.4 婚礼布置预算

- [ ] 确认婚房装饰品预算

#### 1.2.5 宾客与餐饮预算

- [ ] 新郎：预定喜糖、喜酒、喜宴

### 1.3 酒店与场地预订

- [ ] ⏰⭐ **确定场地** — 订婚宴确定婚礼时间后立即预订酒店，尽早预订婚礼酒店场地
- [ ] 两人一起：确定婚礼形式、风格、主题，确定酒店
- [ ] 新郎：挑选酒店
- [ ] 和双方父母确定大概宴请人数、宴会厅和桌数
- [ ] 新郎：与酒店沟通桌数、备桌及其他事宜
- [ ] 确定婚礼方案（鲜花、甜品台、桌数等）
- [ ] 两人一起：与酒店沟通婚礼流程等

### 1.4 婚庆公司筛选

- [ ] ⭐ 婚庆确定后再挑选四大金刚，不要未定婚庆就急着定
- [ ] 通过已婚朋友或当地推荐筛选婚庆公司
- [ ] 请一位婚礼管家全程把控
- [ ] 新郎：挑选婚庆策划

### 1.5 婚纱礼服初步规划（身材分析与版型选择）

- [ ] ⏰ 中式礼服提前 8-10 个月试纱
- [ ] ⏰ 定制婚纱提前 6-8 个月试纱；婚期前 6-8 个月开始试纱，热门日子提前半年预定
- [ ] ⏰ 租赁婚纱提前 3-6 个月试纱，旺季提前 4-6 个月
- [ ] 确认自己的身材类型（倒三角/矩形/沙漏/苹果/梨型）
- [ ] 明确自己最在意的身材点（腰、肩、手臂等）
- [ ] 根据身材类型筛选适合的婚纱版型
- [ ] 列出需要避开的婚纱款式清单
- [ ] 按版型试穿：小个子选 A 字款/短款，微胖选高腰 A 字/缎面简约，肩宽选一字肩/V 领，避开无袖
- [ ] 不用盲目跟风网红款
- [ ] **提前在社交平台收藏喜欢的款式**

### 1.6 个人形象管理启动

- [ ] 制定减肥计划及最佳体重目标
- [ ] 开始健身和美容护理
- [ ] 体态训练：瘦肚、瘦背、直角肩、瘦腰
- [ ] 新娘：开始身材和皮肤管理

## 二、执行中（婚礼前 1-6 个月）

### 2.1 婚纱试纱与定纱

#### 2.1.1 试纱前准备（时间锚点排序）

- [ ] ⏰⭐ **第一次试纱**：婚礼前 3-4 个月，确定婚纱店和风格方向
- [ ] ⏰⭐ **第二次试纱**：婚礼前 1-2 个月，结合最终身材和场布定稿选定婚纱
- [ ] ⏰ 提前 1-2 周预约并告知场地风格、预算和身材特点
- [ ] ⏰ 试纱前 1-2 天和婚纱店确认有无隐形消费（试纱费、改衣费、配饰费等）
- [ ] ⏰ 试纱前一天洗头洗澡、护肤脱毛（提前腋下脱毛）
- [ ] 提前预约多家婚纱店（建议 3-5 家），选择工作日（如周二下午）去试纱，尽量避开周末高峰
- [ ] 规划试纱行程路线和时间安排
- [ ] 选择新款到店后的时间段去试纱
- [ ] 对比多家婚纱店，考察款式数量、婚纱状态、价格区间
- [ ] 确认婚纱店审美是否在线，是否真心推荐适合你的款式
- [ ] 两人一起：试纱
- [ ] 去试纱前列出要问的问题清单
- [ ] 向有经验的朋友收集试纱经历和建议
- [ ] 提前问询是否需要自带妆，如已定好化妆师可当天**妆纱同试**

#### 2.1.2 试纱物品准备

- [ ] 准备胸贴/乳贴（1-2 副备用），带裸色无痕胸贴（Nubra）
- [ ] 准备肉色安全裤（优先选有收腰提臀效果的）
- [ ] 准备防磨脚贴（试穿婚鞋后准备）
- [ ] 准备新娘当日穿戴包（隐形胸贴、备用丝袜、防滑贴、安全别针、发夹）
- [ ] 带上婚鞋去试纱（鞋跟高度与婚礼当天一致）
- [ ] 带一双与婚礼当天高度相近的高跟鞋

#### 2.1.3 个人形象准备

- [ ] 腋下/胳膊脱毛
- [ ] 化淡妆（底妆+眉毛+口红），戴隐形眼镜/美瞳
- [ ] 盘发或扎马尾（披发会遮挡肩颈线条）
- [ ] 近视者佩戴自然舒适的美瞳
- [ ] 试纱前吃饭七分饱，避免小肚腩
- [ ] 避开生理期以免不小心弄脏婚纱

#### 2.1.4 到店沟通

- [ ] 到店先和礼服师明确需求：婚礼场地（室内可冲大拖尾/重工款，户外/草坪优先轻纱/简约款）、身材痛点（肩宽/腰腹/副乳）、风格偏好（极简/公主风/复古/鱼尾，别盲目试网红款）
- [ ] 提前告知婚纱店婚礼场地和预算范围
- [ ] 提前和礼服师说明预算，避免推荐超出预算的款式
- [ ] 提前收藏喜欢的款式并**告知礼服师**
- [ ] 确定偏好风格（干净简约还是华丽繁复）
- [ ] 确认有哪些风格并索要客片参考
- [ ] 确认风格可私人订制还是固定拍摄样式
- [ ] 确认所有风格挑选是否免费
- [ ] 礼服馆需要安排试衣间和礼服师
- [ ] 各种款式都试一下，选择最适合自己的

#### 2.1.5 试纱费用确认

- [ ] 🔍 问清试纱费收费标准（按件/按类型/按次）、能否免除（当天定下或多人同行时）、能否全额抵扣套餐价、是否限时及超时怎么算、免费试纱是否有数量限制，要求写进收据
- [ ] 🔍 确认试纱是否收费，下单后能否抵扣套餐费用 / 是否退还

#### 2.1.6 服装套数与配饰确认

- [ ] 🔍 确认套餐具体包含哪几件衣服（出门纱/主纱/敬酒服/晨袍等），是否有包含秀禾、敬酒服、伴郎伴娘服的套餐及性价比
- [ ] 确定秀禾款式、敬酒服款式、迎宾纱款式
- [ ] 确定婚礼所需服装套数（主纱、敬酒服、秀禾等）
- [ ] 控制试穿数量在 3-5 件（主纱、出门纱、敬酒服各 1-2 件），试太多会产生审美疲劳
- [ ] 新娘：选婚纱礼服及配饰
- [ ] 🔍 确认参观的婚纱、饰品是否都可以随便选
- [ ] 🔍 问清套餐价是否包含修改、清洗、配饰、运费
- [ ] 🔍 确认套餐是否包含头纱、裙撑、伴娘服等配饰
- [ ] 🔍 确认套餐包含衣服套数及配饰（头纱、裙撑、首饰等）是否另收费
- [ ] 🔍 确认租的婚纱包含哪些配饰（头纱、头饰、耳环、项链等）
- [ ] 确认新娘**跟妆服务**包含人数（是否含妈妈/伴娘）
- [ ] 准备新娘当日仪式包（头纱、手套、首饰袋、敬茶杯、改口红包）

#### 2.1.7 升级与单租

- [ ] 🔍 问清套餐里的衣服能否更换或加钱升级、能否单租某一件及怎么算、套餐能否升级及补差价规则

#### 2.1.8 陪同选择

- [ ] 只带 1-2 个审美在线、会说实话的陪同人员
- [ ] 第一次试纱带老公、妈妈或闺蜜多人参考
- [ ] 带上闺蜜一起提供参考建议，最好别带老公（保留 first look 惊喜）
- [ ] 最后一次确认试纱不带老公，保留 first look 惊喜

#### 2.1.9 试穿技巧

- [ ] 试穿后测试能否自然走路、坐下、不用憋气；走动、转身、坐下、抬手测试舒适度（肩带是否滑落、腰腹是否勒人、裙摆会不会绊脚、是否踩裙边、是否走光）
- [ ] 进店先试自己选的款，再听店员推荐（避免被带着试滞销款）
- [ ] 试穿时仔细检查婚纱是否有破损、污渍、开线，配饰是否齐全
- [ ] 控制试纱时间在 1-2 小时内

#### 2.1.10 拍照留存

- [ ] 试穿时拍正面、侧面、背面照片和视频留存对比，自己用手机多角度拍照留底，方便回家冷静对比
- [ ] 提前确认店内能否拍照/拍视频留存参考
- [ ] 确认拍照是否需包工作人员午餐

#### 2.1.11 合同条款与砍价

- [ ] 🔍 **签订完整合同**：确认合同中写明婚纱品牌/款号、取还纱日期、物品清单、总价及违约条款
- [ ] 🔍 问清定金比例、尾款支付时间（取纱时付还是还纱时付）、取消婚礼定金能否退
- [ ] 🔍 问清婚期改了能否免费换档期、提前多久通知
- [ ] 🔍 确认轻微磨损/污渍赔偿标准及具体赔偿金额
- [ ] 🔍 确认婚礼当天婚纱破损或污渍的清理方式及赔偿金额
- [ ] 🔍 确认付款流程（定金、押金、尾款分别什么时候付）及婚纱归还后多久退押金
- [ ] 🔍 警惕低价引流工作室，确认是否正版授权
- [ ] 🔍 确认是否全场通选、有无分区加价
- [ ] 🔍 确认无清洗费、超时费、上门额外费用
- [ ] 将赠送的产品和沟通细节写进合同
- [ ] 问清所有费用（试纱费、改衣费、配饰费、清洗费、押金）并写进合同
- [ ] 交定金预定后，若更换新款/其他款式是否可以调整
- [ ] 确认婚期临时变动能否延期
- [ ] 不着急付定金，警惕"价格只保留今天"等销售话术
- [ ] 不透露自己的预算给对方
- [ ] 让谈判强势的一方出面砍价，通常可砍 500-1000 元
- [ ] 看高价套餐争取按预算价拿下（如 6000 预算看 7000 套餐）
- [ ] 记录每家店的款式、价格和服务评价
- [ ] 提前了解婚纱店的套餐内容和潜在消费项
- [ ] 问清不同套餐的实物差异（品牌、新旧、面料、定制程度）
- [ ] 不冲动付定金，多对比几家
- [ ] 保留谈价聊天记录避免后期涨价
