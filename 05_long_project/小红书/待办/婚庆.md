## 一、前期准备（婚礼前 6-12 个月）

### 1.1 确定婚期与整体规划

- [ ] ⏰⭐ **确定婚期** — 越早选择越多，避免喜欢的没档期（婚前 8-12 个月）
- [ ] ⭐ 根据自身情况制定 90 天备婚流程计划
- [ ] 新郎：预估男方宾客数量
- [ ] 向身边已婚朋友收集经验和建议，完善备婚清单

### 1.2 预算规划

#### 1.2.1 整体预算

- [ ] ⭐ **确定预算与心理价位** — 确定心理价位，避免盲目去奢华店
- [ ] 确认新郎西服、婚纱礼服、敬酒服、美甲预算
- [ ] 确认双方父母衣服、新娘新郎新衣服预算
- [ ] 确认上车礼、梳头礼、开口礼、伴郎伴娘礼预算
- [ ] 确定伴手礼预算和数量

#### 1.2.2 四大金刚预算

- [ ] 确认摄影、主持、化妆预算
- [ ] 确认四大金刚单项报价及明细

#### 1.2.3 婚纱礼服预算

- [ ] 确认**婚纱礼服租赁价格**及换款政策

#### 1.2.4 婚礼布置预算

- [ ] 确认婚房装饰品预算

#### 1.2.5 宾客与餐饮预算

- [ ] 新郎：预定喜糖、喜酒、喜宴

### 1.3 酒店与场地预订

- [ ] ⏰⭐ **确定场地** — 订婚宴确定婚礼时间后立即预订酒店，尽早预订婚礼酒店场地
- [ ] 两人一起：确定婚礼形式、风格、主题，确定酒店
- [ ] 新郎：挑选酒店
- [ ] 和双方父母确定大概宴请人数、宴会厅和桌数
- [ ] 新郎：与酒店沟通桌数、备桌及其他事宜
- [ ] 确定婚礼方案（鲜花、甜品台、桌数等）
- [ ] 两人一起：与酒店沟通婚礼流程等

### 1.4 婚庆公司筛选

- [ ] ⭐ 婚庆确定后再挑选四大金刚，不要未定婚庆就急着定
- [ ] 通过已婚朋友或当地推荐筛选婚庆公司
- [ ] 请一位婚礼管家全程把控
- [ ] 新郎：挑选婚庆策划

### 1.5 婚纱礼服初步规划（身材分析与版型选择）

- [ ] ⏰ 中式礼服提前 8-10 个月试纱
- [ ] ⏰ 定制婚纱提前 6-8 个月试纱；婚期前 6-8 个月开始试纱，热门日子提前半年预定
- [ ] ⏰ 租赁婚纱提前 3-6 个月试纱，旺季提前 4-6 个月
- [ ] 确认自己的身材类型（倒三角/矩形/沙漏/苹果/梨型）
- [ ] 明确自己最在意的身材点（腰、肩、手臂等）
- [ ] 根据身材类型筛选适合的婚纱版型
- [ ] 列出需要避开的婚纱款式清单
- [ ] 按版型试穿：小个子选 A 字款/短款，微胖选高腰 A 字/缎面简约，肩宽选一字肩/V 领，避开无袖
- [ ] 不用盲目跟风网红款
- [ ] **提前在社交平台收藏喜欢的款式**

### 1.6 个人形象管理启动

- [ ] 制定减肥计划及最佳体重目标
- [ ] 开始健身和美容护理
- [ ] 体态训练：瘦肚、瘦背、直角肩、瘦腰
- [ ] 新娘：开始身材和皮肤管理

## 二、执行中（婚礼前 1-6 个月）

### 2.2 四大金刚确认与沟通

#### 2.2.1 四大金刚总览

- [ ] ⏰ 尽早预订四大金刚（摄影、摄像、化妆、主持）
- [ ] 两人一起：确定主持人、摄影摄像、化妆师
- [ ] 🔍 确认婚礼当天各供应商是一个人还是有自己的团队（督导、音响助手等），是否需要增加额外费用

#### 2.2.2 摄影服务

- [ ] 确认摄影单机还是双机，建议双机位
- [ ] 确认摄影师人数及档次（高端跟拍/普通跟拍）
- [ ] 确认婚礼摄影多长时间、拍摄过多少场婚礼、拍摄机器
- [ ] 多了解拍摄风格并指定摄影师
- [ ] 确认擅长什么风格（抓拍还是摆拍）、拍人为主还是拍氛围
- [ ] 确认一般会拍哪些场景、新郎出发接亲前是否会拍
- [ ] 确认摄影师拍摄角度偏好（正拍/斜拍/仰拍/俯拍/特写/远景）
- [ ] 确认构图方式（人物中心/边上）和画面美感
- [ ] 确认后期色调偏好（暖色/冷色）
- [ ] 新娘：与摄影摄像沟通拍摄想法
- [ ] 🔍 确认婚礼当天拍摄张数（如不少于 200-400 张）、底片是否全给、精修多少张
- [ ] 🔍 确认额外加修一张多少钱、婚礼当天是否能出 9 张精修
- [ ] 将用不上的产品（如摆台）换成精修（精修拿到手才是最值钱的）
- [ ] 确认拍完后多久可以选片、多久可以拿到精修
- [ ] 🔍 确认套餐内底片拍摄张数、精修数量、是否全送、不满意是否重修
- [ ] 确认**摄影摄像**精修张数、底片数量及交付时间
- [ ] 确认摄影服务时长和价位
- [ ] 明确底片和精修交付时间点
- [ ] 确认当天是否能出预告片
- [ ] 明确成片交付节点、付款方式、吃住行费用
- [ ] 确认是否有特定环节需要拍摄（与父母、伴娘伴郎、宾客互动等）
- [ ] 确认摄影内容是否包含晨袍互动、父母合影、迎亲送别等

#### 2.2.3 摄像服务

- [ ] 确认摄像师人数（单机位/双机位）
- [ ] 确认四大金刚具体人员配置（司仪/摄像/摄影/跟妆）
- [ ] 确认剪辑节奏和配乐风格是否符合喜好
- [ ] 确认喜欢的拍摄成片风格（动感/文艺）
- [ ] 确认婚礼会用到什么设备（无人机、航拍、摇臂、滑轨）
- [ ] 🔍 确认婚前 MV、快剪是否有、是否另外收费
- [ ] 🔍 确认是否提供快剪（婚礼当天大屏播放）
