## 2、求职策略与执行

### 2.1 平台使用技巧

#### 2.1.1 搜索优化

- [ ] 优化招聘平台搜索方式，打破信息茧房

	- [ ] 用多关键词组合搜索岗位（如策划、数据助力、内容运营等）
	- [ ] 用AI工具查询目标岗位的所有业内叫法
	- [ ] 切换一二线城市搜索自己的专业名称发现可投岗位
	- [ ] 更改岗位排序为最新优先/距离优先/匹配度优先，刷出不同公司
	- [ ] 使用招聘平台网页版（不登录直接搜索）发现更多公司
	- [ ] 用技能关键词搜索岗位（运营/产品/测试等）
	- [ ] 关闭BOSS直聘个性化职位/内容推荐
	- [ ] 开启“对BOSS隐藏求职偏好”等隐藏设置

#### 2.1.2 地理与扫楼

- [ ] 以住处为中心，利用地图/定位功能扫楼式搜索周边企业
	- [ ] 利用地图APP搜索"公司"发现周边企业
	- [ ] 将 BOSS 直聘定位临时修改为目标区域标志性写字楼或大厦
	- [ ] 使用"附近"功能筛选目标楼宇或3公里内的岗位
	- [ ] 搜索目标产业园区入驻公司，并在招聘平台查看是否在招聘

#### 2.1.3 活跃度与信息筛选

- [ ] 筛选高活跃度岗位，避开僵尸/模糊岗位
	- [ ] 优先选择 BOSS 直聘、猎聘等活跃度高的平台进行重点投递
	- [ ] 投递前确认 HR 近期在线，跳过长期未上线的岗位
	- [ ] 优先投递3-5日内新发布的岗位
	- [ ] 重点查看"企业认证"和"岗位更新时间"，跳过信息模糊的旧岗位
	- [ ] 设置HR活跃度筛选（3天/一周/最多一月），避开僵尸岗位

#### 2.1.4 跨平台验证

- [ ] 跨平台交叉验证：在某平台看到岗位后，去公司官网和企业信用网站确认近期动态

### 2.2 简历优化

#### 2.2.1 简历内容与格式

- [ ] 使用简历工具，控制1页A4纸，用STAR法则与数据量化成果
	- [ ] 使用超级简历、职徒简历、知页简历、五百丁、简历本优化简历
	- [ ] 用数据和成果化表达量化项目与工作价值

#### 2.2.2 岗位匹配

- [ ] 按岗位JD拆解用人标准，定制不同方向简历
	- [ ] 按岗位方向定制简历，不要一份简历投多岗
	- [ ] 按岗位JD拆解用人标准并优化简历，贴合岗位JD
	- [ ] 先收藏目标岗位再按JD反向修改简历
	- [ ] 简历提取岗位关键词+行业术语+数据量化
	- [ ] 按“能否加分”原则筛选简历内容
	- [ ] 调整简历模块顺序，把优势放前面
	- [ ] 截图10个头部公司JD，用AI拆解共性要求
	- [ ] 简历突出技术栈、GitHub/技术博客，命名格式规范
	- [ ] 适当美化简历，gap期间用实际经历或学习证明填充
	- [ ] 提前编辑好招聘APP在线简历+附件简历

### 2.3 投递策略

#### 2.3.1 投递节奏

- [ ] 制定投递节奏，分阶段海投
	- [ ] 每周固定2天进行信息采集，不要每天全平台打开
	- [ ] 固定每天投简历的时间段，工作日9-11点、14-16点集中投递
	- [ ] 海投分练手/同段位/冲刺/定岗四阶段执行
	- [ ] 有针对性地投递与工作经历匹配或感兴趣的岗位

#### 2.3.2 投递心态

- [ ] 大胆投递，不要自我设限
	- [ ] 符合70%岗位要求就大胆投递
	- [ ] 放宽目标行业，大胆投递非垂直岗位
	- [ ] 放宽距离和行业限制，多投多面

#### 2.3.3 投递话术

- [ ] 优化投递沟通话术，提高回复率
	- [ ] 给HR发消息时使用开门见山的话术，突出技能匹配、经验对口与可带来的结果
	- [ ] 在BOSS直聘直接发送简历并说明项目经历
	- [ ] 投递时发送招呼语+简历，邮件投递附加正文和自荐信

### 2.4 面试准备

#### 2.4.1 面试前必问清单

- [ ] 面试前确认薪资、五险一金、工作时间、试用期等核心条件
	- [ ] 面试前问清薪资结构、五险一金缴纳比例与时间，同时了解晋升与团队分工
	- [ ] 面试前确认工作时间（单双休、加班、年假等）
	- [ ] 面试前确认具体工作内容与职责范围
	- [ ] 面试前确认试用期/试岗期、试用期薪资与转正考核标准；确认试用期时长、调薪机制、绩效/加班费

#### 2.4.2 面试表达

- [ ] 面试前做岗位拆解与模拟演练，掌握转化话术
	- [ ] 面试前用30分钟做岗位拆解、公司摸底、模拟演练
	- [ ] 面试前了解目标岗位和企业发展方向
	- [ ] 面试时主动展示优势
	- [ ] 面试换行原因强调能力迁移+创造价值
	- [ ] 离职原因、缺点、期望薪资用转化话术回答
	- [ ] 面试时提高音量，把公司当作双向选择对象
	- [ ] 使用腾讯会议进行模拟面试练习
	- [ ] 找同行朋友突击学习岗位经验

#### 2.4.3 面试复盘

- [ ] 面试后及时复盘并跟进
	- [ ] 面试后及时复盘失败原因并优化表达
	- [ ] 每次面试当天复盘问题并扩充面试题库
	- [ ] 面试结束当天主动跟进HR并继续面试其他家

#### 2.4.4 技术面试

- [ ] 技术/算法岗面试前确认是否有机试/coding环节，识别伪技术岗
	- [ ] 识别伪技术岗（JD模糊、专利少、只问行政问题）

## 3、风险识别与避坑

### 3.1 公司背调

#### 3.1.1 企业信用

- [ ] 用企查查/天眼查/看准网等工具核查公司背景
	- [ ] 使用企查查/天眼查辅助判断公司是否靠谱
	- [ ] 面试前用天眼查、电子税务局核验公司风险
	- [ ] 面试前用天眼查/看准网查公司参保与纠纷
	- [ ] 在企查查招聘/天眼查招聘查看公司扩张动向和招聘信息
	- [ ] 使用36氪、天眼查/爱企查、IT桔子、创业邦查询公司公开投资事件
	- [ ] 筛选有行业头部同行或知名资本入股的目标公司投递

#### 3.1.2 反向背调

- [ ] 把双休/五险一金/清晰职责作为底线，做反向背调
	- [ ] 小红书搜公司真实评价+企查查社保人数做反向背调
	- [ ] 面试时观察公司环境，人员过少或不带薪培训的不入职

### 3.2 常见骗局防范

#### 3.2.1 收费与虚假招聘

- [ ] 拒绝收费内推、先交钱办证、高薪兼职等骗局
	- [ ] 拒绝收费内推/保offer机构
	- [ ] 拒绝需要先交钱办证的养老护理/陪诊岗位
	- [ ] 警惕高薪兼职和开车跑路线类兼职
	- [ ] 不信任何“给钱安排岗位”的信息
	- [ ] 不轻信不知名小招聘网站和高薪兼职
	- [ ] 避开58同城/赶集网虚假岗位

#### 3.2.2 公司类型识别

- [ ] 识别伪装国企/央企/双休的保险公司、催收公司、娱乐直播公司
	- [ ] 投递前看清公司名称，避开娱乐直播类公司
	- [ ] 识别“品牌名+科技公司+薪资跨度大”的催收公司
	- [ ] 警惕标注国企/央企/双休但实为保险公司的岗位
	- [ ] 过滤BOSS主动联系的服务员、外卖、快递、销售岗位

#### 3.2.3 不规范用工

- [ ] 拒绝无五险一金、试岗期不给工资等不规范offer
	- [ ] 拒绝财务制度混乱的offer（两套账、现金发工资等）
	- [ ] 拒绝无五险一金、随时加班、不尊重员工的公司
	- [ ] 遇到试岗期不给工资拨打12333举报
