# 09-婚纱需求表达与沟通

> 很多新娘对婚纱有想法，但不知道怎么描述。学会用礼服师听得懂的关键词沟通，能大幅提高试纱效率。

## 试纱前必说的基础信息

| 信息 | 为什么重要 |
|------|------------|
| 婚礼人数 | 决定拖尾长度和裙摆大小 |
| 场地类型 | 室内/室外、暗场/明场，决定材质和风格 |
| 婚礼日期 | 考虑季节温度，决定是否需要长袖/保暖设计 |
| 个人身高体重 | 帮助礼服师初步判断适合的版型 |
| 想修饰的部位 | 让礼服师精准推荐扬长避短款式 |

## 婚纱版型关键词

| 版型 | 适合场景 | 关键词 |
|------|----------|--------|
| 鱼尾裙 | 小型婚礼、百人左右 | 包臀、紧身、展现曲线 |
| A摆/A字裙 | 百人左右、150人以内 | 裙摆自然散开、小个子友好 |
| 蓬裙 | 150人以上、大型婚礼 | 大裙摆、长拖尾、压场、仪式感 |

## 室内婚礼关键词

- 婚礼人数
- 重工
- 缎面
- 缎闪结合
- 蕾丝
- 纯纱

## 室外婚礼关键词

- 缎面
- 纯纱
- 蕾丝
- 轻盈
- 飘逸
- 便于行走

## 婚纱风格关键词

| 风格 | 关键词 |
|------|--------|
| 法式复古 | 蕾丝、缎面、小裙摆、鱼尾、礼帽、手套 |
| 中式复古 | 缎面花边、羊毛卷发、泡泡袖 |
| 仙气款 | 花朵元素、纯纱、仙女感 |
| 公主风 | 重工闪闪、缎面公主、腰部蓬起、万众瞩目 |

## 有效表达雷区与硬性要求

### 可以说出自己的雷区

- 不要长袖
- 不要蕾丝
- 不要缎面
- 不要泡泡袖
- 不要深V

### 可以告知自己的硬性要求

- 大臂有纹身必须遮盖
- 后背一点不能露
- 必须能穿bra
- 必须方便走动
- 婚礼当天要抱小孩/宠物

### 可以说出最喜欢的元素

- 蕾丝
- 缎面
- 带花的
- 带钻的
- V领
- 长袖
- 蝴蝶结

## 最精准的沟通方式

- **保存网图直接发给婚纱店**，这是最精准的参考方式。
- 不建议线上把款式和风格卡得太死，因为上身效果跟图片可能完全不同。
- 先试几款不同风格，再缩小范围。

## 给礼服师的完整需求模板

> 我的婚礼是 [室内暗场/明场/草坪/教堂/海边]，预计 [X] 位宾客，身高 [X]，想修饰 [手臂/腰腹/胯宽/肩膀]。我喜欢 [蕾丝/缎面/带花/带钻/V领/长袖]，不喜欢 [长袖/蕾丝/缎面/泡泡袖]。必须满足 [遮纹身/不露背/方便走动]。
