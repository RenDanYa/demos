# 10-秀禾服选择

> 秀禾服并非不挑身材。不同身材和不同身形问题，都有对应的款式选择技巧。

## 按体型选秀禾

### 沙漏型身材

- **推荐**：廓型秀禾
- **要点**：在收腰基础上重视腰臀比，举手投足间更显雍容华贵。

### 梨型身材

- **推荐**：收腰大裙摆秀禾服
- **要点**：视觉重心上移，遮挡腿部肉肉，显瘦且端庄大气。

### O型/苹果型身材

- **推荐**：金色秀禾服
- **要点**：金色比红色更亮眼，来宾目光会聚焦在衣服上而非身材上；金色视觉上更立体，小腹赘肉不影响整体效果。

### 倒三角型身材

- **推荐**：高开叉秀禾服、高腰线秀禾服
- **要点**：强调腿长优势，视觉上拉长腿部线条。

### H型身材

- **推荐**：有云肩或披风的秀禾款式
- **要点**：微微收腰，遮住肩宽，整体更协调，凸显气质与高雅。

## 按具体身形问题选秀禾

| 问题 | 推荐设计 | 原因 |
|------|----------|------|
| 臂粗 | 泡泡袖、网纱袖 | 遮挡拜拜肉 |
| 胯宽 | 高腰线设计 | 视觉拉长线条 |
| 背厚 | 云肩或披风款 | 遮挡背部 |
| 头大 | 宽肩收腰设计 | 显头小 |
| 腰粗 | 收腰设计 + 大裙摆 | 打造完美腰臀比 |
| 微胖 | 上身贴合 + 纵向流苏 | 拉长身形、显瘦 |
| 显老气 | 紫金、红金、粉色、碧玉色 + 蝴蝶结 | 比传统红色更减龄 |
| 窄肩 | 小垫肩云肩款 | 加宽肩膀、更有型 |
| 脖短 | 小V领 | 露出脖颈线条，避免立领 |

## 选秀禾核心原则

- 不要盲目跟风选爆款，适合自己的才是最好的。
- 金色、粉色等浅色秀禾比传统红色更减龄、更亮眼。
- 高腰线、收腰设计能修饰大多数身材问题。
- 云肩、披风、泡泡袖是遮挡手臂和背部肉肉的有效元素。
