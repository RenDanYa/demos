# 11-主纱造型参考

> 主纱造型包括发型、头饰和头纱，直接影响整体气质和婚礼当天的出片效果。

## 主纱造型分类

### 按发型风格

| 造型 | 特点 | 适合脸型 |
|------|------|----------|
| 大波浪披发 | 浪漫优雅、女人味足 | 多数脸型 |
| 优雅盘发 | 显气质、显高、正式感强 | 圆脸、方脸 |
| 复古高发髻 | 女王气场、仪式感十足 | 脖子较长的新娘 |
| 低盘发 | 温柔知性、适合迎宾 | 多数脸型 |
| 丸子头/花苞头 | 年轻俏皮、减龄 | 小脸、瓜子脸 |
| 侧分披发 | 自然随性、适合户外 | 长脸、鹅蛋脸 |
| 复古波纹 | 古典优雅、适合复古婚礼 | 五官立体的新娘 |

### 按头饰风格

| 头饰 | 风格 | 适合造型 |
|------|------|----------|
| 皇冠 | 女王气场、公主风 | 高发髻盘发 |
| 发带/发箍 | 甜美、减龄、韩系 | 蓬松盘发、披发 |
| 珍珠发饰 | 优雅、法式 | 低盘发、侧分披发 |
| 鲜花/假花 | 自然、森系、仙气 | 低盘发、半扎发 |
| 精致小发饰 | 简约、高级 | 侧分披发、低盘发 |

### 按头纱长度

| 头纱 | 效果 | 适合造型 |
|------|------|----------|
| 长头纱 | 拉长身形、增强宿命感 | 圆脸、娇小新娘 |
| 蕾丝边短纱 | 柔化脸部线条 | 方脸新娘 |
| 面纱 | 神秘感、仪式感 | 简约盘发 |
| 多层头纱 | 层次感强、更梦幻 | 盘发造型 |

## 造型与婚礼场景搭配

| 场景 | 推荐造型 | 原因 |
|------|----------|------|
| 室内暗场 | 高发髻+皇冠+长头纱 | 仪式感最强、舞台效果好 |
| 室内明场/韩式 | 低盘发+简约发饰+短头纱 | 干净高级、与场布统一 |
| 室外草坪 | 侧分披发+鲜花+轻盈头纱 | 自然浪漫、便于走动 |
| 教堂 | 复古高发髻+长头纱/面纱 | 庄重大气 |
| 海边 | 低盘发+简约头饰 | 不易被海风吹乱 |

## 选造型注意事项

- 发型要与婚纱领型协调：高领/立领适合盘发，一字肩适合披发或低盘发。
- 头纱长度可以弥补拖尾长度，长头纱宿命感强。
- 试妆时保存心仪造型图片，与化妆师沟通可行性。
- 考虑婚礼当天的便利性：敬茶、敬酒、拥抱等环节是否方便。
