# 02-婚纱裙摆版型

> 按裙摆版型分类是婚纱选款中最核心的分类方式，直接决定婚纱的廓形与身材修饰效果。

## A字裙

- **特点**：上半身贴合，下摆自然散开呈 A 字形。
- **适合人群**：万能不挑人，是最稳妥的选择。
- **场景**：适用范围广，不挑场地。

## 蓬蓬裙（公主裙）

- **特点**：高腰线 + 超大裙摆，自带童话滤镜。
- **适合人群**：小个子新娘或喜欢甜美风的新娘。
- **场景**：宽敞的宴会厅或城堡场地非常压场。

## 鱼尾裙

- **特点**：贴身剪裁到膝盖，下摆如鱼尾般散开。
- **适合人群**：身材匀称、沙漏型身材的新娘，能完美勾勒腰臀曲线。
- **风格**：性感天花板。

## 喇叭裙

- **特点**：鱼尾裙的温柔版，从大腿处开始散开裙摆。
- **适合人群**：比鱼尾更灵动，对梨形身材更友好。

## 修身直筒裙

- **特点**：极简利落，线条流畅，高级感拉满。
- **适合人群**：纸片人身材或喜欢极简主义的新娘。

## 帝国腰线裙

- **特点**：高腰线设计，胸下开始散开裙摆。
- **适合人群**：苹果型身材或小个子新娘，自带拉长腿部效果。

## 版型与身材速查

| 版型 | 关键词 | 适合身材 |
|------|--------|----------|
| A字裙 | 万能、稳妥 | 不挑人 |
| 蓬蓬裙 | 甜美、童话 | 小个子、喜欢甜美风 |
| 鱼尾裙 | 性感、曲线 | 沙漏型、匀称身材 |
| 喇叭裙 | 灵动、温柔 | 梨形身材 |
| 直筒裙 | 极简、高级 | 纸片人、极简主义 |
| 帝国腰线裙 | 显高、高腰 | 苹果型、小个子 |
