# 06-婚纱搭配与试纱建议

> 试纱是选婚纱最关键的环节。提前明确自己的需求、雷区和身材特点，能让试纱效率更高、结果更满意。

## 试纱前准备清单

- [ ] 明确婚礼场地：室内暗场/明场、草坪、教堂、海边等。
- [ ] 预估宾客人数，初步确定拖尾长度范围。
- [ ] 保存喜欢的网图，直接发给礼服师作为参考。
- [ ] 列出自己的**雷区款式**（如不要长袖、不要蕾丝、不要缎面）。
- [ ] 列出自己的**硬性要求**（如必须遮纹身、后背不能露）。
- [ ] 列出自己的**最喜欢元素**（如蕾丝、带花、带钻、V领、长袖）。
- [ ] 告知礼服师自认为的身材优缺点。

## 试穿时必须检查的细节

| 检查项 | 注意点 |
|--------|--------|
| 袖口 | 位置是否合适，抬手是否方便 |
| 领口 | 是否太低或太紧，低头是否走光 |
| 裙撑 | 带着裙撑多走路，确认是否好走、不绊脚 |
| 拖尾 | 不要贪大，小个子适合 1-1.5m；过长会压身高 |
| 腰线 | 礼服腰线要高于肚脐眼，才能显高 |
| 裙摆 | 小个子不适合裙摆太大的婚纱，容易像"把人装进去" |
| 整体重量 | 太重的婚纱穿着累，行动受限 |

## 领口与身材速查

| 身材特点 | 推荐领口/袖型 | 避雷领口/袖型 |
|----------|---------------|---------------|
| 斜方肌明显 | 挂脖款 | 一字肩 |
| 溜肩 | 泡泡袖 | 过于夸张的泡泡袖（微胖/头大慎选） |
| 手臂粗 | 一字肩、长袖、半袖、泡泡袖 | 抹胸 |
| 肩膀厚 | 避免一字肩，会显虎背熊腰 | 一字肩 |
| 脖子短 | V领、一字肩、抹胸 | 高领、立领 |
| 方脸 | V领、心形领、抹胸 | 方领、竖领、一字领、U领 |
| 大胸 | 避免无袖/V领/挂脖/吊带 | 无袖、深V、吊带 |
| 小胸 | 胸前保守、长袖露背、高腰线 | 过于暴露胸前设计 |
| 圆肩 | 垫肩、袖子有立体设计、复古高领、脖子配饰 | 软塌无肩线设计 |

## 面料与颜色搭配公式

| 维度 | 建议 |
|------|------|
| 微胖 | 选硬挺缎面，避免贴身软塌面料 |
| 娇小 | 选轻盈欧根纱，避免厚重面料 |
| 冷白皮 | 香槟色更显高级 |
| 黄皮 | 珍珠白更衬肤色 |
| 圆脸 | 配长头纱，拉长脸型 |
| 方脸 | 选蕾丝边短纱，柔化线条 |

## 与礼服师沟通的关键信息

1. **婚礼人数**：决定拖尾长度和裙摆大小。
2. **场地类型**：室内/室外、暗场/明场，决定材质选择。
3. **个人偏好**：喜欢的元素和雷区。
4. **身材顾虑**：希望修饰的部位（手臂、腰腹、胯宽等）。
5. **特别建议**：没试过婚纱不要把风格卡太死，上身效果和图片可能完全不同。
