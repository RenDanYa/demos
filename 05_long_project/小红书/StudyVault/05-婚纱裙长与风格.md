# 05-婚纱裙长与风格

> 裙长决定仪式感与行动便利度，风格决定婚纱的整体气质。两者结合场地与身材，才能选出最出彩的款式。

## 拖尾长度分类

| 拖尾类型 | 长度范围 | 适用场景 |
|----------|----------|----------|
| 微型拖尾 | < 30cm | 户外草坪、海边、轻婚礼 |
| 小型拖尾 | 30-50cm | 小型室内婚礼、出门纱 |
| 教堂短拖尾 | 50-80cm | 教堂婚礼、中型宴会厅 |
| 教堂长拖尾 | 80-130cm | 大型宴会厅、隆重仪式 |
| 皇室级拖尾 | > 130cm | 超大型婚礼、豪华场地 |

### 拖尾与宾客人数参考

- **宾客 ≥100人**：拖尾 1m 左右及以内，可选鱼尾但拖尾或头纱长一些。
- **宾客 200人以内**：拖尾 80cm-2m 之间。
- **宾客 200人以上**：拖尾 1.5m-5m 都可以，更有仪式感。
- **注意**：拖尾越长越压身高，小个子新娘需按身材比例选择。

## 裙长分类

| 裙长 | 特点 | 适合场景 |
|------|------|----------|
| 超短款 | 活泼俏皮、显腿长 | 旅拍、户外轻婚礼、after party |
| 短款 | 轻盈灵动、适合小个子 | 订婚、领证、户外婚礼 |
| 及地款 | 传统经典、行动方便 | 多数婚礼场景 |
| 落地长裙 | 仪式感强、气场足 | 主仪式、大型宴会厅 |
| 不对称/前短后长 | 设计感强、个性突出 | 旅拍、个性婚礼 |

## 婚纱风格分类

### 按气质划分

| 风格 | 亮点元素 | 适合人群 |
|------|----------|----------|
| 法式复古 | 蕾丝、缎面、小裙摆、礼帽、手套 | 喜欢复古优雅的新娘 |
| 中式复古 | 缎面花边、泡泡袖、羊毛卷发 | 更适合拍照，现场效果一般 |
| 仙气款 | 花朵元素、纯纱、轻盈层次 | 喜欢浪漫梦幻的新娘 |
| 公主风 | 重工闪闪、缎面公主、腰部蓬起 | 喜欢万众瞩目感的新娘 |
| 现代简约 | 线条简洁、剪裁利落 | 追求高级感的新娘 |
| 个性婚纱 | 彩色、印花、独特设计 | 追求独特风格的新娘 |

## 风格与场景速查

| 婚礼场景 | 推荐风格 | 避雷风格 |
|----------|----------|----------|
| 室内暗场 | 重工闪闪、公主风 | 过于简约寡淡 |
| 室内明场/韩式 | 现代简约、缎面、仙女纱 | 欧式颜色过黄过黑 |
| 室外草坪 | 法式复古、仙气款、缎面 | 超大蓬蓬裙 |
| 教堂 | 蕾丝、复古、长拖尾 | 过于短款、过于休闲 |
| 海边 | 轻盈纱质、前短后长 | 厚重缎面、长拖尾 |
