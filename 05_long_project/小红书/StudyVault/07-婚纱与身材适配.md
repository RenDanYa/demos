# 07-婚纱与身材适配

> 不同身材有各自的优势和需要修饰的部位。选对婚纱版型、领口和腰线，才能在婚礼当天穿出最佳状态。

## 按体型分类

### 梨形身材（胯宽腿粗、腰细）

- **特点**：上半身瘦、下半身有存在感。
- **推荐**：A字裙、高腰蓬蓬裙、高腰裙、希腊式垂坠感婚纱。
- **避雷**：鱼尾裙、紧身缎面、低腰设计、包臀款。
- **要点**：视觉重心上移，遮挡臀腿。

### 苹果型身材（腰腹有肉、四肢纤细）

- **特点**：脂肪集中在腰腹，上半身偏圆润。
- **推荐**：高腰A字裙、帝国腰线裙、V领轻纱、简约直筒裙。
- **避雷**：紧身腰封、包臀缎面、腰部堆叠太多。
- **要点**：拉高腰线，遮住腹部，分散上半身视觉重心。

### 沙漏型身材（肩胯均衡、腰细）

- **特点**：胸臀丰满、腰线清晰、曲线好。
- **推荐**：鱼尾裙、紧身裙、收腰A字裙、水滴领收腰缎面。
- **避雷**：过蓬大裙摆、无腰线直筒、腰线太高。
- **要点**：突出腰臀比，展现曲线美。

### H型/长方形身材（肩腰臀接近、曲线不明显）

- **特点**：肩腰胯宽度接近，缺乏明显腰线。
- **推荐**：收腰A字裙、蓬蓬裙、鱼尾裙、立体雕花宫廷风婚纱。
- **避雷**：直筒无腰线、过宽高腰裙、过分宽松。
- **要点**：制造腰部曲线，增加上半身层次感。

### 倒三角身材（肩宽胯窄）

- **特点**：肩比胯宽，上半身有存在感。
- **推荐**：A字裙、高腰裙、蓬蓬裙、法式方领蓬蓬裙。
- **避雷**：一字肩、泡泡袖、上半身装饰过多、垫肩。
- **要点**：视觉下移重心，平衡肩胯比例。

### 娇小身材（身高不足160cm）

- **特点**：怕显矮、怕压身高。
- **万能公式**：
  - 超大裙摆 ❌ | 中小裙摆 ✅
  - 繁琐装饰/重工爆闪 ❌ | 简约简单 ✅
  - 鱼尾/小鱼尾 ❌ | A摆 ✅
  - 低腰线 ❌ | 高腰线 ✅
- **推荐**：短款婚纱、高腰线、及地款、简约直身裙、开叉、前短后长。
- **避雷**：超大裙摆、超长拖尾、低腰线、重工爆闪。

### 微胖身材

- **推荐**：一字肩、高腰线、A字裙、有褶皱设计、分体式、鱼骨设计、直线条裁剪、硬挺面料。
- **避雷**：吊带裙、紧身裙、过于贴身长袖、贴身抹胸。

## 按具体部位修饰

| 部位 | 推荐设计 | 避雷设计 |
|------|----------|----------|
| 手臂粗 | 一字肩、长袖、半袖、泡泡袖 | 抹胸、无袖 |
| 肩膀厚 | 避免一字肩显壮 | 一字肩 |
| 斜方肌明显 | 挂脖款 | 抹胸、一字肩 |
| 溜肩 | 泡泡袖、有袖款式 | 软塌无肩线 |
| 脖子短 | V领、一字肩、抹胸 | 高领、立领 |
| 方脸 | V领、心形领、抹胸 | 方领、竖领、一字领、U领 |
| 小胸 | 胸前保守、长袖露背、高腰线 | 过度暴露胸前 |
| 大胸 | 避免无袖/V领/挂脖/吊带 | 无袖、深V、吊带 |
| 圆肩 | 垫肩、立体袖子、复古高领 | 软塌肩部设计 |
