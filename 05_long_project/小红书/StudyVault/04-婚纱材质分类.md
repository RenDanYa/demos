# 04-婚纱材质分类

> 材质决定婚纱的质感、光泽、垂坠感和整体氛围。选对材质，能让婚礼现场效果与照片效果都更出彩。

## 常见婚纱材质

### 缎面

- **特点**：光泽感强、表面光滑、垂坠感好、自带高级感。
- **风格**：成熟、简约、大气、经典耐看。
- **适合场景**：室外婚礼、草坪婚礼、韩式简约明场。
- **身材建议**：微胖新娘可选硬挺缎面，显瘦更有型；娇小新娘避免过于厚重的缎面。

### 纱质/网纱

- **特点**：轻薄透气、层次丰富、梦幻飘逸。
- **风格**：甜美、仙气、浪漫、少女感十足。
- **适合场景**：室内暗场、公主风婚礼、拍照出片。
- **身材建议**：娇小新娘优先选择轻盈欧根纱，避免超大蓬蓬纱压身高。

### 蕾丝

- **特点**：精致细腻、法式浪漫、透光性好。
- **风格**：优雅、性感、复古、纯欲。
- **适合场景**：法式复古婚礼、户外草坪、教堂婚礼。
- **注意**：大面积蕾丝对做工要求高，需现场确认质感。

### 欧根纱

- **特点**：轻盈挺括、立体感强、透气性好。
- **风格**：仙气、灵动、适合打造蓬松层次。
- **身材建议**：娇小新娘首选，能减轻婚纱整体重量感。

### 雪纺

- **特点**：柔软飘逸、自带柔光滤镜效果。
- **风格**：温柔、浪漫、适合轻婚纱或出门纱。
- **颜色建议**：香槟色雪纺自带柔光感，适合暖黄皮新娘。

### 缎纱结合/缎闪结合

- **特点**：融合缎面的高级与纱质的梦幻，或加入细闪元素。
- **风格**：既简约又出彩，近年来非常流行。
- **适合场景**：室内外皆可，尤其适合拍照。

## 材质与场景速查

| 场景 | 推荐材质 | 原因 |
|------|----------|------|
| 室内暗场 | 重工闪纱、蕾丝、缎闪结合 | 灯光下更璀璨，仪式感强 |
| 室内明场 | 缎面、纯纱、蕾丝简约款 | 干净显气质，与韩式简约布置适配 |
| 室外草坪 | 缎面、纯纱、蕾丝 | 自然光下质感高级，拍照耐看 |
| 教堂婚礼 | 蕾丝、缎面、重工纱 | 庄重大气，与教堂氛围契合 |
| 海边婚礼 | 轻盈纱质、雪纺 | 飘逸灵动，便于行走 |

## 材质与身材速查

| 身材特点 | 推荐材质 | 避雷材质 |
|----------|----------|----------|
| 微胖 | 硬挺缎面、有支撑感的面料 | 贴身软塌面料 |
| 娇小 | 轻盈欧根纱、轻薄纱质 | 厚重缎面、超大蓬蓬纱 |
| 想显瘦 | 垂坠感好的缎面、有纹理的纱 | 反光过强或过于贴身面料 |
| 追求梦幻 | 多层网纱、蕾丝、欧根纱 | 极简缎面 |
