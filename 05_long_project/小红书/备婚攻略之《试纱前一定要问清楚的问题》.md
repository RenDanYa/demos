### 试纱前准备
- [ ] 提前了解目标婚纱店的试纱费用政策
- [ ] 确认试纱费是否可在下单时抵扣
- [ ] 提前了解婚纱店的套餐内容和潜在消费项
- [ ] 去试纱前列出要问的问题清单
- [ ] 向有经验的朋友收集试纱经历和建议

### 试纱费必问
- [ ] 问清试纱费收费标准（按件/按类型/按次）
- [ ] 问清试纱费能否免除（当天定下或多人同行时）
- [ ] 问清试纱费能否全额抵扣套餐价
- [ ] 问清免费试纱是否有数量限制
- [ ] 问清试纱是否限时、超时怎么算

### 套餐必问
- [ ] 问清套餐具体包含哪几件衣服（出门纱/主纱/敬酒服/晨袍等）
	- 常见的套餐组合:
		- 3件套:出门纱+主纱+敬酒服。
		- 4件套:晨袍+出门纱+主纱+敬酒服
		- 5件套:晨袍+出门纱+主纱+敬酒服+回门/派对裙
	- 下单之前要问:
		- 套餐具体包含哪几件?能不能换?(比如你不想要晨袍想换成更好的主纱能不能加钱升级?)
- [ ] 问清套餐里的衣服能否更换或加钱升级
- [ ] 问清套餐价是否包含修改、清洗、配饰、运费
- [ ] 问清不同套餐的实物差异（品牌、新旧、面料、定制程度）
- [ ] 问清能否单租某一件、单租怎么算
- [ ] 问清套餐能否升级、补差价规则


### 合同必问
- [ ] 问清婚期改了能否免费换档期、提前多久通知
- [ ] 问清婚礼前多久可以再来试穿、不合适能否免费换款或改尺寸
- [ ] 问清轻微磨损/污渍赔偿标准
- [ ] 问清定金比例、尾款支付时间（取纱时付还是还纱时付？）、取消婚礼定金能否退
- [ ] 确认合同中写明婚纱品牌/款号、取还纱日期、物品清单、总价及违约条款
