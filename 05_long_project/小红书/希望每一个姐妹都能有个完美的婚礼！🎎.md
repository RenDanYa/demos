### 婚庆及四大金刚
- [ ] 通过已婚朋友或当地推荐筛选婚庆公司
- [ ] 请一位婚礼管家全程把控
- [ ] 跟妆提前试妆并确认风格

### 婚礼请帖
- [ ] 至少提前1个月制作电子请帖和纸质请帖
- [ ] 制作父母版本和新人版本两份请帖

### 新娘婚前准备
- [ ] 制定减肥计划及最佳体重目标
	- [ ] 体态训练：瘦肚、瘦背、直角肩、瘦腰
	- [ ] 婚前1-2周清淡饮食避免长痘
- [ ] 提前3-6月试纱并预订婚纱
	- [ ] 确定主纱款式（室内重工/室外缎面）
	- [ ] 确定秀禾款式
	- [ ] 确定敬酒服款式
	- [ ] 确定迎宾纱款式
	- [ ] 确定晨袍款式
	- [ ] 准备**1-3套婚礼前后裙装**
- [ ] 鞋
	- [ ] 提前2-3月购买主纱鞋（7-10cm高跟）
	- [ ] 购买秀禾鞋（5-9cm闪粉细跟尖头）
	- [ ] 准备敬酒服鞋、迎宾纱鞋、晨袍鞋
