### 试妆前必问清单

- [ ] 确认跟妆套餐价位及包含的妆造套数
- [ ] 确认是否包含新郎、妈妈、婆婆、伴娘的妆面造型及人数限制
- [ ] 确认套餐是否包含头饰头纱、耳环、项链、秀禾团扇等配饰
- [ ] 确认是否提供身体素颜霜、高光闪粉、精灵耳贴、双眼皮贴、假睫毛等耗材
- [ ] 确认护肤品和化妆品是否为一线品牌
- [ ] 确认是否可提前试妆、试妆是否收费、可试几套妆造、不满意是否可换化妆师
- [ ] 确认能否看化妆师作品集尤其是真实客片
- [ ] 确认是否为全程跟妆、凌晨化妆是否额外收费、套餐工作时长及加时费
- [ ] 确认化妆流程具体安排及每套妆造所需时间
- [ ] 确认看中的化妆师婚礼当天是否有档期
- [ ] 确认化妆师交通费是否实报实销及是否需要安排食宿
- [ ] 确认异地婚礼是否收取额外异地费
- [ ] 确认近期优惠活动及合作婚纱店/婚庆公司是否有额外折扣
- [ ] 确认付款流程及尾款是否可在婚礼结束后结算
- [ ] 确认婚礼当天化妆师因不可抗力无法到场时是否有同档位或以上化妆师补救

### 妆造需求清单

- [ ] 整理晨袍造型需求（风格、发型、耳饰等）并附参考图
- [ ] 整理中式造型需求（妆容、头饰、耳饰、团扇等）并附参考图
- [ ] 整理迎宾造型需求（风格、发型、首饰等）并附参考图
- [ ] 整理主纱造型需求（妆容、发型、耳饰、头纱等）并附参考图
- [ ] 整理敬酒造型需求（风格、发型、花草点缀等）并附参考图
- [ ] 将妆造需求清单连同个人照片一起发给跟妆老师
