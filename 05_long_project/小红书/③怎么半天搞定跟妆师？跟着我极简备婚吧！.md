### 快速筛选化妆师

- [ ] 快速从各平台搜索附近可跟妆店铺，优先婚纱店，其次化妆培训，最后摄影店
- [ ] 挑选10家有一定规模和名气的店铺并一一联系
- [ ] 对比价格，超过预算直接PASS，低于1000的尽量不考虑
- [ ] 从各平台评价和朋友打听中对比，筛选到5家以内
- [ ] 小店找创始人，大店找经理及总监级，确认有好的跟妆师
- [ ] 电话沟通无问题后，实地考察店铺

### 沟通确认清单

- [ ] 确认全程跟妆安排（是否从早上到敬酒全部结束）
- [ ] 确认女方不在本市是否需要提前一天接、包食宿及额外费用
- [ ] 确认新娘妈妈和伴娘化妆费用怎么算
- [ ] 确认配饰（头饰、睫毛等）是否全部包含，有无隐形消费
- [ ] 确认多久可以试妆、试妆是否收费及具体金额
- [ ] 确认每个妆要化多长时间、要换多少个造型
- [ ] 确认试妆和婚礼当天化妆师是否为同一人
- [ ] 确认每套衣服能试多少个造型，不满意可以换几个
- [ ] 确认化妆师用的化妆品品牌，敏感肌提前沟通或自带
