### 费用问题

- [ ] 确认全程跟妆、半程跟妆、早妆分别多少钱
- [ ] 确认化妆师路程远近及交通费、住宿费是否另付
- [ ] 确认是否送伴娘简妆和妈妈简妆，不送的话额外收费多少
- [ ] 确认是否存在隐形消费（头饰、配饰、假睫毛等材料费）
- [ ] 确认凌晨接亲或婚宴结束较晚是否需要额外付加班费
- [ ] 确认试妆是否收费、费用多少、是否可免

### 试妆问题

- [ ] 确认能否提前试妆及大概提前多久
- [ ] 确认每套衣服可以试多少个造型、不满意是否可以多试
- [ ] 确认试妆和正式化妆是否为同一个化妆师、不满意可否更换
- [ ] 确认试妆注意事项及需要自带哪些物品

### 时间安排问题

- [ ] 确认每个妆需要化多久、会试多少个造型
- [ ] 确认妈妈妆和伴娘妆的时间安排
- [ ] 确认化妆时间紧或婚礼当天临时有事时的补救措施

### 其他细节

- [ ] 确认化妆师擅长风格及往期作品、多看真实客片
- [ ] 确认化妆品品牌、敏感肌是否可以自带化妆品
- [ ] 试妆前做好精简护肤、避免涂抹过多导致搓泥
