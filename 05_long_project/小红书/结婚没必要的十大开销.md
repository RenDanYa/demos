### 婚礼开销规划

- [ ] 婚纱照不额外加精修和相框相册，套餐精修足够
- [ ] 床品准备 2-4 套，注重品质
- [ ] 婚纱礼服先了解酒店免费提供的款式，再决定是否租赁或定制
- [ ] 婚鞋选择一双可日常搭配的白色鞋款

### 婚礼服务与用品

- [ ] 先找婚庆，根据婚庆推荐选择酒店或场地
- [ ] 考虑婚庆+四大金刚+酒席打包服务
- [ ] 纸质请柬控制数量，主要用于领导同事
- [ ] 确认手捧花和胸花是否由婚庆提供
- [ ] 接亲套房对比婚庆赠送的大床房与升级套房性价比
- [ ] 婚纱礼服优先考虑租赁，不必花大价钱定制

### 珠宝首饰

- [ ] 三金选择日常可佩戴的经典款
- [ ] 钻戒不保值，可考虑性价比方案
- [ ] 对戒选择日常可长期佩戴的款式

### 其他开销

- [ ] 车队不必花大价钱，头车安排好即可

### 婚礼装饰与道具

- 手捧花不必花大价钱定制真花，选择仿真花更便宜且婚礼后可转卖。
- 网红拍照道具、接亲道具买二手更划算，用完后也可转卖回血。
- 婚房布置不必太复杂，把日常用品如电视、柜子等作为背景即可，减少一次性装饰支出。
- 纸质请柬主要发给长辈，年轻朋友可用电子请柬，节省印刷成本。

### 仪式与接待

- 婚礼管家可请有经验的朋友帮忙统筹，不一定聘请专业人员。
- 伴手礼注重实用，不必追求高价，选择大家能用得上的物品即可。
- 甜品台不用准备太多，准备一个小巧精致的款式就够了。

### 服饰与婚鞋

- 婚纱礼服租赁可考虑酒店自带的免费或升级套餐。有的酒店 8980 元套餐包含晨袍、秀禾、仪式堂婚纱、主纱 5 套、新郎定制西服及父母伴娘伴郎服装，性价比高于单独定制。
- 婚鞋买一双白色基础款即可，婚纱、礼服、龙凤褂都能搭配，日常也能穿。
