> [!note] 正文
>
> - 👰‍♀️兄弟姐妹们！谁说的备婚一定要一年起？因为各种原因（比如我和我女朋友，其实就是懒+拖延😭）只剩最后3个月的兄弟姐妹们，举起你们的双手让我看到！🙋‍♀️
> - 别焦虑！咱主打的就是一个效率和抓大放小！这份《3个月极速备婚流程表》，保你稳中带皮，婚礼照样嗨！🎉
> - 📅 第一个月：定海神针月（搞定核心大件）
> - 🏨 第1周：定场地！ 酒店/餐厅是灵魂！热门日子一定要快准狠！直接问档期，别犹豫！
> - 🤵 第2周：定“四大金刚”！ 摄影 > 摄像 > 化妆 > 主持（按抢手程度排）。赶紧看作品，约试妆，手慢无！
> - 👰 第3周：定婚纱照！ 来不及旅拍？本地工作室香香的！选最经典耐看的风格，沟通好一定要在婚礼前拿到成品。
> - 👗 第4周：定主婚纱 & 西装！ 租还是买？主纱+敬酒服+新郎西装，先试穿！定制来不及就选成品或租赁，改到合身为止！
> - 📅 第二个月：细节敲定月（疯狂买买买🛍️）
> - 👠第1周：婚鞋挑选，女生可以买松糕鞋，穿主纱时会比高跟鞋舒服很多，男生可以买内增高皮鞋。
> - 🎁 第2周：买买买！ 婚包、喜糖、伴手礼、婚房装饰、堵门道具… 把这些零碎但又必要的小东西全部加入购物车，一次性下单！
> - 👨‍👩‍👧 第3周：人员分工！ 找好伴郎伴娘，并指定一个“总导演”，当天一切听她指挥！以及花童、证婚人（如有需要），挑选婚车需要提前预定！
> - 💌 第4周：发请柬 & 建群！ 电子请柬先发一轮，统计大概人数。建立婚礼亲友群，方便沟通。
> - 📅 第三个月：冲刺落地月（全员Ready！）
> - 🎵第1周：婚礼音乐 & 流程！ 和司仪敲定仪式流程和歌单，把你的想法告诉他，拒绝尴尬煽情！和车队确认接亲路线，最好提前走一遍！
> - 🎬 第2周：确认最终细节！ 和摄影摄像沟通想要的镜头和感觉，和酒店确认最终的菜单和座位图。
> - 📞 第3周：电话提醒！ 给重要的宾客再打一遍电话确认出席！
> - 🧘‍♀️ 第4周：你最重要！ 做SPA、敷面膜、早睡！
> - 💡TIPS： ✅ 抓大放小！盯紧效果图，小瑕疵当天根本没人注意到！ ✅ 相信你的团队！既然选了就信任他们，你越放松他们发挥越好！ ✅ 婚礼当天，只管微笑！剩下的交给摄影师和你的总导演！
> - 最后，㊗️所有看到这篇的兄弟姐妹们，都能拥有一场独一无二、充满欢笑的完美婚礼！💒

## 待办

> 本笔记待办已同步到 [[待办/婚庆待办]] 汇总索引

### 第一个月：核心预订

- [ ] 沟通彩礼、婚期、确定桌数
- [ ] 预定婚礼酒店（确认档期、桌数、位置、费用、合同细则）
- [ ] 确定婚庆团队
- [ ] 见婚礼策划师确定婚礼布置、风格色系和预算
- [ ] 预定婚纱照拍摄并确保婚礼前拿到成品（先出10~12张精修制作电子请帖）
- [ ] 预定四大金刚（摄影、摄像、化妆、司仪）
- [ ] 试妆并把自己喜欢的妆容给化妆师看
- [ ] 看客片确定司仪风格
- [ ] 确定主婚纱、敬酒服、新郎西装（试穿，定制或租赁并改到合身）

### 第二个月：婚品采购与人员

- [ ] 挑选婚戒、婚鞋（女生可考虑松糕鞋，男生可考虑内增高皮鞋）
- [ ] 选购父母及伴郎伴娘服饰
- [ ] 购买婚房装饰套装
- [ ] 购买婚包/行李箱
- [ ] 购买接亲游戏道具
- [ ] 购买酒水、饮料、糕点
- [ ] 购买礼炮、礼花
- [ ] 准备誓言卡、假戒指
- [ ] 准备红包、敬茶杯、跪垫
- [ ] 购买一次性杯子、早生贵子、子孙桶、压床娃娃、矿泉水
- [ ] 选购喜糖并分装好
- [ ] 制作电子请柬（选模板）和准备纸质请柬
- [ ] 确定伴郎伴娘、花童、证婚人名单及服饰
- [ ] 指定婚礼"总导演"
- [ ] 预定婚车
- [ ] 建立婚礼亲友群

### 第三个月：最终确认与冲刺

- [ ] 婚前一个月和司仪见面沟通（带上要求和故事）
- [ ] 发送请柬
- [ ] 确定宾客名单并安排席位图
- [ ] 给外地宾客预定酒店
- [ ] 整理物品清单并补齐未购入婚品
- [ ] 安排并提前走一遍接亲路线
- [ ] 和司仪敲定仪式流程和歌单
- [ ] 和摄影摄像沟通想要的镜头和感觉
- [ ] 和酒店确认最终的菜单和座位图
- [ ] 确认四大和酒店最后细节
- [ ] 安排婚礼当日接待、物品运送等人员分工
- [ ] 准备新人及父母发言稿
- [ ] 给重要宾客打电话确认出席
- [ ] 做SPA、敷面膜、早睡
