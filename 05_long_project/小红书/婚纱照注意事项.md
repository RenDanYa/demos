### 选片注意事项

- [ ] 选片时果断删除光线、角度、动作、表情、闭眼、姿势重复不好的照片
- [ ] 选片时多留双人照，单人照各留两张，男士基本照保留
- [ ] 选片时少留背影照、剪影、半身照、远景照
- [ ] 选片时每个场景平均留几张，按精修张数分配到每套服装每个场景
- [ ] 选择相框时根据横竖版照片选择对应的相框
- [ ] 迎宾海报选全身内景照，床头挂相选外景横框照
- [ ] 选片时不要升级相框，避免积灰
- [ ] 确认精修张数、加精修单价及精修是否都入册

### 男女拍摄前准备

- [ ] 女生拍摄前 3 天染发、2 天做美甲、1 天脱毛
- [ ] 男生拍摄前 2 天剪发、前一天晚上刮胡子修鼻毛
- [ ] 选片时和另一半一起去，问清隐形消费、底片张数、重拍政策、产品寄送和邮费

### 男生拍摄物品准备

### 选片注意事项

- 光线不好、角度不好、动作不好、表情不好、闭眼、姿势重复的照片果断删除，这些后期都难以修复。
- 多留双人照，单人可各留两张，男士照片保持基础数量即可。
- 背影照、剪影、半身照、远景可少留；每个场景平均选片，按精修张数分配到每套服装和每个场景。
- 看好赠送相框的横竖方向，根据照片构图选择；迎宾海报建议选全身内景照，床头挂相建议选外景横框照。
- 选片时问清隐形消费（除精修外是否有入册排版设计费）、底片张数及是否全送、拍摄不满意是否可重拍、产品寄送时间及邮费承担方、精修张数及加精修单价、精修是否全部入册。

### 新人拍摄前准备

**女生准备**
- 染发：建议拍摄前 3 天染，黑茶色偏棕更易做发型、上镜效果好。
- 美甲：提前 2 天做，延长甲裸粉带钻透明感强。
- 脱毛：提前 1 天脱好，腋下必须脱。
- 美瞳与润眼液：棕色系自然耐看，建议日抛，并备润眼液防止眼干。
- 贴身衣物：硅胶胸贴、无痕内裤、拖鞋、厚底鞋、黑白袜子各一双。
- 其他物品：防晒、雨伞、遮阳伞、湿巾、花露水、水、一次性吸管。

**男生准备**
- 剪发：提前 2 天，长度方便做造型、不要太短。
- 刮胡子、修鼻毛：拍摄前一天晚上处理。
- 隐形眼镜：非近视可不带。
- 剪指甲、黑/白袜子（船袜、中腰、高腰各一双）、手表、口喷、假戒指一对。
- 可准备身体素颜霜，起到美白和防晒作用。
