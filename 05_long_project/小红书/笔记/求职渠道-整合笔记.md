#### 1.1.2 BOSS直聘（11 条）

- 方法1：关闭个性化推荐
	- 作用：减少平台基于历史行为反复推送老公司，扩大新公司曝光
	- 关闭「个性化职位推荐」和「个性化内容推荐」两个开关
- 方法2：开启隐藏求职偏好
	- 作用：让系统无法根据已有偏好过滤，从而推荐更多样化的岗位与公司
	- 打开「对BOSS隐藏求职偏好」开关
- BOSS直聘
	- BOSS直聘：沟通69次，投递11份：2次
	- BOSS直聘：活跃度最高
- 优先查看3-5日内新发布岗位，回复率通常更高
- **合计**：面试5次，最终获1个offer，来源于BOSS直聘
- BOSS直聘：与应聘公司BOSS直接线上沟通

#### 1.1.3 前程无忧（9 条）

- 前程无忧（https://www.51job.com/）：国内老牌综合招聘平台，覆盖全国各行业、各城市
- 常用软件：BOSS、智联、前程无忧，其中 BOSS 回复效率较快。
- **前程无忧**：沟通22次（招聘方主动5次），投递15份，0面试
- 前程无忧/某程某优：反馈差，效果不佳
- 偏传统行业/国企/外企/民企：前程无忧51job：综合性强
- 主用：BOSS直聘、前程无忧51job、猎聘
- 前程无忧51job：大多已读不回或直接拒绝，相对BOSS略靠谱
- 传统行业：前程无忧：国企和传统行业，非互联网公司多
- 前程无忧：专业人力资源服务公司

#### 1.1.4 猎聘网（9 条）

- 猎聘网
	- 猎聘网（https://www.liepin.com/）：中高端人才招聘平台，兼顾校招管培生与社招岗位
	- 猎聘网：中高端职位市场占有率高，很多外企发布招聘信息或委托猎头寻访；完善简历后会有猎头主动联系。
- 猎聘
	- 猎聘：国企和相对大型企业较多，岗位高级但要求严格，可批量一键投递
	- 猎聘：以往大部分机会来自猎聘
- **猎聘**：沟通86次（招聘方主动约15次），投递40份，面试2次
- 综合招聘 APP：BOSS 直聘、猎聘、智联招聘、前程无忧。
- 中高端/外企：猎聘：猎头多、管理岗多、大公司/外企多
- 猎头内推：猎聘：专业猎头，应届生没机会
- 重点平台：猎聘 + BOSS（精准筛选）

#### 1.1.5 智联招聘（7 条）

- 智联招聘
	- 智联招聘（https://www.zhaopin.com/）：综合性大型招聘平台，提供简历优化、面试指导等辅助服务
	- 智联招聘：职位种类丰富，覆盖各行各业；大中小型企业岗位均有；投递和筛选流程规范，企业审核较严格：职位更新不及时，部分旧职位未下架；简历模板单一，缺乏个性化
	- 智联招聘：校招、社招岗位都有
- 不要只盯着Boss直聘和智联招聘。
- 智联招聘 & 前程无忧：传统综合招聘网站，覆盖范围广、基数大；仍是许多大型外企业务、销售、运营等岗位的重要渠道。
- 传统行业：智联招聘：岗位类型全，HR已读不回
- 智联招聘：面向大型公司和快速发展的中小企业

#### 1.2.1 互联网科技（26 条）

- 互联网类

- 提前准备代码能力和算法题，避免面试时被动。

- 技术栈放在最前面，分熟练、掌握、了解三个层次
- 附上 GitHub 链接、技术博客，比空说技术更有说服力
- 拉勾网（https://www.lagou.com）：科技/互联网领域的小公司/新公司常驻，创业公司发布岗位更快，适合互联网人。

- 技术类：后端开发、前端开发、算法工程师：需硬技能，薪资高，校招竞争激烈
- 渠道：操作方法
- 欧企技术岗：西门子、博世：技术栈稳定，下班准时，不卷：追求工作生活平衡
- 大厂核心业务岗：字节抖音、阿里电商：成长快，项目含金量高，镀金价值高：追求快速成长
- 央企科技岗：中电科、航天科技：稳定性强，技术压力适中：求稳型求职者
- 行业垂直平台：InfoQ 招聘、CSDN 人才；互联网、物联网、人工智能等细分领域岗位集中；可按技术栈精准匹配（如 Java+分布式、Python+自动化测试）
- 项目经历用"技术栈+动作+数据"描述，例如：用 Java+Redis 实现缓存优化，QPS 从 1000 提升至 5000
- 简历命名格式：姓名-后端开发-XX大学-2026届
- 拉勾：专注互联网行业
- 程序员客栈：国内技术类自由职业平台，适合开发者、产品经理等

### 2.1 信息差与搜索技巧（68 条）

#### 2.1.1 岗位筛选（29 条）

- 投递前筛选
	- 无经验宝妈可尝试：销售公司、物业楼栋管理员、电商助理、线上客服等
	- 看清公司名称，带"娱乐"等词的多数是娱乐直播公司，如不想入职需在投递时规避
	- 这类岗位大多招聘无经验者，上班时间适合接送孩子
- 要懂得规则、会筛选、利用信息差
- 选择公司前需分析自身性格与能力，找到匹配度高的工作环境。
- 这类公司条条框框少、管理随意，通常不打卡、不开无意义例会、不写日报。
- 重点查看“企业认证”和“岗位更新时间”，跳过资料模糊、信息过旧的岗位。
- 将家庭住址临时改为目标区域标志性写字楼或大厦，使用"附近"功能筛选该楼宇或3公里内公司
- 每天目标投30份简历，避免过多导致烦躁
- 同一个岗位在不同公司叫法可能不同，增强信息检索能力很重要
- 所学专业/技能不是只有垂直业务公司才需要，很多工作不需要严格对口
- 若不在一二线城市，可在求职软件中切换城市到北京、深圳、杭州、上海，搜索自己的专业名称，发现可投岗位
- 神仙外企（https://www.waiqi.com）：专门发布外企实习/全职岗位，涵盖快消、咨询、四大、科技类公司，筛选维度专业（公司性质、城市、学历、语言要求等）。
- Boss 直聘：能与招聘者直接沟通，反馈速度较快；适合新兴行业和中小企业：企业质量参差不齐，筛选难度大；沟通效率和专业性不稳定
- 放宽目标行业：大胆海投，基数够大选择机会才多；不要只找与过往经验强相关的岗位。
- 不要只盯着大公司：大厂待遇好、晋升空间大，但压力大、人际关系复杂、竞争激烈、面试流程长。性格平和、不适应高强度脑力劳动或复杂人际关系的人，可考虑小而美的公司。
- 外语要求：一般只需基础水平（如四级），日常多为中文沟通。
- 可搜索岗位关键词：“清关员”“数据录入员”“报关”“跟单员”等。
- 注意：数据录入类岗位重复性高、动脑少；报关/跟单类岗位任务复杂、环节多。
- 更改排序：综合排序改为"最新优先"，也可尝试"距离优先"或"匹配度优先"
- 人工筛选：通勤1小时内、双休、五险一金、7k以上、看岗位简介和公司主页
- 优先选择：BOSS 3日内活跃、今日新发布岗位
- 方法：用 AI 工具输入指令"我正在找 xxx 岗位工作，这个岗位在业内都有什么叫法，穷尽给到我"
- 财会英才网：细分岗位筛选高效。
- 主动搜索：关键词如"Google" + "Marketing" + "Shanghai" + "Jobs"，可筛选公司、地区、工作经验。
- FlexJobs：需会员，但经过筛选，信息质量较高
- RemoteOK：筛选功能细致，技术类岗位机会较多
- 标签：#精准筛选 #长期规划 #稳定为王

#### 2.1.3 搜公司背调（15 条）

- 企业背调
	- 面试前用天眼查、看准网查公司：参保人数、评价、劳动纠纷
- 不要只看招聘软件，要学会"反向搜公司"
- 1. 去小红书搜公司名字，看真实评价
- 2. 去企查查看公司成立时间、社保人数
- 别盲目相信 HR 话术，聪明人都会提前做背调
- 原则：真正好的公司不缺人，垃圾公司才会天天招人
- 两步查底：
- 警惕信号：十几人的小公司吹着要上市、评论区全是"避雷"、社保缴纳人数还没招聘人数多
- 企查查招聘 / 天眼查招聘：商业信息平台的招聘栏目，可查看公司扩张动向、股东、融资历史、人员流动，辅助判断公司靠谱程度。
- 顶级同行投资公司：通过查询股权结构，识别有行业头部同行或知名资本入股的公司
- 公开投资事件：利用36氪、天眼查/爱企查、IT桔子、创业邦等免费平台查询
- 改期望工作地点：线上扫楼式找工作，把工作地点逐个筛选
- 地图搜索：利用地图APP搜索"公司"，发现住处周围企业

## 3、面试与谈薪（94 条）

### 3.1 面试准备（34 条）

#### 3.1.1 面试反问（17 条）

- 面试反问
	- 问清薪资结构（底薪占比）、五险一金、试用期时长
- 工资情况
	- 薪资构成：底薪（有责/无责）+绩效（考核方式）+提成+补贴+年终奖
	- 五险一金：是否缴纳、缴纳时间（入职即缴/三个月/一年）
	- 招聘信息中的薪资范围往往与实际底薪有差距，需问清底薪数额及是否有责
- 工作时间
	- 是否加班、有无加班费
	- 忘打卡、迟到、请假、全勤等扣款规则
	- 年假天数及是否带薪、出差补助
- 这个岗位的核心KPI是什么？入职后第一个月需要重点完成什么？
- 团队目前有多少人？未来的直属领导是什么风格？
- 公司的晋升通道是怎样的？一般多久会有晋升机会？
- 这个岗位的前任是因为什么原因离职的？
- 会有针对这个岗位系统的培训吗？
- 入职后主要负责内容
- 岗位描述以外的具体工作内容

#### 3.1.2 面试前准备（9 条）

- 认真对待每个面试机会
- 每天刷面试经验，整理新媒体运营面试可能问题并过一遍
- 在招聘软件模拟面试间每天练习一次
- 面试前确认岗位是否有coding/机试环节，可向HR或网友打听。
- 10分钟岗位拆解：把JD关键词拎出来，对应自己简历经历，想1-2个带数据的案例
- 10分钟公司摸底：打开公司官网、小红书搜"公司名+避雷/体验"，了解主营业务、近期动态、员工评价，面试时提一两个细节
- 10分钟模拟演练：对着镜子用口语化方式过一遍常见问题，注意眼神和语气
- 面试前准备：根据职位描述做准备，包括面试内容（专业术语、英文界面等）和面试仪态（精神状态、穿着得体）。
- 面试中观察：通过领导说话风格初步判断性格和作风。

#### 3.1.3 笔试与面试形式（7 条）

- 笔试：提前刷言语理解、判断推理、资料分析保持手感；写作题多为材料分析+议论文，结构清晰、逻辑通顺即可；提前熟悉公文格式
- 业务面：会深挖简历细节，提前梳理自己做过的事情，问到时能说明白
- 专业知识：一般技术岗会考
- 企业文化：考前在官网查看，选择题基本可应对
- 结构化面试：题型固定，提前准备答题思路
- 半结构化面试：自我介绍+考官提问，90%问题可提前搜索练习
- 无领导小组面试：注重团队协作，先倾听再表达，避免过于强势或沉默，建议选择计时员或总结类角色

#### 3.1.4 面试观察与安全（1 条）

- 安全防范：面试地点若在居民楼、小巷子等偏僻场所，需谨慎，避免前往不正规公司。

### 3.2 面试问题应对（32 条）

#### 3.2.1 敏感问题（22 条）

- 你为什么离职？
	- 转化为：追求成长 + 匹配新机会
	- 避免说"前公司工资低、同事处不来"
	- 示例："我想接触更具挑战性的项目，贵司这个岗位的XX业务方向很吸引我，我觉得我的XX经验能在这里发挥更大价值"
- 你的缺点是什么？
	- 突出：有小不足，但在积极改进，且不影响核心工作
	- 避免暴露"拖延、脾气急"
	- 示例："我对新工具的掌握速度有点慢，但我会主动学习、找资料，最近就在啃Python数据分析的课程"
- 你期望薪资是多少？
	- 不要上来直接报数
	- 示例："我了解这个岗位在行业内的薪资区间是XX-XX，我希望能拿到XX，当然我更看重公司的发展平台和团队氛围"
- 6月底辞职，GAP两个多月
- 已离职者不要过于焦虑急躁，大环境如此
- 不要真老实讲自己身上的毛病，也别把优点硬说成缺点。
- 适当美化简历，GAP期间用实际经历或学习证明填充
- 如GAP时间较长，可写上期间实际帮忙的小企业经历
- 面试中你才是主角，应自信、提高音量；不是被测试，而是看公司是否匹配自己的薪资和环境预期。
- 调整心态：不过度否定自己，享受GAP期
- 小公司常见 PUA：劝你别看重薪资，要多积累经验
- HR只想听与应聘岗位相关的信息：你的优缺点对这个岗位有什么帮助？
- 可以接受薪资比之前低一些
- 培训时间长且不带薪资的直接不考虑

#### 3.2.2 常见问题（9 条）

- 面试时逻辑清晰、语言流畅地回答问题
- 缺乏清晰职业规划和owner意识，主观能动性不足
- 每次面试针对岗位写一段自我介绍
- 自我评价放在前面，可在几行内展示岗位匹配优势
- 简历要会包装，但不是学历造假或虚报年限，而是优化话术、贴合岗位JD、突出优势。
- 自我介绍要展现优势，不要流水账，内容尽量贴近岗位要求。
- 面试后总结：除刷 KPI 的面试外，每次面试后需回顾问题、改进自我介绍和简历。
- 职场人参考话术二：姓名+应聘岗位+来自/毕业于XX+工作年限与经验+上家公司职责+项目与成果+相对丰富的经验+看贵司业务匹配+希望加入。
- 关键词：经验优势、风险控制、成熟稳重

#### 3.2.3 经验不足应对（1 条）

- 经验不足时，可找同行朋友突击学习，借鉴项目经验并结合自身经历梳理清楚流程。

### 3.3 谈薪与Offer（23 条）

#### 3.3.1 谈薪技巧（14 条）

- 谈薪是博弈，HR问期望薪资时不要直接报底线，可先反问："我在JD上看到的岗位薪资是XXX，请问这个薪资范围准确吗？"
- 若英语能力尚可，可优先考虑国外远程岗位，数量多且薪酬体系相对成熟。
- 如必须给具体数字，可在真实底线基础上大胆上浮约30%，避免入职后不甘心。
- 找工作是双向选择，自信是得分点；只要不造假、不虚张声势，适当包装真实经历可被接受。
- 薪资是靠谈出来的，不是HR给的；要求太低会显得能力一般、不自信，要求太高容易失去机会。
- 参考招聘岗位的薪资范围进行谈判。
- 1. 薪资结构是怎么样的？
- 2. 五险一金怎么交？比例是多少？
- 3. 试用期多久？试用期后是否调薪？
- 4. 是否有餐补、话补等其他福利？
- 5. 绩效/提成的算法？
- 6. 加班是否有薪资？
- 报价公式：我有X年相关经验，能快速上手，对市场行情有了解，期望XX-XX，可根据贵司情况调整，是否在预算范围内。

### 5.2 简历优化（33 条）

#### 5.2.1 简历包装（13 条）

- 不要海投简历，要"包装自己的价值"
- 企业不缺埋头干活的人，缺的是能带来价值的人
- 企业更看重实际成果，不会慢慢培养新人
- 有能力不会展示，再好的本事也没用
- 一份简历不能通用，需根据不同岗位性质调整。
- 提前打磨简历、补齐对应岗位技能
- 简历修改示例：
- 原表述：会做数据、熟悉 ERP 系统、分析商品结构和销售情况
- 优化后：独立梳理销售数据，输出复盘报表，协助团队优化货品结构；熟练制作业务汇报 PPT，支撑部门决策
- 工作经历：分条分点描述工作内容和成果，尽量用数字化指标（如完成率提升、排名上升）。
- 个人技能与亮点：技能、项目、奖项、大学绩点均可写入；若无实习/获奖经历，可将课程小组任务包装为合作项目。
- 包装示例：招聘专员可写为"全面负责招聘工作，通过建立优秀员工画像、分类管理人才库，帮业务部门精准识别候选人，招聘准确率提升45%"。
- 职场人参考话术一：姓名+毕业院校+行业经验+上家公司职责+工作经历（用数据说话，贴近岗位要求）+参与项目+技能锻炼+胜任理由。

#### 5.2.2 有效简历写法（13 条）

- 简历控制在1页A4纸，重点突出与岗位相关的技能和经历，不写无关校园活动
- 可借助 AI 工具润色经历，突出匹配度和数据结果
- 对应岗位需求挖掘过往相关经历
- 把后补的岗位相关能力融入过往经历（公司只要求你会，不在乎何时学的）
- 一切以"写这个能不能为我加分"为标准，不能加分的不写
- 个人评价避免"团队意识、学习能力强、性格开朗"等虚词，围绕岗位匹配关键词写
- 教育背景若不能加分，放在最后
- 职业技能/荣誉奖项对社招作用不大，可不写
- 量化结果：把"做过的活动数据""达成的效果"写清楚，数字更有说服力
- 简历核心传达 2 点：高匹配度、高价值
- 有匹配经历时：提取岗位行话关键词 → 用行业术语描写执行步骤 → 数字量化结果
- 转岗/应届生经历少时：
- 作者建议顺序：个人信息 → 自我评价 → 经历 → 教育背景

- 超级简历（HR认可智能优化）
- 职徒简历（内置名企案例模板）

## 6、避坑与权益保护（45 条）

### 6.1 骗局识别（15 条）

#### 6.1.1 收费骗局（6 条）

- 任何让你先交钱的工作都是骗子
- 国外岗位需注意甄别信息真实性，避免虚假招聘或诈骗。
- 不知名小招聘网站：信息不透明，公司资质存疑，可能涉及传销或诈骗
- 1-3线城市/互联网岗位：首推BOSS直聘，回复速度快但需小心骗子
- 必要时购买付费服务：招聘平台置顶简历可提高曝光率，但同时也要小心骗子
- 不要为“安排岗位”付费：好岗位通常需求少、不向外流出，给钱也轮不到自己。

#### 6.1.2 岗位陷阱（6 条）

- 岗位描述带"分布式、高并发、自动化"等关键词，属于技术核心岗
- 提到"跨国项目、海外协作"，能接触前沿技术，部分有海外轮岗机会
- 写"导师带教、技术特训营"，新人培养体系完善
- JD 技术栈描述模糊，只强调办公软件、沟通能力，大概率是运维杂活岗
- 查公司技术专利数量、研发投入占比，低于行业均值慎投
- 面试只问行政问题、不聊技术细节，可直接 pass

#### 6.1.3 虚假招聘（3 条）

- BOSS 主动联系的高频岗位多为服务员、外卖员、快递员、销售，如非过渡需求可自动过滤。
- 招聘软件中离家近、标注“农夫山泉”“元气森林”等品牌，但公司名为某科技公司，且月薪跨度（如 4000-8000）很大，大概率是催收公司。
- BOSS直聘：多刷，存在较多假岗位/长期挂岗不回复

### 6.2 薪资社保（12 条）

#### 6.2.1 五险一金（6 条）

- 招聘软件上写着"接受无经验""双休""五险一金"，面试后才发现：试用期不给交社保、底薪非常低、画大饼
- 双休和五险一金不是"福利"，是入职底线
- 一旦降低底线，只会被不断压榨
- 真正靠谱的公司，一开始就很规范
- 找工作先看三件事：双休、五险一金、清晰的岗位职责
- 不能接受：没有五险一金、要求随时加班、明显不尊重员工的公司

#### 6.2.2 双休加班（5 条）

- 公司规模小（英国公司在国内设点），因国外人力成本高而将部分岗位转移到国内，提供双休、不加班的工作节奏。
- 国外华人开的小公司（如清关公司）因人力成本原因在国内设点，可能带来双休、不加班的工作模式。
- 好工作判定指标：钱多事少、双休不加班、人际关系和谐、晋升空间大，但很难同时满足，需按优先级排序。
- 不要说：我学习能力强，能加班，愿意拼
- 单休、双休还是大小周

#### 6.2.3 试岗期工资（1 条）

- 警惕"试岗期不给工资"，法律规定工作一天也应发工资，可拨打12333举报

### 6.3 求职诚信（9 条）

#### 6.3.1 简历诚信（8 条）

- 学历别造假，尤其是全日制和非全日制类别。
- 资格证书、职称不要乱编，入职通常要求提供佐证。
- 工作时间轴别乱写，背调公司会找渠道核对。
- 岗位title别乱拔高，背调会直接问上下级关系。
- 薪资水平别瞎写，社保、工资流水都可核实。
- 简历要适当包装但不能造假：在真实经历基础上，从工作细节入手，把普通工作用更专业的话术表达。
- Excel技能示例：熟练运用AVERAGE、IF函数，擅长数据透视表，能够利用复杂数据进行可视化及分析。
- PPT技能示例：能独立完成PPT方案设计、排版、动效制作，有较高的审美及创新意识。

#### 6.3.2 职场认知（1 条）

- 新人职场混得累，往往是因为没人教求职规则

### 6.4 合同陷阱（9 条）

#### 6.4.1 入职风险（4 条）

- 面试前用天眼查等工具查看公司是否存在异常和纠纷。
- 拒绝挂名法人、财务负责人等存在风险的安排。
- 入职后查验电子税务局是否被绑定为办税员。
- 每次面试当天复盘：有没有更好的回答方式？HR还问了哪些未准备的问题？

#### 6.4.2 试用期转正（4 条）

- 试用期和转正
	- 是否有试岗期、试岗期内工作内容
	- 试用期薪资（7天无工资需谨慎）
	- 试用期考核及转正标准

#### 6.4.3 空白合同违约金（1 条）

- 签合同前逐条核对，空白合同不要签

## 7、心态与状态管理（32 条）

### 7.1 长期主义（8 条）

#### 7.1.1 长期主义（8 条）

- 远程岗位信息流通性较弱，需长期关注垂直渠道。
- 找工作过程较累，需保持持续投递
- 建议：不要领导安排什么就做什么，要体现主动性和 ownership
- 不建议轻易跳槽，内部有调整时尽量保守活下来
- 保持持续投递，保持对悬而未决事项的耐受力
- 若HR显示长期未上线，可先跳过，避免简历石沉大海
- 避免长期待在封闭空间反复刷岗位
- 每日小事：坚持每天做一件让自己进步的小事，如看书、健身、写总结

### 7.2 日常状态（7 条）

#### 7.2.1 环境与作息（7 条）

- 兼职如“图书馆整理员一天 200 元”加微信后多为进兼职群，实际岗位以餐馆服务员、工厂正式工为主。
- 避免周末和下班时间投递，容易被新简历覆盖
- 去图书馆完成每日固定任务，模拟上下班节奏
- 通过运动改善睡眠和心态
- 自媒体可作为复盘工作能力和开拓新收入的方式
- 给自己放假，去公园、爬山等接触自然
- 睡前用读书代替玩手机，保证早起

### 7.3 焦虑管理（7 条）

#### 7.3.1 焦虑管理（7 条）

- 吃好喝好睡好，维持状态
- 找工作同时保持健身、写作、护肤等生活节奏
- 不要因失业放弃热爱生活
- 面试时保持自信
- 社区/街道推荐岗位质量通常有限，需酌情看待
- 保持好心态，工作能找到，但满意度因人而异
- 兴趣爱好帮助冲散焦虑迷茫

### 7.4 投递心态（5 条）

#### 7.4.1 投递心态（5 条）

- 很多公司岗位要求并没有写的那么高
- 投递时不必100%符合岗位要求，符合约70%即可大胆投递。
- 大胆投简历，永远不设限：不要因为没经验、学历不够、经历不丰富就自我否定。
- 不怕没经验：很多公司招聘要求互相复制，写3-5年经验实际没那么严格，尤其是小公司。
- 不怕没技能：岗位完全符合的候选人很少，HR刷简历能满足60%就不错，HR也有KPI考核，因此不必害怕，大胆海投。

### 7.5 转型心态（4 条）

#### 7.5.1 转型心态（4 条）

- 你不是被淘汰，只是在转型
- 你的经验是财富，不是包袱
- 找工作的方式变了，不代表你不行了
- 不要先入为主认为35岁注定难找工作

### 7.6 面试心态（1 条）

#### 7.6.1 面试心态（1 条）

- 一切感受以亲身经历为准，避免自我设限
