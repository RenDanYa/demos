### 四大金刚
#### 问主持人
- [ ] 确认主持人与哪些酒店合作过、主持过几场婚礼、能否看现场视频
- [ ] 确认大概流程、串词和音乐谁负责、串词能否和新人商定、是否有彩排
- [ ] 确认当天是一个人还是有自己的团队（督导、音响助手等）
- [ ] 确认现场不活跃怎么办、新人紧张忘词怎么办
- [ ] 确认主持风格（轻松诙谐还是煽情），提前沟通不喜欢的环节
- [ ] 确认是否需要长辈上台致辞、是否需要提前准备稿子

#### 问化妆师
- [ ] 确认试妆是否收费、多少钱、可以试几次、不满意是否可以换人
- [ ] 确认跟妆费用怎么算（包天/按小时/按造型数量）、是否全天跟妆补妆
- [ ] 确认化妆和换妆需要多长时间、是否能配合礼服适当修改
- [ ] 确认是否有配饰、是否另外收钱、化妆品品牌、过敏风险
- [ ] 确认眼睫毛、一次性粉扑等是否需要额外收费
- [ ] 确认试妆的化妆师是否是婚礼当天的化妆师
- [ ] 确认婚礼当天是一个人来还是带助理、是否需要增加额外费用
- [ ] 确认是否能为父母及伴娘伴郎提供简单妆发、收费多少
- [ ] 确认新娘需要提前准备什么

#### 问摄影/摄像师
- [ ] 确认婚礼摄影多长时间、拍摄过多少场婚礼、拍摄机器
- [ ] 确认擅长什么风格（抓拍还是摆拍）、拍人为主还是拍氛围
- [ ] 确认一般会拍哪些场景、新郎出发接亲前是否会拍
- [ ] 确认单机位还是双机位
- [ ] 确认婚礼当天会拍多少张照片、底片是否全给、精修多少张
- [ ] 确认额外加修一张多少钱、婚礼当天是否能出9张精修
- [ ] 确认付款方式、精修多长时间能出
