### 试纱准备与流程

- [ ] 在线上锁定2-3家心仪婚纱店铺和具体款式
- [ ] 优先预约提供免费试纱的店家
- [ ] 准备无肩带内衣或胸贴，提前处理腋下脱毛
- [ ] 试纱当天化淡妆前往
- [ ] 带1-2位审美同频的亲友陪同试纱
- [ ] 主动与店员沟通，尝试不同风格的婚纱
- [ ] 每件婚纱多角度拍照（正面、侧面、背面、走动、坐下）
- [ ] 关注婚纱舒适度，确保行动自如
- [ ] 试纱后不急于当场下单，回家对比后再决定

### 异地租赁条款与费用

- [ ] 确认租赁条款（是否支持异地、邮寄/自取、异地费、清理费）
- [ ] 算好租期确保覆盖婚礼日期和试装时间（一般租3-5天），问清超时收费标准
- [ ] 核实所有费用明细（定金、尾款、清洁费、损坏赔偿、改尺寸费）并写进合同

### 收货检查

- [ ] 收货时在快递点全程录像开箱检查外包装
- [ ] 拿到婚纱后立即试穿，发现尺寸问题马上联系店家
