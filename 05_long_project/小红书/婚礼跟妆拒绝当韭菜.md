### 试妆硬标准

- [ ] 试妆时检查眉毛是否根根分明、有无糊成一团
- [ ] 试妆时检查睫毛是否有苍蝇腿、真假睫毛是否分层
- [ ] 试妆时检查发型碎发情况及颅顶高度是否足够

### 跟妆套路确认

- [ ] 确认婚礼当天是否是试妆的化妆师本人全程跟妆
- [ ] 确认跟妆包含几个妆造及补妆用品是否齐全
- [ ] 确认妈妈妆、伴娘妆是否额外加钱及其他隐性费用
- [ ] 确认试妆不满意能否免费调整几次、能否更换化妆师
- [ ] 确认定金何时交、试妆费是否包含在套餐内或可抵扣

### 风格匹配准备

- [ ] 寻找审美和风格匹配的真实新娘妆参考
- [ ] 先定好婚纱款式再试妆，让化妆师搭配着化
- [ ] 试妆前一周做好基础保湿、不尝试新的功效型护肤品

### 试妆与沟通

- [ ] 试妆时检查底妆是否暗沉假面卡粉、细节处理是否到位
- [ ] 试妆时检查眼妆是否显气质、真假睫毛融合是否自然
- [ ] 试妆时检查发型是否显头小显脸小、头饰能否试戴
- [ ] 主动沟通自己的喜好和避雷点
- [ ] 试妆过程中及时反馈每一步的感受
- [ ] 模拟婚礼当天流程，估算各造型切换所需时间

### 动态测试

- [ ] 试妆后走动、抬头、低头、鞠躬，测试发饰和发髻牢固度
- [ ] 用原相机拍半身照，检查妆容自然度和整体比例
- [ ] 用手机录一段15秒视频，检查大笑、皱眉、假装流泪时的妆面状态
