# 整合后待办


## 1、前期规划与预算

### 1.1 整体预算规划

#### 1.1.2 婚纱礼服预算

- [ ] 确认**婚纱礼服租赁价格**及换款政策

#### 1.1.3 婚礼布置预算

- [ ] 确认婚房装饰品预算

#### 1.1.4 宾客与餐饮预算

- [ ] 新郎：预定喜糖、喜酒、喜宴

#### 1.1.5 其他杂项预算

- [ ] 确认新郎西服、婚纱礼服、敬酒服、美甲预算
- [ ] 确认双方父母衣服、新娘新郎新衣服预算
- [ ] 确认上车礼、梳头礼、开口礼、伴郎伴娘礼预算
- [ ] 确定伴手礼预算和数量

### 1.2 砍价与谈判策略

#### 1.2.1 砍价技巧

- [ ] 不着急付定金，警惕"价格只保留今天"等销售话术
- [ ] 不透露自己的预算给对方
- [ ] 让谈判强势的一方出面砍价，通常可砍500-1000元
- [ ] 确定心理价位，避免盲目去奢华店

#### 1.2.2 套餐比价

- [ ] 看高价套餐争取按预算价拿下（如6000预算看7000套餐）
- [ ] 记录每家店的款式、价格和服务评价
- [ ] 提前了解婚纱店的套餐内容和潜在消费项
- [ ] 问清不同套餐的实物差异（品牌、新旧、面料、定制程度）
- [ ] 不冲动付定金，多对比几家
- [ ] 保留谈价聊天记录避免后期涨价

### 1.3 时间线与流程规划


#### 1.3.3 婚前2-3个月

- [ ] 提前2-3月购买主纱鞋（7-10cm高跟）

#### 1.3.4 婚前1个月

- [ ] 婚礼前1个月左右做最终复尺与确认

#### 1.3.5 婚前1-2周

- [ ] 确认改衣周期（一般1-2周），赶婚期需提前安排
- [ ] 婚前一周每天敷补水面膜
- [ ] 婚前一周做裸色简单款美甲（如需延长甲提前适应）
- [ ] 提前两周定制手捧花
- [ ] 提前一周做新娘美甲

#### 1.3.6 婚前3天至当天

- [ ] 带上婚鞋去试纱（鞋跟高度与婚礼当天一致）
- [ ] 确认婚礼当天拍摄张数（如不少于200-400张）
- [ ] 确认是否提供快剪（婚礼当天大屏播放）
- [ ] 确认当天是一个人还是有自己的团队（督导、音响助手等）
- [ ] 确认试妆的化妆师是否是婚礼当天的化妆师
- [ ] 确认婚礼当天是一个人来还是带助理、是否需要增加额外费用
- [ ] 提前三天布置婚房（客厅和卧室）
- [ ] 带一双与婚礼当天高度相近的高跟鞋
- [ ] 提前预约（避开节假日及周末，提前1-3天预约，准时到达）
- [ ] 提前问询是否需要自带妆，如已定好化妆师可当天**妆纱同试**
- [ ] 确认婚礼当天婚纱破损或污渍的清理方式及赔偿金额

## 2、酒店与场地

### 2.2 场地布置协调

#### 2.2.1 场地风格确认

- [ ] 提前确认婚礼场地类型（室内或户外）
- [ ] 进店先和礼服师明确婚礼场地（室内一可冲大拖尾、重工款，户外/草坪优先轻纱、简约款）、身材痛点（肩宽/腰腹/副乳）、风格偏好（极简、公主风、复古、鱼尾，别盲目试网红款!）
- [ ] 确定主纱款式（室内重工/室外缎面）
- [ ] 携带场地照片和婚礼策划定稿去试纱
- [ ] 试纱时考虑婚礼整体布置风格和色调协调性
- [ ] 新娘：考虑婚礼形式、风格主题
- [ ] 确定婚礼舞台风格，针对性选择婚纱店

## 3、婚庆策划与四大金刚

### 3.5 化妆师/跟妆服务确认

#### 3.5.1 试妆与费用

- [ ] 确认试妆方案
	- [ ] 确认试妆是否收费、多少钱、可以试几次、不满意是否可以换人
	- [ ] 跟妆提前试妆并确认风格
	- [ ] 新娘：试妆并确定妆面
- [ ] 确认新娘化妆跟妆费用是否另算及具体价格
- [ ] 确认跟妆是否可试妆及服务时长
- [ ] 预约专业化妆师试妆（可节省眉弓骨+山根等医美费用）

#### 3.5.2 服务范围

- [ ] 确认跟妆方案
	- [ ] 确认跟妆费用怎么算（包天/按小时/按造型数量）、是否全天跟妆补妆
	- [ ] 确认化妆和换妆需要多长时间、是否能配合礼服适当修改
	- [ ] 确认是否能为父母及伴娘伴郎提供简单妆发、收费多少
	- [ ] 确认新娘需要提前准备什么

#### 3.5.3 化妆品与配饰

- [ ] 确认化妆品与配饰
	- [ ] 确认是否有配饰、是否另外收钱、化妆品品牌、过敏风险
	- [ ] 确认眼睫毛、一次性粉扑等是否需要额外收费
- [ ] 确认化妆品、饰品、道具是否需要额外收费
- [ ] 试纱前1-2天和婚纱店确认有无隐形消费（试纱费、改衣费、配饰费等）
- [ ] 试穿时仔细检查婚纱是否有破损、污渍、开线，配饰是否齐全


## 4、婚纱礼服与试纱

### 4.1 身材与版型准备

#### 4.1.1 身材类型确认

- [ ] 确认自己的身材类型（倒三角/矩形/沙漏/苹果/梨型）
- [ ] 明确自己最在意的身材点（腰、肩、手臂等）

#### 4.1.2 版型选择

- [ ] 根据身材类型筛选适合的婚纱版型
- [ ] 列出需要避开的婚纱款式清单
- [ ] 按版型试穿：小个子选A字款/短款，微胖选高腰A字/缎面简约，肩宽选一字肩/V领，避开无袖
- [ ] 不用盲目跟风网红款

### 4.2 试纱前准备

#### 4.2.1 试纱物品

- [ ] 提前准备胸贴、肉色内裤、高跟鞋
- [ ] 准备胸贴/乳贴
- [ ] 准备肉色安全裤（优先选有收腰提臀效果的）
- [ ] 准备防磨脚贴（试穿婚鞋后准备）
- [ ] 准备新娘当日穿戴包（隐形胸贴、备用丝袜、防滑贴、安全别针、发夹）
- [ ] 带裸色无痕胸贴（Nubra）和肉色安全裤

#### 4.2.2 个人形象

- [ ] 腋下/胳膊脱毛
- [ ] 化淡妆（底妆+眉毛+口红）
- [ ] 盘发或扎马尾（披发会遮挡肩颈线条）
- [ ] 准备隐形眼镜/美瞳（框架眼镜影响观感）
- [ ] 试纱当天化淡妆、戴隐形眼镜、头发简单盘起
- [ ] 试纱前一天洗头洗澡、护肤脱毛（提前腋下脱毛）
- [ ] 近视者佩戴自然舒适的美瞳
- [ ] 试纱前吃饭七分饱，避免小肚腩
- [ ] 避开生理期以免不小心弄脏婚纱

#### 4.2.3 信息收集

- [ ] 去试纱前列出要问的问题清单
- [ ] 向有经验的朋友收集试纱经历和建议
- [ ] **提前在社交平台收藏喜欢的款式**

#### 4.2.4 预约安排

- [ ] 提前预约多家婚纱店（建议3-5家）
- [ ] 规划试纱行程路线和时间安排
- [ ] 安排第一次试纱：婚礼前3-4个月，确定婚纱店和风格方向
- [ ] 安排第二次试纱：婚礼前1-2个月，结合最终身材和场布定稿选定婚纱
- [ ] 选择新款到店后的时间段去试纱
- [ ] 对比多家婚纱店，考察款式数量、婚纱状态、价格区间
- [ ] 确认婚纱店审美是否在线，是否真心推荐适合你的款式
- [ ] 两人一起：试纱
- [ ] 提前预约试纱时间，尽量避开周末高峰
- [ ] 选择工作日（如周二下午）去试纱

### 4.3 婚纱店沟通

#### 4.3.1 试纱费用

- [ ] 确认试纱费用
	- [ ] 提前了解目标婚纱店的试纱费用政策
	- [ ] 问清试纱费收费标准（按件/按类型/按次）
	- [ ] 问清试纱费能否免除（当天定下或多人同行时）
	- [ ] 问清试纱费能否全额抵扣套餐价
	- [ ] 问清试纱是否限时、超时怎么算
	- [ ] 问清试纱费及是否可全额抵扣并要求写进收据
	- [ ] 问清免费试纱是否有数量限制
- [ ] 确认试纱是否收费，下单后能否抵扣套餐费用
- [ ] 确认试纱费是否可在下单时抵扣
- [ ] 问清楚是否需要试纱费，下单后是否退还

#### 4.3.2 服装套数确认

- [ ] 确认套餐服装套数
	- [ ] 确认是否有包含秀禾、敬酒服、伴郎伴娘服的套餐及性价比
	- [ ] 问清套餐具体包含哪几件衣服（出门纱/主纱/敬酒服/晨袍等）
- [ ] 确认摄影内容是否包含晨袍互动、父母合影、迎亲送别等
- [ ] 确定秀禾款式
- [ ] 确定敬酒服款式
- [ ] 确定迎宾纱款式
- [ ] 确定婚礼所需服装套数（主纱、敬酒服、秀禾等）
- [ ] 新娘：选婚纱礼服及配饰
- [ ] 控制试穿数量在3-5件（主纱、出门纱、敬酒服各 1-2 件），试太多会产生审美疲劳

#### 4.3.3 配饰与服务

- [ ] 确认参观的婚纱、饰品是否都可以随便选
- [ ] 确认新娘**跟妆服务**包含人数（是否含妈妈/伴娘）
- [ ] 问清套餐价是否包含修改、清洗、配饰、运费
- [ ] 准备新娘当日仪式包（头纱、手套、首饰袋、敬茶杯、改口红包）
- [ ] 确认套餐是否包含头纱、裙撑、伴娘服等配饰
- [ ] 确认套餐包含衣服套数（秀禾、敬酒服、伴郎伴娘服？）及配饰（头纱、裙撑、首饰等）是否另收费
- [ ] 确认租的婚纱包含哪些配饰（头纱、头饰、耳环、项链等）

#### 4.3.4 升级与单租

- [ ] 确认套餐升级规则
	- [ ] 问清套餐里的衣服能否更换或加钱升级
	- [ ] 问清能否单租某一件、单租怎么算
	- [ ] 问清套餐能否升级、补差价规则

#### 4.3.5 合同条款

- [ ] 确认租赁合同条款
	- [ ] 问清婚期改了能否免费换档期、提前多久通知
	- [ ] 问清轻微磨损/污渍赔偿标准
	- [ ] 问清定金比例、尾款支付时间（取纱时付还是还纱时付？）、取消婚礼定金能否退
	- [ ] 确认合同中写明婚纱品牌/款号、取还纱日期、物品清单、总价及违约条款
	- [ ] 确认污渍、破损的具体赔偿标准
	- [ ] 确认付款流程（定金、押金、尾款分别什么时候付）
	- [ ] 确认婚纱归还后多久退押金
- [ ] 确认婚期临时变动能否延期
- [ ] 警惕低价引流工作室，确认是否正版授权
- [ ] 确认是否全场通选、有无分区加价
- [ ] 确认无清洗费、超时费、上门额外费用

### 4.4 试纱执行

#### 4.4.1 需求沟通

- [ ] 到店与礼服师沟通
	- [ ] 到店先和礼服师明确需求
	- [ ] 提前告知婚纱店婚礼场地和预算范围
	- [ ] 提前和礼服师说明预算，避免推荐超出预算的款式
	- [ ] 提前1-2周预约并告知场地风格、预算和身材特点
- [ ] 确定偏好风格（干净简约还是华丽繁复）
- [ ] 确认有哪些风格并索要客片参考
- [ ] 确认风格可私人订制还是固定拍摄样式
- [ ] 确认所有风格挑选是否免费
- [ ] 提前收藏喜欢的款式并**告知礼服师**
- [ ] 礼服馆需要安排试衣间和礼服师
- [ ] 各种款式都试一下，选择最适合自己的


#### 4.4.3 试穿技巧

- [ ] 试穿测试
	- [ ] 试穿后测试能否自然走路、坐下、不用憋气
	- [ ] 试穿时走动、坐下、抬手，测试是否勒腰、踩裙边、走光
	- [ ] 每试一件婚纱都要走动、坐下、抬手，测试是否方便行动
	- [ ] 试纱时走动、转身、坐下、抬手测试舒适度（肩带是否滑落、腰腹是否勒人、裙摆会不会绊脚）
	- [ ] 进店先试自己选的款，再听店员推荐（避免被带着试滞销款）
- [ ] 拍照与决策
	- [ ] 试穿时拍正面、侧面、背面照片和视频留存对比
	- [ ] 试穿多种款式婚纱并拍摄照片做对比
- [ ] 新娘：试婚纱礼服、婚鞋确保合身

#### 4.4.4 拍照留存

- [ ] 拍照与决策
	- [ ] 多拍多角度照片（正面/侧面/背面），方便对比和商量
	- [ ] 自己用手机多角度拍照留底，方便回家冷静对比
- [ ] 提前确认店内能否拍照/拍视频留存参考
- [ ] 确认试纱后能否拍照/拍视频
- [ ] 确认拍照是否需包工作人员午餐

#### 4.4.5 决策技巧

- [ ] 拍照与决策
	- [ ] 不要一次性试太多款（建议3-5件），避免审美疲劳
	- [ ] 最后一次确认试纱不带老公，保留first look惊喜
- [ ] 控制试纱时间在1-2小时内

### 4.5 定纱与取还

#### 4.5.1 定金与押金

- [ ] 确认定金、押金金额是多少，何时退还，有无退还条件
- [ ] 问清定金和押金金额、退还时间

#### 4.5.2 改衣与换款

- [ ] 确认婚纱尺寸是否可以微调，修改是否免费
- [ ] 问清楚后续更换款式是否需要加价及具体收费标准
- [ ] 确认婚纱租赁是否包含修改尺寸服务
- [ ] 婚纱量体并修改尺寸
- [ ] 问清婚礼前多久可以再来试穿、不合适能否免费换款或改尺寸
- [ ] 确认免费修改尺寸次数和超出收费
- [ ] 确认定完后能否换款及是否收费
- [ ] 确认什么时候去试最终尺寸，是否可以免费修改尺寸

#### 4.5.3 取纱与归还

- [ ] 确认婚纱提前多久取货、最晚归还时间、超时计费标准
- [ ] 确认取衣时婚纱是否会清洗熨烫，是否需要额外付清洁费
- [ ] 确认归还时若出现轻微破损是否扣费及扣费标准
- [ ] 若确定要租，提前问清楚取衣时间、存放要求
- [ ] 确认拍摄后是否需要支付服装清洁费
- [ ] 试婚纱并提前租赁，确定取纱时间
- [ ] 取纱时拍摄360度视频留证
- [ ] 确认取还纱时间及超时费用
- [ ] 确认取婚纱提前几天取，婚礼结束几天归还
- [ ] 确认婚纱归还是否有额外清洗费
