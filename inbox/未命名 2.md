


### 1. 选片策略

**原则类：**
- [ ] 选片前设定预算与目标，拒绝选片师引导
- [ ] 选片时坚定不加精修
- [ ] 拒绝强制加片与诱导加片
- [ ] 选片时隔几天再决定是否加片
- [ ] 查清加片单价并设定加片预算上限

**选片标准：**
- [ ] 优先保留双人合照，单人照各留 1~2 张
- [ ] 少选背影、剪影、半身、远景及大全景
- [ ] 多选全身正面照与中近景照片
- [ ] 重复动作 / 场景只保留最好的一张
- [ ] 只选表情、光线、构图最佳的照片，不凑数
- [ ] 手或物品特写只保留最好的一张

**产品核对：**
- [ ] 查清赠送相册、摆台、相框数量
- [ ] 查清相册、相框材质与尺寸
- [ ] 查清是否赠送婚礼海报和电子相册
- [ ] 不升级昂贵相册，不额外加相册页数
- [ ] 查清附加礼包内容及实际价值

**用途预留：**
- [ ] 按用途预留对应照片：迎宾海报 / 请柬 / 相框 / 床头 / 视频 / 手机壁纸
- [ ] 按相册排版预留精修张数，避免被动加片

### 2. 精修沟通（逐项核对）

**整体要求：**
- [ ] 查看客片修图效果并提出皮肤质感要求
- [ ] 要求指定或优先安排修图师
- [ ] 要求先修几张预审，不满意可修到满意为止
- [ ] 要求初版精修不满意可免费修改
- [ ] 逐张检查精修细节、胖瘦与体态
- [ ] 检查整体环境与服饰细节，不只关注脸部
- [ ] 拒绝流水线 P 图，按原五官比例微调
- [ ] 提前告知修图师需保留的特征（如痣）
- [ ] 保留明显个人特征，拒绝一键磨皮

**肤色与色调：**
- [ ] 要求肤色均匀、整体提亮、气色自然
- [ ] 要求整体色调统一，避免发青发紫
- [ ] 要求色调和谐温馨，避免假白
- [ ] 要求光线正常曝光、光影过渡自然
- [ ] 要求背景颜色干净自然
- [ ] 要求外景草地调色、肤色提亮

**背景与杂物修复：**
- [ ] 要求去除背景杂物、穿帮及背景布褶皱
- [ ] 要求去除外景反光板、电线及背景多余人物
- [ ] 要求修掉脏污、褶皱痕迹及裙摆周边干净
- [ ] 放大检查迎宾照及放大产品的裙摆与衣服破损

**五官与脸型：**
- [ ] 要求面部头部整体稍微修小，额头饱满、发际线补齐
- [ ] 要求脸型对称、五官立体轮廓
- [ ] 要求适当放大双眼、对称眼神提亮
- [ ] 要求鼻翼缩小、鼻梁适当拔高
- [ ] 要求淡化颈纹、眼角细纹，自然不抢镜
- [ ] 要求牙齿美白

**皮肤质感：**
- [ ] 要求皮肤去除痘印、卡粉，干净清透且有纹理

**身形调整：**
- [ ] 要求人物整体瘦身但比例协调
- [ ] 要求身材比例适当拉长、腿部挺拔
- [ ] 要求瘦胳膊、锁骨立体、消除斜方肌和腰部赘肉
- [ ] 要求高低肩、颈部前倾、驼背自然调整

### 3. 产品制作与交付

**合同保障：**
- [ ] 将成品**交付周期与物流方式**写入合同
- [ ] 将产品包邮或邮费承担方写入合同
- [ ] 将赠品清单（相册、相框、摆台、登记照等）写入合同

**产品选择与审核：**
- [ ] 选择**大尺寸、高质量材质**的主相框
- [ ] 不升级昂贵相册与相框
- [ ] 不额外做九宫格 / 十二宫格等排版
- [ ] 提前审核相册排版设计
- [ ] 要求全程陪伴服务，确保各环节问题及时解决

**创意用途（非必做）：**
- [ ] 用照片制作创意照片墙
- [ ] 用单人照或合照制作席位卡 / 桌牌
- [ ] 用氛围感照片做手机壁纸或头像
- [ ] 用情绪森系 / 纪实素材制作婚礼 Vlog
- [ ] 用清新海景 / 氛围海景照片做手机壁纸
