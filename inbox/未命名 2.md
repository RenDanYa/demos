## 阶段二：拍摄前准备（倒计时执行）
> 目标：调理状态、准备物品、与商家确认所有细节。建议拍摄前 1 个月开始逐步推进。

### 倒计时 7 天（集中调理）

- [ ] 拍摄前一周开始清淡饮食
- [ ] 拍摄前一周开始坚持涂润唇膏
- [ ] 提前一周开始护肤补水
- [ ] 提前对着镜子练习自然笑容、表情和拍照姿势

### 倒计时 3~7 天（造型基础准备）

- [ ] 提前 3~5 天染发，推荐黑茶色或深棕色系，保持发色统一
- [ ] 提前 3~7 天理发（男生），注意不要剪太短
- [ ] 拍照前不种睫毛、不剪头发

### 倒计时 1~2 天（细节收尾）

- [ ] 提前 1~2 天完成腋下及手臂脱毛
- [ ] 提前 1~2 天做裸色或法式美甲，或备好裸钻穿戴甲
- [ ] **试穿婚鞋**并准备创可贴、高跟鞋贴及防磨脚润滑剂
- [ ] 有正式西装或衬衣可自带，提前拍照发群确认款式
- [ ] 浅色高跟鞋和平底鞋提前拍照发群确认款式颜色

### 倒计时 1 天（终极准备）

- [ ] 拍摄前一天洗头，不使用护发素和发膜
- [ ] 拍摄前一天修剪指甲（男生）、刮胡子、修鼻毛
- [ ] 拍摄前一晚早睡并减少饮水，避免水肿
- [ ] 拍摄前一晚尽量少吃
- [ ] 提前一天查看拍摄日天气预报
- [ ] 备齐拍摄当天需自备的物品（见下方“物品打包清单”）
- [ ] 提前试穿主纱，检查舒适度与效果
- [ ] 录制一个转场短视频（如有此需求）

### 服装与造型沟通（拍摄前1~2周重点执行）

> 注：此部分原属于“前期准备”中的内容，按时间线归入拍摄前阶段。

#### 一、前期选纱与风格确认（拍摄前1~2周）

- [ ] 确认**选婚纱时间**（拍摄当天还是提前几天），在群里问清
- [ ] 确认是否会**提前试婚纱**
- [ ] 确认当天是否可以参观婚纱场景
- [ ] 提前整理并告知礼服师自己想要的婚纱风格
- [ ] 前置沟通争取**升级礼服区域**
- [ ] 遇到**喜欢的服装** → 向礼服师索要样片确认效果
- [ ] 不选裙摆脏、超过三种材质、长袖带领子或泡泡袖婚纱
- [ ] 婚纱首选**缎面或纱面材质**
- [ ] 慎选烟雾光影婚纱照，避免看不清人脸
- [ ] 红色礼服更适合室内纯色背景，外景颜色易扎眼
- [ ] 确认能否看**化妆师作品和服装款式**
- [ ] 确认**鞋子**是否需要自带

#### 二、人员沟通与妆造服务确认（选纱后、拍摄前集中沟通）

- [ ] 确认一套服装可拍几个造型
- [ ] 确认妆造更换规则
- [ ] 在既定服装数量下争取多做造型（如主纱做两套妆造）
- [ ] 确认摄影师、造型师等级及是否可以指定
- [ ] 确认拍摄前是否有时间与化妆师、摄影师沟通需求
- [ ] 化妆师：
    - [ ] 确认化妆师是否**全程跟妆**
    - [ ] 确认**化妆时间**
    - [ ] 确认改妆是否免费，是否可随时与化妆师沟通
    - [ ] 提前与化妆师充分沟通妆造（不满意当场提出）
    - [ ] 确认是否可以要求造型
- [ ] 摄影师：
    - [ ] 拍摄前与摄影师沟通拍摄风格、动作及构图
    - [ ] 告知摄影师按用途拍摄：横版双人正面照、竖版全身显高照、横版大场景照、竖版甜蜜亲密照
    - [ ] 要求摄影师多拍横版、竖版、特写、全景等不同构图
    - [ ] 让摄影师在拍摄时提醒驼背、耸肩、高低肩等问题
    - [ ] 拍摄过程中有想法及时与摄影师 / 化妆师沟通
    - [ ] 每组拍完后现场查看原片，发现问题立即要求重拍
    - [ ] 拍摄中提醒摄影师注意男生的姿势与面部拍摄角度

#### 三、拍摄流程与选片规划（拍摄前定好方案）

- [ ] 四套服装按秀禾、主纱、礼服、轻纱顺序安排，主纱放第二套
    - [ ] 选择白灰 / 简约光影背景拍摄内景主纱
    - [ ] 选择草坪 / 森系场景拍摄外景主纱
    - [ ] 慎选红色秀禾拍外景，优先浅色秀禾搭配中山装拍园林
- [ ] 4 套服装安排 1~2 套外景即可，避免过多
- [ ] 提前给摄影师强调哪套是主纱
- [ ] 提前规划每套服装入选张数（如每套约 10 张）

## 阶段三：拍摄当日执行
> 目标：顺利拍摄，确保成片质量。核心是 **现场看片、及时纠偏**。

### 当天早晨

- [ ] 拍摄当天早上喝杯黑咖啡帮助消肿
- [ ] 拍摄当天早晨吃好早餐
- [ ] 拍摄前做好面部清洁与补水保湿
- [ ] 拍摄前做好防晒
- [ ] 拍摄前涂抹防蚊液（外景）
- [ ] 保持放松自信，拍摄时大胆表现

### 拍摄现场执行

- [ ] 实地查看化妆品、化妆间等硬件条件（可提前踩点或当天提早到）
- [ ] 每套造型拍完后现场查看照片，不满意当场要求重拍
- [ ] 拍摄中有想法及时与摄影师 / 化妆师沟通
- [ ] 提醒摄影师注意男生的姿势与面部拍摄角度
- [ ] 告知摄影师按用途拍摄（横版双人正面、竖版全身显高、横版大场景、竖版甜蜜亲密）
- [ ] 要求摄影师多拍横版、竖版、特写、全景等不同构图

### 拍摄结束后

- [ ] 拍摄结束当天及时清洗头发，可先用护发素再用洗发水或去理发店清洗
- [ ] 拍摄结束后及时卸妆并做好皮肤清洁

## 阶段四：后期处理
> 目标：选片、精修沟通、产品制作与交付。核心原则：**不加精修、不升级产品、逐张审核**。建议预留 1~2 个月。

### 1. 选片策略

**原则类：**
- [ ] 选片前设定预算与目标，拒绝选片师引导
- [ ] 选片时坚定不加精修
- [ ] 拒绝强制加片与诱导加片
- [ ] 选片时隔几天再决定是否加片
- [ ] 查清加片单价并设定加片预算上限

**选片标准：**
- [ ] 优先保留双人合照，单人照各留 1~2 张
- [ ] 少选背影、剪影、半身、远景及大全景
- [ ] 多选全身正面照与中近景照片
- [ ] 重复动作 / 场景只保留最好的一张
- [ ] 只选表情、光线、构图最佳的照片，不凑数
- [ ] 手或物品特写只保留最好的一张

**产品核对：**
- [ ] 查清赠送相册、摆台、相框数量
- [ ] 查清相册、相框材质与尺寸
- [ ] 查清是否赠送婚礼海报和电子相册
- [ ] 不升级昂贵相册，不额外加相册页数
- [ ] 查清附加礼包内容及实际价值

**用途预留：**
- [ ] 按用途预留对应照片：迎宾海报 / 请柬 / 相框 / 床头 / 视频 / 手机壁纸
- [ ] 按相册排版预留精修张数，避免被动加片

---

### 2. 精修沟通（逐项核对）

**整体要求：**
- [ ] 查看客片修图效果并提出皮肤质感要求
- [ ] 要求指定或优先安排修图师
- [ ] 要求先修几张预审，不满意可修到满意为止
- [ ] 要求初版精修不满意可免费修改
- [ ] 逐张检查精修细节、胖瘦与体态
- [ ] 检查整体环境与服饰细节，不只关注脸部
- [ ] 拒绝流水线 P 图，按原五官比例微调
- [ ] 提前告知修图师需保留的特征（如痣）
- [ ] 保留明显个人特征，拒绝一键磨皮

**肤色与色调：**
- [ ] 要求肤色均匀、整体提亮、气色自然
- [ ] 要求整体色调统一，避免发青发紫
- [ ] 要求色调和谐温馨，避免假白
- [ ] 要求光线正常曝光、光影过渡自然
- [ ] 要求背景颜色干净自然
- [ ] 要求外景草地调色、肤色提亮

**背景与杂物修复：**
- [ ] 要求去除背景杂物、穿帮及背景布褶皱
- [ ] 要求去除外景反光板、电线及背景多余人物
- [ ] 要求修掉脏污、褶皱痕迹及裙摆周边干净
- [ ] 放大检查迎宾照及放大产品的裙摆与衣服破损

**五官与脸型：**
- [ ] 要求面部头部整体稍微修小，额头饱满、发际线补齐
- [ ] 要求脸型对称、五官立体轮廓
- [ ] 要求适当放大双眼、对称眼神提亮
- [ ] 要求鼻翼缩小、鼻梁适当拔高
- [ ] 要求淡化颈纹、眼角细纹，自然不抢镜
- [ ] 要求牙齿美白

**皮肤质感：**
- [ ] 要求皮肤去除痘印、卡粉，干净清透且有纹理

**身形调整：**
- [ ] 要求人物整体瘦身但比例协调
- [ ] 要求身材比例适当拉长、腿部挺拔
- [ ] 要求瘦胳膊、锁骨立体、消除斜方肌和腰部赘肉
- [ ] 要求高低肩、颈部前倾、驼背自然调整

### 3. 产品制作与交付

**合同保障：**
- [ ] 将成品**交付周期与物流方式**写入合同
- [ ] 将产品包邮或邮费承担方写入合同
- [ ] 将赠品清单（相册、相框、摆台、登记照等）写入合同

**产品选择与审核：**
- [ ] 选择**大尺寸、高质量材质**的主相框
- [ ] 不升级昂贵相册与相框
- [ ] 不额外做九宫格 / 十二宫格等排版
- [ ] 提前审核相册排版设计
- [ ] 要求全程陪伴服务，确保各环节问题及时解决

**创意用途（非必做）：**
- [ ] 用照片制作创意照片墙
- [ ] 用单人照或合照制作席位卡 / 桌牌
- [ ] 用氛围感照片做手机壁纸或头像
- [ ] 用情绪森系 / 纪实素材制作婚礼 Vlog
- [ ] 用清新海景 / 氛围海景照片做手机壁纸
